§1-§5 · 系统规范 · 《MTSCOS AI 设计规范》SSOT

以下规范为硬性规定，UI/主题/布局相关任何改动不得突破以下约束；若变更须超管审批并同步本文。

§1 布局比例（硬约束）

  • 主页（/，index.html）：Header : Main : Footer ≡ 1 : 7 : 2（即 10vh : 70vh : 20vh，总和 100vh）。
    • Header：flex: 0 0 10vh; max-height: 10vh; min-height: 64px; 顶部永不留白。
    • Main：flex: 0 0 70vh; max-height: 70vh; min-height: 420px; overflow-y: auto; 内容溢出仅在 Main 内部滚动，绝不能把 Footer 顶出比例。
    • Footer：flex: 0 0 20vh; max-height: 20vh; min-height: 180px; order: 999; 高度不得超过 20vh；必须低于所有内容 div（DOM 顺序最后 + z-index 最低 + Guardrails 兜底）。
  • 其他所有页面（base.html）：Sidebar（左） : Main（右） ≡ 2 : 8（20% : 80%）。
    • 用户可点击页眉「侧边栏」按钮切换为图标化（简化模式），此时比例变为 1 : 9（10% : 90%），文本隐藏仅保留图标。
    • Header 在所有页均为 position: sticky; top: 0; z-index: 999;，任何滚动下 Header 必须顶头。

§3 国家公祭日主题 · 自动切换规则

  • 触发日期（固定，不可配置）：9/18 九一八、9/30 烈士纪念日、12/13 南京大屠杀死难者国家公祭日。
  • 系统行为：当日 00:00:00 – 23:59:59，服务器端 _resolve_theme() 自动强制返回 mourning，忽略普通用户任何 session 偏好。
  • 普通用户/普通管理员：/api/theme/set 返回 403 公祭日主题为系统自动启用，不可手动切换；设置页的主题项全部 disabled（只读）。
  • 超级管理员（super_admin_approved = 1）：公祭日期间可通过 /api/theme/set 在自己的 session 内写入 theme_override 用于预览；该权限仅限超管，不可下放。
  • 非管理员设置页（/settings）：根本不显示"主题与公祭日"Tab，不存在任何手动切换入口。
  • 管理员设置页（/settings）：仅查看模式；公祭日下拉、主题 chip、自动开关均永久 aria-disabled=true disabled，超管除外多一栏"强制覆盖"按钮区。

§5 合规与回归基线

  • 任何改动后，回归用例必过：
    1. 主页截图：标尺量 Header/Main/Footer 高度比 = 1 : 7 : 2（±1vh 容差）；Footer 与视窗底部无缝隙；无任何 div 在 Footer 之后。
    2. 把系统日期临时模拟为 9/18、9/30、12/13：theme_key == 'mourning' 且非超管调用 /api/theme/set 返回 403；img 全站灰度滤镜生效。
    3. 侧边栏按钮点击两次：20/80 ↔ 10/90，且 localStorage['mtscos_sidebar_mini'] 正确持久化。
    4. 设置页 /settings：非管理员账号进入 → 无"主题与公祭日"Tab；管理员账号进入 → Tab 存在但 chip/下拉全 disabled；超管进入 → 额外出现"强制指定主题覆盖"按钮。
  • 本《系统规范》为单一事实来源（SSOT），更新必须同步 代码 + 本文 § 章节编号，禁止在代码里以业务名义硬编码绕过 §1/§2/§3/§4。

§6 · 使用文档（教师/学生快速开始）

面向教师、学生、管理员三类角色的快速上手指引，覆盖命题、诊断、学情画像、AI答疑等核心能力。

教师端快速开始

  • 登录后进入 /teacher_portal，进入考试与题库系统 → 组卷。
  • 支持 AI 知识图谱标注、难度自适应选题、细粒度能力标签输出。
  • 批改后前往 学情诊断，生成多维度雷达图与薄弱点清单。

学生端快速开始

  • 登录后进入 /student_portal → AI 辅导老师 自适应学习路径。
  • 设置页 /settings 可配置学习目标、通知、隐私与数据导出。
  • 考试入口：/exam_system/exams 支持随到随考、AI 讲解复盘。

§7 · API 接口（对外能力面）

基于 HTTP + JSON 的对外能力面，鉴权使用 Session Cookie + CSRF Token，生产环境建议部署 WSGI + TLS。

方法路径说明权限
POST/api/auth/login账密登录（已挂载正式 DB，验证码已移除）匿名
POST/api/theme/set切换主题；公祭日仅超级管理员可写登录/超管
POST/api/theme/reset清除自定义覆盖，回到系统自动判定登录
GET/api/user/info当前会话用户/版本/角色信息登录

§8 · 系统规则（会话/安全/权限/审计/数据）

  • 会话：连续 30 分钟无操作自动登出，5 分钟无输入进入锁屏（MTSCOS.lock()）。
  • 安全：账密经 scrypt + salt 存储，登录失败 5 次触发 10 分钟冷却；全程 HTTPS/TLS。
  • 权限：角色分为 学生 / 家长 / 教师 / 校管理员 / 超管 五阶，细粒度由 users.super_admin_approved 与 role 联合判定。
  • 审计：登录/登出、主题切换、敏感数据写入均进入审计表可追溯。
  • 数据：个人数据支持导出（JSON）与删除（GDPR 合规），在 /settings → 数据管理 操作。

§9 · 常见问题 FAQ

  • 为什么我进设置看不到"主题与公祭日"？ 你是普通账号（非管理员）；按 §3/§4，非管理员无此入口。
  • 公祭日主题我能不能手动关掉？ 不能。按 §3，任何非超管账号均无法手动切换公祭日与标准主题。
  • 为什么侧边栏比例有时 2:8 有时 1:9？ 你点了页眉的「侧边栏」按钮进入图标模式（§1），再点一次就回去。
  • 忘记密码怎么办？ 前往 /auth/forgot_password 用注册邮箱/手机找回，或联系校管理员重置。
  • 能导出我的学习数据吗？ 可以，/settings → 数据管理 → 导出 JSON 或发起删除申请（GDPR 合规）。
