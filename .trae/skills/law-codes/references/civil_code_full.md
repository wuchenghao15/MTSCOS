# 中华人民共和国民法典（1260 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 通过时间 | 2020年5月28日（第十三届全国人大第三次会议） |
| 生效时间 | 2021年1月1日 |
| 条文总数 | 1,260 条 |
| 编/分编/章 | 7编 + 3分编 + 72章 |
| 取代 | 民法通则/物权法/合同法/担保法/婚姻法/收养法/继承法/侵权责任法 |

## 法典结构

```
第一编 总则（204条） — 民事活动通用规则
  第1章 基本规定  第2章 自然人  第3章 法人  第4章 非法人组织
  第5章 民事权利  第6章 民事法律行为  第7章 代理
  第8章 民事责任  第9章 诉讼时效  第10章 期间计算

  结婚/家庭关系/离婚/收养

```

## 第一编 总则（204条）

### 核心原则（第3-9条）

| 原则 | 条文 | 含义 |
|------|------|------|
| 权利受保护 | 第3条 | 人身权、财产权等合法权益不受侵犯 |
| 平等原则 | 第4条 | 民事主体法律地位一律平等 |
| 自愿原则 | 第5条 | 按照自己意思设立/变更/终止民事法律关系 |
| 公平原则 | 第6条 | 合理确定各方权利义务 |
| 诚信原则 | 第7条 | 秉持诚实、恪守承诺 |
| 守法与公序良俗 | 第8条 | 不得违反法律，不得违背公序良俗 |
| 绿色原则 | 第9条 | 节约资源、保护生态环境 |

### 自然人（第13-56条）

```
民事权利能力：出生→死亡（第13条）
民事行为能力：
  完全：18周岁以上；或16+周岁以自己劳动为主要收入（第18条）
  限制：8周岁以上未成年人；不能完全辨认自己行为的成年人（第19条）
  无：不满8周岁；完全不能辨认自己行为的成年人（第20条）
监护：
  父母是未成年子女当然监护人（第27条）
  无民事行为能力成年人监护顺序（第28条）：
    配偶 → 父母/子女 → 其他近亲属 → 其他有监护能力人
  监护人职责（第34条）：保护人身权利/管理财产/代理活动/教育监督
宣告失踪（第40条）：
  条件：自然人下落不明满2年
  程序：利害关系人向法院申请
  后果：为其设立财产代管人
宣告死亡（第46条）：
  条件：下落不明满4年；或意外事件满2年
  程序：利害关系人申请；公告期1年/特别程序3个月
个体工商户/农村承包经营户（第54-56条）：
  债务：个人经营→个人财产；家庭经营→家庭财产
```

### 法人（第57-101条）

```
营利法人（第76条）：有限责任公司/股份有限公司
  内部：股东会/股东大会 + 董事会/执行董事 + 监事会/监事
  利润分配：按实缴出资比例/持股比例
非营利法人（第87条）：社会团体/基金会/社会服务机构
特别法人（第96条）：机关法人/农村集体经济组织法人/基层群众性自治组织法人
法人解散情形（第69条）：
  ① 章程规定存续届满或解散事由出现
  ② 权力机构决议解散
  ③ 合并/分立需要
  ④ 吊销/责令关闭/被撤销
  ⑤ 其他
法人清算：由清算组执行；清算期间不得开展与清算无关的经营活动
```

### 民事法律行为（第133-160条）

```
生效条件（第143条）：
  ① 行为人具有相应民事行为能力
  ② 意思表示真实
  ③ 不违反法律/行政法规强制性规定，不违背公序良俗
无效情形：
  无民事行为能力人实施 → 无效（第144条）
  虚假意思表示 → 无效（第146条）
  恶意串通损害他人合法权益 → 无效（第154条）
  违反法律/行政法规强制性规定 → 无效（第153条但强制性规定不导致行为无效除外）
  违背公序良俗 → 无效（第153条）
可撤销情形：
  重大误解（第147条，自知道或应知90日内请求撤销；自行为成立5年内未行使消灭）
  欺诈（第148/149条，受欺诈方自知道90日内请求）
  胁迫（第150条，受胁迫方自胁迫终止1年内请求）
  显失公平（第151条，受害方自知道90日内请求）
撤销权消灭（第152条）：
  ① 自知道应知撤销事由起1年内未行使
  ② 重大误解90日内未行使
  ③ 当事人明确表示/以自己行为放弃
  ④ 自行为成立起5年内未行使
```

### 代理（第161-175条）

```
委托代理授权（第165条）：书面/口头均可
无权代理（第171条）：
  行为人无代理权/超越代理权/代理权终止后
  被代理人追认 → 有效；不追认 → 无效
  善意相对人可撤销（被代理人追认前）
表见代理（第172条）：
  相对人有理由相信行为人有代理权 → 代理行为有效
  要件：客观上有使相对人相信行为人具有代理权的事实/理由 + 相对人善意无过失
```

### 民事责任（第176-187条）

```
承担方式（第179条，可单独/合并适用）：
  ① 停止侵害  ② 排除妨碍  ③ 消除危险  ④ 返还财产
  ⑤ 恢复原状  ⑥ 修理/重作/更换  ⑦ 继续履行
  ⑧ 赔偿损失  ⑨ 支付违约金  ⑩ 消除影响/恢复名誉  ⑪ 赔礼道歉
不可抗力免责（第180条）：不能预见/不能避免/不能克服的客观情况
正当防卫（第181条）：造成损害的，不承担民事责任（超过必要限度的部分除外）
紧急避险（第182条）：由引起险情发生的人承担责任；自然原因引起的，受益人给予补偿
见义勇为（第183条）：因保护他人民事权益使自己受到损害的，由侵权人承担；侵权人逃逸/无力承担的，受益人给予适当补偿
```

### 诉讼时效（第188-199条）⭐高频⭐

```
普通时效：3年（自知道/应当知道权利受损害及义务人之日起）（第188条）
最长时效：20年（自权利受损害之日起）；有特殊情况的法院可延长（第188条）
时效起算特殊规定：
  分期履行：最后一期履行期限届满之日起（第189条）
  无民事/限制民事行为能力人：法定代理人知道/应当知道之日起（第190条）
  未成年人遭受性侵害：年满18周岁之日起（第191条）❌重点❌
不适用诉讼时效的请求权（第196条）：
  ① 请求停止侵害/排除妨碍/消除危险
  ② 不动产物权和登记的动产物权的权利人请求返还财产
  ③ 请求支付抚养费/赡养费/扶养费
  ④ 依法不适用诉讼时效的其他请求权
时效中止（第194条，最后6个月内）：
  不可抗力；无民事/限制民事行为能力人无法定代理人；继承开始后未确定继承人/遗产管理人；权利人被控制无法主张权利
时效中断（第195条）：
  权利人主张权利；义务人同意履行；起诉/仲裁/申请强制执行；其他
  → 中断后时效重新计算
```

## 第二编 物权（258条）

### 物权通则

```
物权法定（第116条）：种类和内容由法律规定
公示原则：
  不动产：登记（第209条，自登记时设立）
  动产：交付（第224条，自交付时转移所有权）
  例外（第209条但书）：依法属于国家所有的自然资源，所有权可不登记
不动产登记例外：
  宅基地使用权/土地承包经营权/地役权等部分用益物权登记对抗主义
动产交付方式（第226-228条）：
  现实交付：直接交付标的物
  简易交付：受让人已占有，合同生效即视为交付
  指示交付：第三人占有，转让人将返还请求权让与受让人
  占有改定：出让人继续占有，约定生效即视为交付
```

### 所有权

```
国家所有权（第246-254条）：
  矿藏/水流/海域/城市土地/无线电频谱资源/国防资产
  森林/山岭/草原/荒地/滩涂等自然资源可以属于国家所有
集体所有权：农村集体所有土地（第260条）
私人所有权：合法收入/房屋/生活用品/生产工具等（第266条）
业主建筑物区分所有权（第271-287条）：
  专有部分：享有所有权
  共有部分：享有共有和共同管理权利
  车位/车库（第275条）：规划内车位车库归属由当事人通过出售/附赠/出租等方式约定
  业主委员会：由业主选举产生，执行业主大会决定事项
共有（第297-310条）：
  按份共有：按份额享有所有权
  共同共有：共同享有所有权（如夫妻共同财产）
  处分共有财产：按份共有→占份额2/3以上共有人同意（另有约定除外）；共同共有→全体同意
善意取得（第311条）【★★★高频】：
  无处分权人将不动产/动产转让给受让人，符合下列情形的受让人取得所有权：
  ① 受让人受让时善意（不知道/不应知道出让人无处分权）
  ② 以合理价格转让
  ③ 依法应当登记的已登记；不需登记的已交付
  善意取得后原权利人有权向无处分权人请求赔偿损失（第312条）
遗失物（第314-318条）：
  遗失物通过转让被他人占有的，权利人有权自知道/应当知道受让人之日起2年内向受让人请求返还
```

### 用益物权

```
土地承包经营权（第330-343条）：
  期限：耕地30年/草地30-50年/林地30-70年（第332条）
  设立：自土地承包经营权合同生效时设立（登记对抗）
建设用地使用权（第344-361条）：
  期限：居住70年/工业50年/教育科技文化体育卫生50年/商业旅游娱乐40年/综合或其他50年
  设立方式：出让（有偿）/划拨（无偿）
  到期续期（第359条）：住宅期满自动续期；非住宅申请批准后续期
宅基地使用权（第362-365条）：
  仅限本集体经济组织成员享有
  不得抵押；取得/行使/转让适用土地管理法律和国家规定
居住权（第366-371条）【★2021年新增物权】：
  定义：以居住为目的，对他人住宅享有占有/使用的用益物权
  设立：自登记时设立
  性质：具有人身专属性，不得转让/继承；期限届满/居住权人死亡的消灭
地役权（第372-385条）：
  为自己不动产便利而使用他人不动产的权利
  从属性：随需役地转让而转让
```

### 担保物权 ⭐⭐

```
抵押权（第394-420条）：
  定义：不转移占有，债务人不履行到期债务时债权人有权优先受偿
  禁止抵押（第399条）：
    ① 土地所有权  ② 宅基地/自留地/自留山等集体所有土地使用权（法律规定可抵押除外）
    ③ 公益设施（学校/幼儿园/医院等）
    ④ 所有权/使用权不明/有争议的财产
    ⑤ 依法被查封/扣押/监管的财产
  浮动抵押（第396条）：
    企业/个体工商户/农业生产经营者将现有及将有的生产设备/原材料/半成品/产品抵押
    登记对抗，抵押财产确定情形（第411条）：债务履行期届满/宣告破产/约定情形/严重影响债权实现
  最高额抵押（第420条）：
    一定期间内将要连续发生的债权，最高债权额限度内优先受偿
  抵押权实现方式（第410条）：
    协议折价/拍卖/变卖 → 协议不成向法院申请
    注意：民法典可直接向法院申请实现担保物权，无需起诉（简化程序）
质权（第425-446条）：
  动产质权：自出质人交付质押财产时设立（第429条）
  权利质权：
    以汇票/本票/支票/债券/存款单/仓单/提单出质 → 交付即设立
    以股权/基金份额出质 → 登记设立
    以知识产权中的财产权出质 → 登记设立
    以应收账款出质 → 登记设立
留置权（第447-457条）：
  定义：合法占有债务人动产，债务人不履行到期债务，债权人有权留置
  要件（第448条）：
    ① 债权人合法占有债务人动产
    ② 债权与债权人占有的财产属于同一法律关系（企业间留置除外）
    ③ 债务人不履行到期债务
担保物权清偿顺序（第414条）：⭐
  ① 已登记的抵押权/质权 → 按登记时间先后
  ② 已登记的优先于未登记的
  ③ 未登记的 → 按债权比例
  ④ 留置权人优先于抵押权人受偿（第456条）
```

## 第三编 合同（526条）

### 合同通则

```
订立形式（第469条）：
  书面/口头/其他形式
  书面形式：信件/电报/电传/传真/电子数据交换/电子邮件等可有形表现所载内容的形式
要约（第472条）：
  希望与他人订立合同的意思表示
  要件：内容具体确定 + 表明经受要约人承诺即受意思表示约束
  生效：到达受要约人时生效
承诺（第479条）：
  受要约人同意要约的意思表示
  方式：通知方式；或根据交易习惯/要约表明可通过行为作出承诺
合同成立时间（第483条）：承诺生效时成立
合同成立地点（第492条）：承诺生效地点（例外：书面合同双方签字盖章地点）
合同生效时间（第502条）⭐⭐：
  依法成立的合同自成立时生效（第1款，民法典核心变化）
  例外：法律/行政法规规定需批准/登记的，自批准/登记时生效（第2款）
效力待定（第503-505条）：
  限制民事行为能力人/无权代理人签订的合同
  善意相对人可撤销（追认前）
附条件/附期限合同（第158-160条）：
  生效条件成就/期限届至时生效；解除条件成就/期限届满时失效
```

### 违约责任（第577-585条）⭐⭐⭐

```
继续履行（第577条）：当事人一方不履行/履行不符合约定的，对方可请求继续履行
损失赔偿（第584条）：
  损失额=违约造成的损失（包括合同履行后可获得的利益）
  但不得超过违约方订立合同时能预见/应预见到的损失（可预见性规则）
违约金（第585条）：
  可约定一方违约时应支付的违约金数额/损失赔偿计算方法
  约定违约金低于损失 → 法院/仲裁机构可按当事人请求予以增加
  约定违约金过分高于损失（一般超过损失30%）→ 可予以适当减少
定金（第586-587条）：
  不得超过主合同标的额20%，超过部分不产生定金效力
  给付定金一方违约：无权请求返还
  收受定金一方违约：应当双倍返还
  既约定违约金又约定定金（第588条）：对方可选择适用违约金或定金条款（不能并用）
不可抗力免责（第590条）：
  不能预见/不能避免/不能克服的客观情况
  部分或全部免除责任；迟延履行期间发生不可抗力不免除
减损义务（第591条）：
  一方违约后，对方应采取适当措施防止损失扩大；未采取的不得就扩大损失请求赔偿
双方违约（第592条）：各自承担相应责任（按过错程度）
```

### 典型合同（19种）⭐核心⭐

| 合同类型 | 条文 | 关键规则 |
|----------|------|----------|
| **买卖合同** | 第595-647条 | 标的物所有权自交付时转移（动产）；风险按交付转移（第604条）；出卖人瑕疵担保责任 |
| **借款合同** | 第667-680条 | 自然人之间借款自贷款人提供借款时成立（第679条）；禁止高利放贷，利率不得违反国家规定 |
| **租赁合同** | 第703-734条 | 期限≤20年（超过部分无效，第705条）；买卖不破租赁（第725条）；承租人优先购买权（第726条） |
| **融资租赁合同** | 第735-760条 | 出租人享有租赁物所有权；承租人破产的，租赁物不属于破产财产 |
| **保理合同** | 第761-769条 | 新增合同类型；有追索权/无追索权两种 |
| **承揽合同** | 第770-787条 | 定作人可随时解除合同（造成承揽人损失的应赔偿） |
| **建设工程合同** | 第788-808条 | 承包人优先受偿权（18个月内行使，第807条）；禁止违法分包/转包 |
| **运输合同** | 第809-824条 | 承运人对运输过程中货物损毁/灭失承担赔偿责任（不可抗力除外）；客运旅客伤亡承运人负责 |
| **技术合同** | 第843-850条 | 技术开发/转让/咨询/服务；职务技术成果归单位 |
| **保管合同** | 第888-903条 | 一般无偿；有偿保管人对保管物损毁灭失承担责任 |
| **仓储合同** | 第904-918条 | 仓单可背书转让 |
| **委托合同** | 第919-930条 | 委托人和受托人均可随时解除委托合同 |
| **物业服务合同** | 第937-950条 | 业主缴费义务；物业服务人公开作出的服务承诺为合同组成部分；新增 |
| **行纪合同** | 第951-960条 | 行纪人以自己名义为委托人从事贸易活动 |
| **中介合同** | 第961-966条 | 新增（居间合同→中介合同）；未促成合同成立的不得请求报酬 |
| **合伙合同** | 第967-978条 | 新增；合伙人共享收益共担风险 |

## 第四编 人格权（62条）⭐

```
生命权/身体权/健康权（第1002-1011条）：
  生命权：自然人享有生命安全/生命利益受保护的权利
  身体权：身体完整/行动自由
  健康权：身心健康
  人体捐献（第1006条）：完全民事行为能力人自主决定；应当采用书面形式/订立遗嘱
  禁止侵害（第1010条）：任何组织/个人不得以行为/文字/图像/电子信息等方式实施性骚扰
姓名权/名称权（第1012-1024条）：
  自然人享有姓名权，有权依法决定/使用/变更自己的姓名
  法人/非法人组织享有名称权
肖像权（第1018-1023条）：⭐2021年重大变化⭐
  未经同意不得制作/使用/公开他人肖像
  法定许可（第1020条，无需同意）：
    ① 为个人学习/艺术鉴赏/课堂教学/科学研究使用
    ② 新闻报道/舆论监督
    ③ 国家机关履行公务
    ④ 肖像权人自愿公开/合法公开的，在公开范围内使用
    ⑤ 公共场所表演/公开活动使用
    ⑥ 其他合理使用
名誉权/荣誉权（第1024-1031条）：
  任何组织/个人不得以侮辱/诽谤方式侵害他人名誉权
  民事主体享有荣誉权
  媒体报道失实：受害人有权请求更正/删除/道歉（第1028条）
隐私权/个人信息保护（第1032-1039条）⭐⭐⭐高频：
  自然人享有隐私权，任何组织/个人不得以刺探/侵扰/泄露/公开等方式侵害
  侵害隐私权行为（第1033条）：电话/短信/邮件/即时通信工具骚扰/窃听/偷拍/人肉搜索/泄露隐私材料
  个人信息处理（第1035-1039条）：
    遵循合法/正当/必要原则
    自然人同意；公开个人信息处理；处理个人自行公开/合法公开；维护公共利益/自然人合法权益等情形可处理（无需单独同意）
    敏感个人信息（生物识别/宗教信仰/医疗健康/金融账户/行踪轨迹等）需取得单独同意
    注意：《个人信息保护法》2021年11月1日施行，优先于民法典适用
```

## 第五编 婚姻家庭（79条）

```
结婚条件（第1046-1048条）：
  ① 双方完全自愿  ② 男方≥22周岁，女方≥20周岁  ③ 双方均无配偶  ④ 非直系血亲/三代以内旁系血亲
禁止结婚（第1048条）：直系血亲和三代以内旁系血亲
婚姻无效（第1051条）：
  ① 重婚  ② 有禁止结婚的亲属关系  ③ 未到法定婚龄
可撤销婚姻（第1052-1053条）：
  胁迫结婚：受胁迫方可向法院请求撤销（自胁迫行为终止之日起1年内）
  一方隐瞒重大疾病：另一方知晓后可请求撤销（自知道/应当知道之日起1年内）
夫妻财产（第1062-1063条）⭐⭐：
  共同财产（第1062条，婚姻存续期间所得）：
    工资/奖金/劳务报酬；生产/经营/投资收益；知识产权收益
    继承/赠与所得（遗嘱/赠与合同确定只归一方除外）；其他
  个人财产（第1063条）：
    婚前财产；一方因人身损害获得的赔偿/补偿
    遗嘱/赠与合同确定只归一方的财产；一方专用生活用品；其他
  夫妻财产约定（第1065条）：可约定全部/部分归共同/个人所有（书面形式，对双方有约束力）
离婚（第1076-1092条）⭐⭐⭐：
  协议离婚（第1076-1077条）：
    双方自愿离婚，签离婚协议（自愿离婚意思+子女抚养+财产债务处理）
    亲自到婚姻登记机关申请 → **30天冷静期** → 双方亲自申请发给离婚证（冷静期内可撤回）
  诉讼离婚（第1079条）：
    向法院提起；法定离婚情形（一次判离）：
    ① 重婚/与他人同居  ② 家暴/虐待/遗弃  ③ 赌博吸毒屡教不改
    ④ 感情不和分居满2年  ⑤ 其他导致夫妻感情破裂情形
    一方宣告失踪，另一方起诉离婚 → 准予离婚
  子女抚养（第1084条）：
    不满2周岁 → 母亲直接抚养
    2-8周岁 → 按最有利于未成年子女原则判决
    8周岁以上 → 应尊重其真实意愿
  抚养费（第1085条）：
    不直接抚养方负担部分/全部抚养费
    负担期限：一般至子女18周岁；年满16周岁以自己劳动为主要收入来源可停止
    标准：月总收入20-30%；负担2个以上不超50%
  离婚损害赔偿（第1091条）⭐⭐：
    重婚/与他人同居/实施家暴/虐待遗弃家庭成员/其他重大过错 → 无过错方有权请求
  家务劳动补偿（第1088条）：
    夫妻一方因抚育子女/照料老年人/协助另一方工作等负担较多义务的，离婚时有权向另一方请求补偿
```

## 第六编 继承（45条）

```
法定继承（第1123-1132条）：
  继承顺序（第1127条）：
    第一顺序：配偶/子女/父母
    第二顺序：兄弟姐妹/祖父母/外祖父母
    继承开始后由第一顺序继承，第二顺序不继承；无第一顺序的由第二顺序继承
  代位继承（第1128条）⭐2021扩大：
    被继承人的子女先于被继承人死亡 → 由被继承人子女的直系晚辈血亲代位继承
    **新增**：被继承人的兄弟姐妹先于被继承人死亡 → 由被继承人兄弟姐妹的子女代位继承
  丧偶儿媳/女婿（第1129条）：
    对公婆/岳父母尽了主要赡养义务的，作为第一顺序继承人
  继承份额（第1130条）：
    同一顺序继承人继承份额一般均等
    对生活困难/缺乏劳动能力的继承人应照顾
    对被继承人尽了主要扶养义务/与被继承人共同生活的继承人可多分
    扶养能力条件的继承人不尽扶养义务 → 应当不分或少分
遗嘱继承（第1133-1140条）：
  遗嘱形式：
    自书遗嘱：遗嘱人亲笔书写，签名，注明年月日
    代书遗嘱：2个以上见证人在场见证，由其中一人代书，遗嘱人代书人其他见证人签名
    打印遗嘱：2个以上见证人在场见证，遗嘱人和见证人应在遗嘱每一页签名
    录音录像遗嘱：2个以上见证人在场见证，录音录像中应记录姓名/肖像及年月日
    口头遗嘱：危急情况下，2个以上见证人在场见证；危急情况消除后遗嘱人能以其他形式立遗嘱的，所立口头遗嘱无效
    公证遗嘱：经公证机构办理
  遗嘱见证人的限制（第1140条）：
    无民事/限制民事行为能力人；继承人/受遗赠人；与继承人/受遗赠人有利害关系的人 → 不能作为见证人
  遗嘱撤回/变更（第1142条）⭐民法典重大变化⭐：
    遗嘱人可以撤回/变更自己所立的遗嘱
    立有数份遗嘱，内容相抵触的，**以最后的遗嘱为准**
    → 民法典废除了公证遗嘱的优先效力！
遗产处理（第1151-1163条）：
  继承人放弃继承：应当在遗产处理前以书面形式作出；未表示视为接受继承
  清偿顺序（第1161条）：
    税款 > 有担保的债权 > 普通债权（不足清偿的按比例）
  执行遗赠不得妨碍清偿遗赠人依法应当缴纳的税款和债务（第1162条）
  保留必要份额（第1141/1155条）：
    遗嘱应保留缺乏劳动能力又没有生活来源的继承人的必要份额
    遗产分割时应保留胎儿的继承份额；胎儿娩出时是死体的，保留份额按法定继承办理
```

## 第七编 侵权责任（97条）

```
过错责任原则（第1165条）：行为人因过错侵害他人民事权益造成损害的，应承担侵权责任
无过错责任原则（第1166条）：法律规定不论行为人有无过错，损害即应承担侵权责任
过错推定（法律规定行为人不能证明自己无过错的应承担责任）：
  - 教育机构（无民事行为能力人受害，第1199条）
  - 医疗机构（违反诊疗规范/隐匿销毁病历/非法获取病历/过错推定，第1222条）
  - 动物园动物致害（第1248条）
  - 建筑物/构筑物脱落坠落（第1253条）
  - 堆放物倒塌（第1255条）
  - 林木折断（第1257条）
  - 地下设施（第1258条）
损害赔偿范围（第1179-1187条）⭐：
  人身损害：医疗费/护理费/交通费/营养费/住院伙食补助费/误工费
  残疾：加辅助器具费/残疾赔偿金；被扶养人生活费计入残疾赔偿金
  死亡：加丧葬费/死亡赔偿金；被扶养人生活费计入死亡赔偿金
  财产损失：按损失发生时市场价格或其他合理方式计算
精神损害赔偿（第1183条）⭐⭐：
  侵害自然人人身权益造成严重精神损害 → 有权请求精神损害赔偿
  故意/重大过失侵害自然人具有人身意义的特定物造成严重精神损害 → 有权请求
责任主体特殊规定：
  监护人（第1188条）：无民事/限制民事行为能力人造成他人损害 → 监护人承担
  用人单位（第1191条）：工作人员执行工作任务致损 → 用人单位承担
  劳务派遣（第1191条第2款）：接受派遣单位负责；派遣单位有过错承担相应责任
  个人劳务（第1192条）：提供劳务一方因劳务致损 → 接受劳务一方承担
  网络侵权（第1194-1197条）⭐⭐⭐高频：
    网络用户/服务提供者利用网络侵害他人民事权益 → 应承担侵权责任
    通知-删除规则（第1195条）：
      被侵权人通知网络服务提供者采取删除/屏蔽/断开等必要措施
      网络服务提供者应及时审查；未及时采取 → 对损害扩大部分与网络用户承担连带责任
    红旗规则（第1197条）：
      网络服务提供者知道/应知网络用户利用其网络服务侵害他人民事权益，未采取必要措施 → 与网络用户承担连带责任
  产品责任（第1202-1207条）⭐：
    生产者（第1202条）：因产品存在缺陷造成他人损害的 → 生产者应承担侵权责任（严格责任）
    销售者（第1203条）：受害人可向生产者/销售者请求赔偿；销售者赔偿后可向生产者追偿（生产者缺陷）
    明知产品存在缺陷仍然生产销售（第1207条）：造成他人死亡/健康严重损害 → 有权请求相应惩罚性赔偿
  医疗损害（第1218-1228条）：
    医疗机构对诊疗活动中造成的患者损害承担赔偿责任（过错责任为原则，第1222条规定5种过错推定）
    医务人员未尽到告知义务（侵害患者知情同意权）造成损害 → 医疗机构承担责任
  机动车交通事故（第1208条）：依照道路交通安全法和本法规定
  动物致害（第1245条）：饲养动物造成他人损害的，动物饲养人/管理人承担侵权责任（能证明损害是被侵权人故意造成的可减轻）
  建筑物/构筑物/抛掷物 ⭐⭐⭐高频新增：
    脱落坠落（第1253条）：所有人/管理人/使用人不能证明无过错的承担责任
    高空抛物（第1254条）：
      从建筑物/构筑物中抛掷物品/从建筑物上坠落物品造成他人损害 → 侵权人依法承担责任
      经调查难以确定具体侵权人的 → 除能够证明自己不是侵权人的外，由可能加害的建筑物使用人给予补偿
      补偿后查明侵权人的，有权向侵权人追偿
      物业服务企业等建筑物管理人应采取必要安全保障措施，未采取的应承担相应责任
```
