# 中华人民共和国行政处罚法（86 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 现行版本 | 2021年7月15日修正 |
| 条文总数 | 86 条 |
| 定位 | 规范行政处罚的设定和实施，保障和监督行政机关有效实施行政管理 |
| 核心原则 | 处罚法定/公正公开/处罚与教育相结合/保障陈述申辩权利 |

---

## 核心条文速查

### 处罚种类（第9条）⭐⭐⭐

```
警告/通报批评
罚款/没收违法所得/没收非法财物
暂扣许可证件/降低资质等级/吊销许可证件
限制开展生产经营活动/责令停产停业/责令关闭/限制从业
行政拘留（1-15日，合并执行不超过20日）
法律/行政法规规定的其他行政处罚
新增（2021修正）：通报批评/限制开展生产经营活动/责令关闭/限制从业
```

### 处罚设定权限（第10-16条）

```
法律：可设定任何种类的行政处罚（含行政拘留）
行政法规：可设定除限制人身自由以外的行政处罚
地方性法规：可设定除限制人身自由/吊销营业执照以外的行政处罚
部门规章：可设定警告/通报批评/罚款（限额由国务院规定）
地方政府规章：可设定警告/通报批评/罚款（限额由省级人大常委会规定）
规范性文件：不得设定行政处罚
```

### 管辖（第22-27条）⭐

```
一般管辖（第22条）：
  行政处罚由违法行为发生地的行政机关管辖
  违法行为发生地包括：实施地/经过地/结果发生地
管辖权争议（第25条）：
  两个以上行政机关都有管辖权的，由最先立案的行政机关管辖
  对管辖权发生争议的，协商解决；协商不成的，报请共同上一级行政机关指定管辖
移送管辖（第27条）：
  行政机关发现违法行为不属于自己管辖的，应当及时将案件移送有管辖权的行政机关
  构成犯罪的，应当将案件移送司法机关追究刑事责任，不得以行政处罚代替刑事处罚
行政处罚实施机关：
  国务院/省级人民政府可决定一个行政机关行使有关行政机关的行政处罚权（综合行政执法）
```

### 处罚时效（第36条）⭐⭐⭐高频⭐⭐⭐

```
追诉时效（第36条）：
  违法行为发生后2年内未被发现的，不再给予行政处罚
  起算点：从违法行为发生之日起计算
  连续/继续行为：从行为终了之日起计算
  例外：法律另有规定的除外（如税收征管法5年/治安管理处罚法6个月）
```

### 处罚程序（第33-57条）⭐⭐

```
查明事实（第33条）：
  公民/法人/其他组织违反行政管理秩序的行为，应当给予行政处罚的，行政机关必须查明事实；违法事实不清/证据不足的，不得给予行政处罚
告知权利（第34条）：
  行政机关在作出行政处罚决定之前，应当告知当事人拟作出的行政处罚内容及事实/理由/依据，并告知当事人依法享有的陈述/申辩/要求听证等权利
  当事人有权陈述和申辩，行政机关必须充分听取；当事人提出事实/理由/证据成立的，行政机关应当采纳
  行政机关不得因当事人申辩而加重处罚

简易程序（第51条）⭐⭐：
  适用条件：
    ① 违法事实确凿并有法定依据
    ② 对公民处以200元以下/对法人/其他组织处以3000元以下罚款或者警告的行政处罚
    ③ 可以当场作出行政处罚决定
  程序：执法人员出示执法身份证件 → 填写行政处罚决定书 → 当场交付当事人
  执法人员应当在作出决定后24小时内向行政机关备案

普通程序（第54条）：
  立案 → 调查取证（2人以上，出示执法证件）→ 审查 → 决定前告知 → 作出决定 → 送达
  行政机关负责人应当对调查结果进行审查；对情节复杂/重大违法行为给予较重行政处罚的，应当由行政机关负责人集体讨论决定

听证程序（第63条）⭐⭐⭐：
  适用情形：
    ① 较大数额罚款
    ② 没收较大数额违法所得/没收较大价值非法财物
    ③ 降低资质等级/吊销许可证件
    ④ 责令停产停业/责令关闭/限制从业
    ⑤ 其他较重的行政处罚
    ⑥ 法律/法规/规章规定的其他情形
  程序：
    当事人要求听证 → 应当在行政机关告知后5日内提出（法定情形当事人未申请不启动）
    行政机关应当在举行听证7日前通知当事人时间/地点
    除涉及国家秘密/商业秘密/个人隐私外，听证公开举行
    听证由行政机关指定的非本案调查人员主持；当事人认为主持人与本案有利害关系的，有权申请回避
    听证结束后，行政机关根据听证笔录作出决定
  注意：当事人不承担行政机关组织听证的费用

一事不再罚（第29条）⭐⭐⭐高频⭐⭐⭐：
  对当事人的同一个违法行为，不得给予两次以上罚款的行政处罚
  同一个违法行为违反多个法律规范应当给予罚款处罚的，按照罚款数额高的规定处罚
  注意：一事不再罚仅适用于"罚款"，其他处罚种类可以叠加（如罚款+吊销执照）

从轻/减轻/不予处罚（第30-33条）⭐⭐：
  不予处罚（第33条）：
    ① 不满14周岁的未成年人有违法行为的
    ② 精神病人/智力残疾人在不能辨认/不能控制自己行为时有违法行为的
    ③ 违法行为轻微并及时改正，没有造成危害后果的
    ④ 初次违法且危害后果轻微并及时改正的（可不予处罚）
    ⑤ 当事人有证据足以证明没有主观过错的（法律/行政法规另有规定除外）
  从轻/减轻处罚（第32条）：
    ① 已满14周岁不满18周岁的未成年人有违法行为的
    ② 主动消除/减轻违法行为危害后果的
    ③ 受他人胁迫/诱骗实施违法行为的
    ④ 主动供述行政机关尚未掌握的违法行为的
    ⑤ 配合行政机关查处违法行为有立功表现的
    ⑥ 其他法定情形
  从重处罚（第50条）：
    ① 胁迫/诱骗他人实施违法行为的
    ② 阻碍/抗拒执法人员调查取证的
    ③ 违法所得较多的
    ④ 其他法定情形
```

### 行政处罚决定书（第59条）⭐

```
应当载明：
  当事人姓名/名称/地址；违法行为事实/证据；行政处罚种类/依据/结果；
  行政处罚履行方式/期限；申请行政复议/提起行政诉讼的途径/期限；
  作出行政处罚决定的行政机关名称/作出日期
  加盖作出行政处罚决定的行政机关印章
```

### 执行（第66-83条）⭐

```
自觉履行（第66条）：
  行政处罚决定依法作出后，当事人应当在行政处罚决定书载明的期限内予以履行
  当事人对行政处罚决定不服申请行政复议/提起行政诉讼的，行政处罚不停止执行（法律另有规定除外）

罚款执行：
  作出罚款决定的行政机关应当与收缴罚款的机构分离（罚缴分离）
  当场收缴罚款情形（第68条）：
    ① 依法给予100元以下罚款的
    ② 不当场收缴事后难以执行的
    ③ 在边远/水上/交通不便地区，当事人到指定银行缴纳罚款确有困难，经当事人提出的
  当事人应当自收到行政处罚决定书之日起15日内到指定银行缴纳罚款

逾期不履行（第72条）⭐：
  当事人逾期不履行行政处罚决定的，作出行政处罚决定的行政机关可采取下列措施：
  ① 到期不缴纳罚款的，每日按罚款数额的3%加处罚款（加处罚款总额不得超出罚款数额）
  ② 根据法律规定，将查封/扣押的财物拍卖/依法处理抵缴罚款
  ③ 采取其他行政强制执行方式
  ④ 依照《行政强制法》申请法院强制执行
申请法院强制执行：
  行政机关申请法院强制执行的期限为从法定起诉期限届满之日起3个月内
  法院应当自受理之日起30日内作出是否执行的裁定
```

### 信息公开（第48条）

```
具有一定社会影响的行政处罚决定应当依法公开
公开的行政处罚决定被依法变更/撤销/确认违法/确认无效的，行政机关应当在3日内撤回公开决定并公开说明理由
```

## 高频问题速查

| 问题 | 答案 |
|------|------|
| 处罚时效？ | 2年（从行为发生之日起）；连续行为从终了之日起 |
| 一事不再罚？ | 同一违法行为不得罚两次款；其他处罚种类可叠加 |
| 听证适用情形？ | 较大数额罚款/吊销许可证/责令停产停业/限制从业等 |
| 简易程序适用？ | 事实清楚+公民≤200元/单位≤3000元罚款+警告 |
| 从轻/减轻情形？ | 主动消除危害/受胁迫/立功/未成年等 |
| 强制执行措施？ | 加罚3%日息（不超本金）/拍卖抵缴/申请法院强制执行 |
| 申请法院强制执行期限？ | 起诉期限届满后3个月内 |
| 当事人申辩会加重处罚吗？ | 不会；禁止因申辩加重 |
| 违法行为人跑了怎么办？ | 当事人下落不明/无法直接送达的，可以公告送达 |
| 对处罚不服？ | 行政复议（60日）/行政诉讼（6个月） |

## 配套法规

| 法规 | 核心内容 |
|------|----------|
| 《治安管理处罚法》 | 治安处罚（时效6个月，行政拘留最长20日） |
| 《行政强制法》 | 行政强制（查封/扣押/冻结/强制执行） |
| 《行政复议法》 | 行政复议（复议申请期限60日） |
| 《行政诉讼法》 | 行政诉讼（起诉期限6个月） |
| 《行政许可法》 | 行政许可设定/实施/监督检查 |
