## 二、诈骗罪基本规定（《刑法》第266条）

| 量刑档位 | 金额 | 刑期 | 其他条件 |
|----------|------|------|----------|
| 数额较大 | ≥3000元 | 3年以下有期徒刑、拘役或管制，并处或单处罚金 | — |
| 数额巨大 | ≥3万元 | 3-10年有期徒刑，并处罚金 | — |
| 数额特别巨大 | ≥50万元 | 10年以上有期徒刑或无期徒刑，并处罚金或没收财产 | — |

### 2.1 电信诈骗加重情节（法发〔2016〕32号）

| 情节 | 从轻/从重 | 量刑影响 |
|------|----------|----------|
| 冒充国家机关工作人员 | 从重 | 可提 50% |
| 诈骗救灾、医疗、扶贫等专项款物 | 从重 | 可提 50% |
| 老年人、残疾人、在校学生 | 从重 | 可提 30% |
| 造成被害人自杀、精神失常等严重后果 | 从重 | 可提 50-100% |
| 国际电话卡、境外实施诈骗 | 从重 | 可提 30% |
| 曾因电信诈骗受过行政处罚 | 从重 | 可提 10-20% |
| 全部退赃退赔、取得谅解 | 从轻 | 可减 30-50% |

### 2.2 免予刑事处罚情形（法发〔2021〕22号 §1）

1. **诈骗数额较大**（3000-3万元），全部退赃退赔，且认罪认罚的 → 可免予刑事处罚
2. **诈骗未遂**，情节显著轻微 → 可不定罪
3. 已满14不满16周岁的未成年人参与 → 一般不追究

## 三、共同犯罪认定（法发〔2021〕22号 §2）

### 3.1 主犯认定

| 情形 | 认定 |
|------|------|
| 集团式诈骗中起组织、策划、指挥作用 | 主犯，按集团全部罪行处罚 |
| 明知他人实施诈骗仍提供帮助（如"跑分""洗米"） | 帮助犯，按其参与部分处罚 |

### 3.2 关键：帮信罪 vs 诈骗罪（法释〔2019〕15号 §13）

| 维度 | 帮信罪（刑法287条之二） | 诈骗罪共犯（刑法266条） |
|------|------------------------|------------------------|
| **主观** | 明知他人利用信息网络实施犯罪（可能知道是诈骗，但未事前共谋） | 与诈骗犯罪分子事前通谋，具有共同诈骗故意 |
| **客观** | 提供技术支持或帮助（提供卡、提供技术、提供支付通道） | 直接参与诈骗环节（拨打电话、话术表演、取款等） |
| **刑期** | 3年以下，**单一量刑档** | 最高无期徒刑 |
| **数额要求** | 无数额要求（只要情节严重即可） | 需达到诈骗数额较大（3000元） |
| **竞合** | 同时触犯帮信罪和其他罪，择一重 | — |

**关键区分点**: 如果行为人 **事前与诈骗分子通谋**，或 **明知他人实施诈骗仍持续提供帮助并参与分赃**，按诈骗罪共犯论处；否则按帮信罪。

## 四、帮信罪详解（《刑法》第287条之二）

### 4.1 帮信罪构成要件（法释〔2019〕15号）

```
┌─────────────────────────────────────────────────────┐
│ 帮信罪构成: 明知他人利用信息网络实施犯罪 + 提供支持/帮助 │
│                                                     │
│ 【支持/帮助】包括:                                    │
│   1. 技术支持: 提供互联网接入、服务器托管、网络存储、   │
│               通讯传输等技术支持                       │
│   2. 支付工具: 提供资金支付结算账户（银行卡、支付宝、   │
│               微信收款码）                            │
│   3. 广告推广: 提供广告投放平台、流量推送服务           │
│   4. 其他帮助: 提供 Call Center、剧本、话术等          │
│                                                     │
│ 【情节严重】认定:                                     │
│   • 提供帮助对象超过 3 人                              │
│   • 支付结算金额超过 20 万元                           │
│   • 以投放广告等方式提供资金超过 5 万元                │
│   • 违法所得超过 1 万元                               │
│   • 曾因帮信罪受过刑事处罚/行政处罚，2 年内再犯         │
└─────────────────────────────────────────────────────┘
```

### 4.2 帮信罪"明知"的司法认定（法释〔2019〕15号 §11）

| 认定方法 | 具体情形 |
|----------|----------|
| **综合判断** | 结合行为人的认知能力、既往经历、交易对象、职业背景、获利情况等 |
| **推定明知** | 1. 经监管部门告知后仍实施有关行为<br>2. 接到举报后不履行法定管理职责<br>3. 交易价格或方式明显异常<br>4. 提供专门用于违法犯罪的程序、工具<br>5. 频繁采用隐蔽上网、加密通信、销毁数据等措施 |

### 4.3 帮信罪不认定的情形

1. **中立帮助行为**：纯粹提供网络接入、服务器托管，收取正常服务费，不知对方犯罪
2. **日常经营行为**：便利店卖手机卡、银行开户等，无证据证明明知
3. **情节轻微**：提供 1 张银行卡、单笔小额支付、未获利等

## 五、"断卡行动"相关认定（2022年纪要）

### 5.1 开卡卖卡行为

| 行为 | 认定 | 刑期 |
|------|------|------|
| 出售/出租自己的银行卡、电话卡 | 帮信罪 | 3年以下 |
| 以他人名义办理银行卡再出售 | 妨害信用卡管理罪（刑法177条之一） | 最高10年 |
| 使用虚假身份办理银行卡 | 同上 | 同上 |
| 明知他人用于诈骗仍提供银行卡 | 诈骗罪共犯（事前通谋）或帮信罪 | 视情节 |

### 5.2 "跑分""洗米"行为

| 行为 | 认定 |
|------|------|
| 为诈骗分子提供银行卡用于接收赃款（"跑分"） | 帮信罪 |
| 为诈骗分子转移赃款（"洗米"） | 掩饰、隐瞒犯罪所得罪（刑法312条），最高7年 |
| 明知是诈骗赃款仍取现、转账 | 同上 |

## 六、金额认定（法发〔2021〕22号 §3）

### 6.1 诈骗数额计算

| 情形 | 计算方法 |
|------|----------|
| 既遂 | 被害人实际被骗数额 |
| 未遂 | 诈骗未遂，但数额达到较大以上 + 情节严重 |
| 多次诈骗 | 累计计算，但已处理的不计 |
| 跨币种 | 按实施诈骗当日汇率折算人民币 |
| 境外诈骗 | 数额同样计算，不受地域影响 |

### 6.2 帮信罪数额认定

| 情形 | 认定 |
|------|------|
| 支付结算金额 | 银行流水总额（进+出）|
| 违法所得 | 实际获利数额（卖卡费、分成等） |
| 情节严重 | 支付结算 ≥20万 或 违法所得 ≥1万 |

## 七、管辖问题

| 维度 | 规定（法发〔2016〕32号）|
|------|------------------------|
| **地域管辖** | 1. 犯罪地法院（包括犯罪行为发生地和犯罪结果发生地）<br>2. 网络犯罪的犯罪地包括：网站服务器所在地、网络接入地、网站建立者/管理者所在地、被害人及其财产损失地 |
| **受害人所在地** | 被害人住所地或经常居住地法院可以管辖 |
| **境外诈骗** | 中国公民在境外实施诈骗，或诈骗中国公民，中国法院均有管辖权 |
| **优先管辖** | 多个地区都有管辖权的，**最先立案的机关**管辖；争议则协商或上级指定 |

## 八、《反电信网络诈骗法》配套责任

### 8.1 行政责任

| 违规行为 | 处罚 |
|----------|------|
| 个人出租、出借、出售银行卡/电话卡 | 行政拘留 + 罚款 + 惩戒（5年内禁止新开卡） |
| 单位未尽到反诈义务 | 罚款（10-100万元）+ 负责人处罚 |
| 电信/金融机构未履行核验义务 | 罚款 + 停业整顿 + 吊销许可 |

### 8.2 民事责任

《反电信网络诈骗法》第46条：**造成他人损失的，应当依法承担赔偿责任**。

> 典型案例：银行未尽开户核验义务 → 犯罪分子用虚假身份开卡诈骗 → 银行承担补充赔偿责任

## 九、快速自查清单

### 9.1 个人/企业红线

| 行为 | 风险等级 | 后果 |
|------|----------|------|
| 卖自己的银行卡/电话卡 | 🔴 高危 | 帮信罪 |
| 用个人收款码帮陌生人收付款 | 🔴 高危 | 帮信罪或掩饰隐瞒犯罪所得 |
| 将银行卡借给朋友用（不知用于诈骗） | 🟡 中危 | 可能被冻结，配合调查 |
| 接到陌生电话索要验证码 | 🟢 安全（只要不提供） | 无 |
| **MTSCOS AI 平台涉及的风险**: | | |
| AI 模型生成诈骗话术（未经审核） | 🟡 中危 | 帮信风险 + 网信办处罚 |
| 用户利用平台 API 批量拨打诈骗电话 | 🔴 高危 | 平台可能担责 |
| 平台未尽反诈提醒义务 | 🟡 中危 | 民事赔偿 |

### 9.2 合规要点

1. **"断卡"意识**: 不出售、不出借银行卡/电话卡/收款码
2. **AI 内容审核**: 模型输出需过滤诈骗话术、敏感词、诱导词
3. **用户身份核验**: 涉及转账、提现的用户必须实名认证（KYC）
4. **异常交易监控**: 建立可疑交易识别模型（高频、小额、分散等模式）
5. **教育提醒**: 对老年人、在校学生等易受骗群体定向推送反诈知识
6. **96110 反诈专线**: 接到 96110 来电/短信 = 你可能正在被诈骗！**必须接听！**
