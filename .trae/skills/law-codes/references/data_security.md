# 中华人民共和国数据安全法（60 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 施行时间 | 2021年9月1日 |
| 条文总数 | 60 条 |
| 定位 | 数据安全领域基础性法律 |
| 配套 | 网络安全法/个保法/关键信息基础设施安全保护条例 |

---

## 核心制度

### 数据分类分级（第21条）⭐⭐⭐⭐⭐

```
国家建立数据分类分级保护制度，根据数据在经济社会发展中的重要程度，以及一旦遭到篡改/破坏/泄露/非法获取/非法利用，对国家安全/公共利益/个人/组织合法权益造成的危害程度，对数据实行分类分级保护
数据分类（按领域）：
  工业/农业/水利/金融/交通运输/科技/教育/医疗/卫生/社保/能源/自然资源/环保/民政/公安/司法/统计/气象等
数据分级（按敏感度，第21条）：
  一般数据：对国家安全/公共利益/个人权益造成一般影响
  重要数据：一旦遭到篡改/破坏/泄露/非法获取/非法利用，对国家安全/公共利益/个人权益造成严重影响
  核心数据：一旦遭到篡改/破坏/泄露/非法获取/非法利用，对国家安全/公共利益造成特别严重影响⭐⭐⭐（国家核心秘密）
重要数据目录由各行业主管部门制定并公布
```

### 数据安全审查（第24条）⭐⭐⭐⭐⭐

```
国家建立数据安全审查制度，对影响或者可能影响国家安全的数据处理活动进行国家安全审查
关键信息基础设施运营者和数据处理者向境外提供重要数据，应当依法经过安全评估（网络安全法第37条）
国家网信部门统筹协调有关部门制定数据安全审查相关制度
数据安全审查范围（第24条）：
  ① 重要数据处理活动
  ② 关键信息基础设施运营者向境外提供重要数据
  ③ 数据处理者开展数据处理活动影响或者可能影响国家安全的
  ④ 其他法定情形
审查内容：
  数据处理活动对国家安全/公共利益/个人权益的影响
  数据处理者的安全保障能力
  数据处理活动的合法性/正当性
注意：数据出境安全评估与个人信息保护法第38条衔接
```

### 数据出境（第31条）⭐⭐⭐

```
关键信息基础设施运营者在中华人民共和国境内运营中收集和产生的重要数据的出境安全管理，适用《中华人民共和国网络安全法》的规定
前款规定以外的数据处理者向境外提供重要数据的，由国务院有关主管部门制定出境安全管理办法
未经批准不得向境外提供的情形（第31条）：
  ① 涉及国家秘密的数据
  ② 涉及国家安全和公共利益的数据
  ③ 其他法定不得出境的数据
```

### 数据安全保护义务（第27条）⭐⭐

```
开展数据处理活动应当依照法律/法规的规定，建立健全全流程数据安全管理制度，组织开展数据安全教育培训，采取相应的技术措施和其他必要措施，保障数据安全
应当履行下列义务：
  ① 依照法律/法规的规定建立健全全流程数据安全管理制度
  ② 组织开展数据安全教育培训
  ③ 采取相应的技术措施和其他必要措施保障数据安全
  ④ 加强数据处理活动的风险监测
  ⑤ 数据安全事件发生后应当及时处置并向有关主管部门报告
```

### 数据安全应急处置（第26条）

```
国家建立数据安全应急处置机制
发生数据安全事件时，有关主管部门应当依法启动应急预案，采取相应的应急处置措施，防止危害扩大，消除安全风险，并及时向社会发布与公众有关的警示信息
数据处理者发现数据安全事件的，应当立即采取处置措施，防止危害扩大，并及时向有关主管部门报告
```

### 法律责任（第52-54条）⭐⭐

```
数据处理者违法（第52条）：
  有关主管部门责令改正，给予警告，可以并处五万元以上五十万元以下罚款
  拒不改正或者造成大量数据泄露等严重后果的，处五十万元以上五百万元以下罚款，并责令暂停相关业务/停业整顿/吊销相关业务许可证
  对直接负责的主管人员和其他直接责任人员处一万元以上十万元以下罚款；情节严重的，处十万元以上一百万元以下罚款
  有本法规定的违法所得的，没收违法所得
  构成犯罪的，依法追究刑事责任
窃取/非法获取数据（第52条）：
  窃取/非法获取/非法出售/非法提供数据，尚不构成犯罪的，由有关主管部门没收违法所得，处五日以上十五日以下拘留，处五千元以上五万元以下罚款
```

## 高频问题速查

| 问题 | 答案 |
|------|------|
| 哪些数据是重要数据？ | 按行业由主管部门制定目录（金融/交通/能源/公共服务等各有目录） |
| 核心数据能出境吗？ | 绝对不能！核心数据一旦出境对国家安全有特别严重影响 |
| 企业数据安全自查？ | 应当建立全流程数据安全管理制度，定期开展数据安全风险评估 |
| 数据泄露了怎么办？ | ① 立即处置 ② 按规定向主管部门报告 ③ 向受影响个人告知 ④ 配合调查 |
| 不做数据安全审查？ | 最高500万罚款+吊销证照 |
