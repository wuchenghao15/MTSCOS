# 中华人民共和国消费者权益保护法（63 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 现行版本 | 2013年10月25日修正 |
| 条文总数 | 63 条 |
| 定位 | 保护消费者合法权益，维护社会经济秩序 |
| 配套 | 《产品质量法》《食品安全法》《欺诈消费者行为处罚办法》 |

---

## 核心条文速查

### 消费者权利（第7-15条）⭐

| 权利 | 条文 | 含义 |
|------|------|------|
| 安全保障权 | 第7条 | 购买/使用商品/接受服务时人身/财产安全不受损害 |
| 知情权 | 第8条 | 知悉购买/使用的商品/接受的服务的真实情况 |
| 自主选择权 | 第9条 | 自主选择经营者/商品/服务方式，决定购买/不购买/接受/不接受 |
| 公平交易权 | 第10条 | 有权获得质量保障/价格合理/计量正确等公平交易条件；有权拒绝经营者强制交易 |
| 求偿权 | 第11条 | 因购买/使用商品/接受服务受到人身/财产损害的，享有依法获得赔偿的权利 |
| 结社权 | 第12条 | 有权依法成立维护自身合法权益的社会组织（消费者协会等） |
| 获得知识权 | 第13条 | 获得有关消费/消费者权益保护方面的知识 |
| 受尊重权 | 第14条 | 人格尊严/民族风俗习惯受到尊重；个人信息受到保护 |
| 监督权 | 第15条 | 对商品/服务/消费者权益保护工作进行监督 |

### 经营者义务（第16-29条）⭐

```
质量保证（第18条）：
  经营者应当保证其提供的商品/服务符合保障人身/财产安全的要求
  对可能危及人身/财产安全的商品/服务，应当向消费者作出真实的说明/明确的警示，并说明/标明正确使用商品/接受服务的方法以及防止危害发生的方法

安全隐患处理（第19条）⭐2013新增⭐：
  经营者发现其提供的商品/服务存在缺陷，有危及人身/财产安全危险的：
  ① 应当立即向行政部门报告并告知消费者
  ② 采取停止销售/警示/召回/无害化处理/销毁等措施
  ③ 未采取有效措施的，行政部门可责令经营者采取召回等措施（费用由经营者承担）
  ④ 经营者应承担因缺陷造成的侵权责任（过错推定）

信息真实（第20条）：
  经营者向消费者提供商品/服务信息：
  ① 应当真实/全面，不得作虚假/引人误解的宣传
  ② 应当标明真实名称和标记
  ③ 提供商品/服务应当明码标价
  ④ 应当保证正常使用商品/接受服务的情况下其提供的商品/服务应当具有的质量/性能/用途/有效期限

举证责任倒置（第23条）⭐⭐⭐高频⭐⭐⭐：
  经营者提供的机动车/计算机/电视机/电冰箱/空调/洗衣机/手机等耐用商品/装饰装修等服务，
  消费者自接受商品/服务之日起6个月内发现瑕疵，发生争议的，由经营者承担有关瑕疵的举证责任
  → 消费者只需主张瑕疵存在，经营者需证明自己无责
  注意：仅限于6个月内；仅限于特定商品/服务

格式条款（第26条）⭐⭐⭐：
  经营者在经营活动中使用格式条款的，应当以显著方式提请消费者注意商品/服务的数量/质量/价款/履行期限/履行方式/安全注意事项/风险提示/售后服务/民事责任等与消费者有重大利害关系的内容
  经营者不得以格式条款等方式作出排除/限制消费者权利/减轻/免除经营者责任/加重消费者责任等对消费者不公平/不合理的规定
  格式条款不得含有免除经营者造成消费者人身损害的责任/故意/重大过失造成消费者财产损失的责任
  → 格式条款中的霸王条款无效！

个人信息保护（第29条）⭐：
  经营者收集/使用消费者个人信息，应当遵循合法/正当/必要原则，明示收集/使用信息的目的/方式和范围，并经消费者同意
  经营者应当采取技术措施/其他必要措施确保个人信息安全，防止信息泄露/丢失
  未经消费者同意/请求，/消费者明确表示拒绝的，不得向其发送商业性信息
```

### 退货/更换/修理（三包）（第24-25条）⭐⭐⭐高频⭐⭐⭐

```
7天无理由退货（第25条）⭐⭐⭐⭐⭐：
  适用：经营者采用网络/电视/电话/邮购等方式销售商品
  消费者有权自收到商品之日起7日内退货，且无需说明理由
  退货商品应当完好；经营者应当自收到退回商品之日起7日内返还消费者支付的商品价款
  退回商品的运费由消费者承担（经营者和消费者另有约定的除外）
  **不能7天无理由退货的情形**（第25条第2款）：⭐⭐⭐
    ① 消费者定作的
    ② 鲜活易腐的
    ③ 在线下载/消费者拆封的音像制品/计算机软件等数字化商品
    ④ 交付的报纸/期刊
    ⑤ 其他根据商品性质并经消费者在购买时确认不宜退货的商品
  注意：食品等鲜活易腐商品不能7天无理由！

质量问题退货（第24条）⭐⭐：
  经营者提供的商品/服务不符合质量要求的，消费者可依照国家规定/当事人约定退货/要求经营者履行更换/修理等义务
  无国家规定和当事人约定的，消费者可自收到商品之日起7日内退货
  7日后符合法定解除合同条件的，消费者可及时退货；不符合法定解除合同条件的，可要求经营者履行更换/修理等义务
  依照前款规定退货的，经营者应当承担运输等必要费用

三包义务（第24条）：
  "三包"：包修/包换/包退
  经营者提供的机动车/计算机/电视机/电冰箱/空调/洗衣机等耐用商品/装饰装修等服务：
    经营者应当承担包修/包换/包退责任
    包修期内修理两次，仍不能正常使用的，消费者可凭修理记录和证明，调换同型号同规格商品/退货
    包修费用由经营者承担
```

### 赔偿与欺诈（第49-55条）⭐⭐⭐⭐⭐

```
人身损害赔偿（第49条）：
  经营者提供商品/服务造成消费者人身伤害的，应当赔偿医疗费/护理费/交通费/营养费/住院伙食补助费等为治疗/康复支出的合理费用，以及因误工减少的收入
  造成残疾的，还应当赔偿辅助器具费和残疾赔偿金
  造成死亡的，还应当赔偿丧葬费和死亡赔偿金

精神损害赔偿（第51条）：
  经营者有侮辱诽谤/搜查身体/侵犯人身自由等侵害消费者人身权益的行为，应当承担停止侵害/恢复名誉/消除影响/赔礼道歉等民事责任，并应当赔偿损失
  消费者可主张精神损害赔偿

欺诈行为三倍赔偿（第55条第1款）⭐⭐⭐⭐⭐最高频⭐⭐⭐⭐⭐：
  经营者提供商品/服务有欺诈行为的，应当按照消费者的要求增加赔偿其受到的损失，增加赔偿的金额为消费者购买商品的价款/接受服务的费用的**三倍**
  增加赔偿的金额不足500元的，为500元
  法律另有规定的，依照其规定
  → 即：退一赔三 + 不足500补足500
  欺诈行为定义（欺诈消费者行为处罚办法）：
    ① 在商品中掺杂掺假/以假充真/以次充好/以不合格商品冒充合格商品
    ② 伪造商品产地/伪造/冒用他人的厂名/厂址/篡改生产日期
    ③ 伪造/冒用认证标志等质量标志
    ④ 销售失效/变质商品
    ⑤ 销售侵犯他人注册商标专用权的商品
    ⑥ 销售伪造/冒用的名优标志等质量标志的商品
    ⑦ 以虚假/引人误解的宣传方式误导消费者
    ⑧ 以虚假的商品说明/商品标准/实物样品等方式销售商品
    ⑨ 不以自己的真实名称/标记销售商品
    ⑩ 采取雇佣他人等方式进行欺骗性销售诱导
    ⑪ 作虚假的现场演示和说明
    ⑫ 利用广播/电视/电影/报刊等大众传播媒介对商品作虚假/引人误解的宣传
    ⑬ 骗取消费者预付款
    ⑭ 利用邮购销售骗取价款而不提供/不按照约定条件提供商品
    ⑮ 以虚假的有奖销售/还本销售/体验销售等方式销售商品
    ⑯ 不以真实名称/标记从事提供经营性服务
    ⑰ 从事修理/加工/安装等服务的经营者弄虚作假
    ⑱ 其他欺诈消费者的行为

食品十倍赔偿（《食品安全法》第148条）⭐⭐⭐⭐⭐：
  生产不符合食品安全标准的食品/经营明知是不符合食品安全标准的食品：
    消费者除要求赔偿损失外，还可以向生产者/经营者要求支付价款10倍或者损失3倍的赔偿金
    增加赔偿的金额不足1000元的，为1000元
    但食品的标签/说明书存在不影响食品安全且不会对消费者造成误导的瑕疵的除外
  → 消保法55条（欺诈→三倍）vs 食安法148条（不符合标准→十倍）：
    消费者可选择适用，食安法148条赔偿更高

产品责任（第40-44条）⭐⭐：
  消费者购买/使用商品时合法权益受损：
    → 可向销售者要求赔偿，也可向生产者要求赔偿
  消费者因商品缺陷造成人身/财产损害：
    → 可向销售者要求赔偿，也可向生产者要求赔偿
    → 销售者/生产者赔偿后有权向应当承担责任的一方追偿
  运输者/仓储者等第三人的过错导致产品存在缺陷：
    → 生产者/销售者赔偿后有权向第三人追偿

平台责任（第44条）⭐⭐：
  消费者通过网络交易平台购买商品/接受服务，其合法权益受到损害的：
    → 可向销售者/服务提供者要求赔偿
    → 网络交易平台提供者不能提供销售者/服务提供者真实名称/地址/有效联系方式的，消费者也可以向网络交易平台提供者要求赔偿
    → 网络交易平台提供者作出更有利于消费者承诺的，应当履行承诺
    → 网络交易平台提供者明知/应知销售者/服务提供者利用其平台侵害消费者合法权益，未采取必要措施的，依法与该销售者/服务提供者承担连带责任
  先行赔付（第44条）：
    网络交易平台提供者赔偿后，有权向销售者/服务提供者追偿
```

### 争议解决（第39条）

```
维权途径：
  ① 与经营者协商和解
  ② 请求消费者协会/依法成立的其他调解组织调解
  ③ 向有关行政部门投诉（工商/市场监管12315）
  ④ 根据与经营者达成的仲裁协议提请仲裁机构仲裁
  ⑤ 向人民法院提起诉讼
消协职责（第37条）：
  ① 向消费者提供消费信息和咨询服务
  ② 参与有关行政部门对商品/服务的监督/检查
  ③ 就有关消费者合法权益的问题，向有关行政部门反映/查询/提出建议
  ④ 受理消费者投诉，并对投诉事项进行调查/调解
  ⑤ 投诉事项涉及商品/服务质量问题的，可以提请鉴定部门鉴定
  ⑥ 就损害消费者合法权益的行为，支持受损害的消费者提起诉讼/依照本法提起诉讼
  ⑦ 对损害消费者合法权益的行为，通过大众传播媒介予以揭露/批评
公益诉讼（第47条）：
  对侵害众多消费者合法权益的行为，中国消费者协会以及在省/自治区/直辖市设立的消费者协会，可以向人民法院提起诉讼
```

### 惩罚性赔偿适用对比表

| 法律 | 适用情形 | 赔偿标准 | 起算 |
|------|----------|----------|------|
| 消保法第55条 | 经营者欺诈 | 退一赔三，不足500补500 | 商品价款/服务费 |
| 消保法第55条 | 明知产品存在缺陷仍生产销售，造成死亡/严重健康损害 | 实际损失2倍以下惩罚性赔偿 | 实际损失 |
| 食安法第148条 | 生产/经营不符合安全标准食品 | 退一赔十，不足1000补1000 | 食品价款 |

## 高频问题速查

| 问题 | 答案 |
|------|------|
| 网购7天无理由？ | 第25条，除定制/鲜活/拆封音像软件/报纸期刊外均可 |
| 卖家以"特价"为由拒绝退货？ | 不行，特价≠处理品（除非明确说明是处理品且质量瑕疵） |
| 欺诈怎么赔？ | 消保法55条：退一赔三+不足500补500 |
| 食品有问题？ | 食安法148条：退一赔十+不足1000补1000 |
| 买到假货？ | ① 与商家协商 ② 平台投诉 ③ 12315 ④ 诉讼 ⑤ 消协支持起诉 |
| 耐用商品瑕疵谁举证？ | 第23条，6个月内由经营者举证（举证倒置） |
| 霸王条款？ | 第26条，经营者单方免除/限制自身责任的格式条款无效 |
| 个人信息被泄露？ | 可起诉要求赔偿+投诉12315/网信办 |
| 维权渠道？ | 协商→消协→行政投诉→仲裁→诉讼 |
| 消协能代表起诉？ | 可以（支持受害消费者起诉/直接公益诉讼） |
