# 中华人民共和国著作权法（66 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 现行版本 | 2020年11月11日修正（2021年6月1日施行） |
| 条文总数 | 66 条 |
| 定位 | 著作权领域基本法律 |
| 核心 | **创作完成即享有著作权**（自动保护原则） |

---

## 核心条文速查

### 著作权主体（第11-19条）⭐⭐⭐

```
作者推定（第11条）⭐⭐：
  著作权属于作者，本法另有规定的除外
  创作作品的自然人是作者
  由法人/非法人组织主持，代表法人/非法人组织意志创作，并由法人/非法人组织承担责任的作品，法人/非法人组织视为作者
  如无相反证明，在作品上署名的自然人/法人/非法人组织为作者

著作权归属：
  ① 委托作品（第19条）：
     受托人完成的作品，著作权的归属由委托人和受托人通过合同约定
     合同未作明确约定/没有订立合同的 → 著作权属于**受托人**
  ② 职务作品（第18条）⭐⭐⭐：
     自然人为完成法人/非法人组织工作任务所创作的作品是职务作品，
     著作权由作者享有，但法人/非法人组织有权在其业务范围内优先使用
     主要利用法人/非法人组织的物质技术条件创作，并由法人/非法人组织承担责任的
     工程设计图/产品设计图/地图/示意图/计算机软件等职务作品 → 著作权由法人/非法人组织享有
     作者享有署名权
  ③ 合作作品（第14条）：
     两人以上合作创作的作品，著作权由合作作者共同享有
     合作作品可以分割使用的，作者对各自创作的部分可以单独享有著作权
  ④ 演绎作品（第13条）：
     改编/翻译/注释/整理已有作品而产生的作品，其著作权由改编/翻译/注释/整理人享有，
     但行使著作权时不得侵犯原作品的著作权

著作权取得（自动取得原则）⭐⭐⭐⭐⭐：
  中国公民/法人/非法人组织的作品，不论是否发表，依照本法享有著作权
  → **创作完成即享有著作权！** 不需要注册/登记/发表
  → 作品登记证书是权利证明文件，但不是著作权取得的前提
```

### 著作权保护期限（第23条）⭐⭐⭐⭐⭐最高频⭐⭐⭐⭐⭐

```
著作人身权（署名权/修改权/保护作品完整权）：
  → **永久保护！** 没有期限限制（但发表权例外）

著作财产权（复制权/发行权/出租权/展览权/表演权/放映权/广播权/信息网络传播权/摄制权/改编权/翻译权/汇编权等）⭐⭐⭐⭐⭐：
  ① 自然人作品：作者终生 + **死后50年**，截止于作者死亡后第50年的12月31日
  ② 法人/非法人组织作品：**首次发表后50年**，截止于作品首次发表后第50年的12月31日
     但作品自创作完成后50年内未发表的，本法不再保护
  ③ 视听作品：**首次发表后50年**
  ④ 摄影作品：**首次发表后50年**
  ⑤ 合作作品：最后死亡的作者终生 + 死后50年
  ⑥ 匿名作品/作者不明作品：**首次发表后50年**
  → 保护期满，著作权消灭，作品进入公有领域

发表权（第23条）：
  发表权一次用尽！发表权的保护期与著作财产权相同
```

### 合理使用（第24条）⭐⭐⭐⭐⭐最高频⭐⭐⭐⭐⭐

```
合理使用（第24条）⭐⭐⭐⭐⭐：
  在下列情况下使用作品，可以不经著作权人许可，不向其支付报酬，
  但应当指明作者姓名/作品名称，并且不得影响该作品的正常使用，也不得不合理地损害著作权人的合法权益：
  ① 为个人学习/研究/欣赏，使用他人已经发表的作品
  ② 为介绍/评论某一作品/说明某一问题，在作品中适当引用他人已经发表的作品
  ③ 为报道新闻，在报纸/期刊/广播电台/电视台等媒体中不可避免地再现/引用已经发表的作品
  ④ 报纸/期刊/广播电台/电视台等媒体刊登/播放其他报纸/期刊/广播电台/电视台等媒体已经发表的关于政治/经济/宗教问题的时事性文章，但作者声明不许刊登/播放的除外
  ⑤ 报纸/期刊/广播电台/电视台等媒体刊登/播放在公众集会上发表的讲话，但作者声明不许刊登/播放的除外
  ⑥ 为学校课堂教学/科学研究，翻译/改编/汇编/播放/向教学科研人员提供少量已经发表的作品
  ⑦ 国家机关为执行公务在合理范围内使用已经发表的作品
  ⑧ 图书馆/档案馆/纪念馆/博物馆/美术馆/文化馆等为陈列/保存版本的需要，复制本馆收藏的作品
  ⑨ 免费表演已经发表的作品，该表演未向公众收取费用，也未向表演者支付报酬，且不以营利为目的
  ⑩ 对设置/陈列在公共场所的艺术作品进行临摹/绘画/摄影/录像
  ⑪ 将中国公民/法人/非法人组织已经发表的以国家通用语言文字创作的作品翻译成少数民族语言文字作品在国内出版发行
  ⑫ 以阅读障碍者能够感知的无障碍方式向其提供已经发表的作品
  ⑬ 法律/行政法规规定的其他情形

三步检验法（国际通行标准）：
  合理使用必须同时满足：
  ① 特定情形（第24条列举的13种情况之一）
  ② 不影响作品的正常使用
  ③ 不得不合理地损害著作权人的合法权益
```

### 法定许可（第25-36条）⭐⭐⭐

```
法定许可：可以不经著作权人许可，但应当支付报酬
  ① 报刊转载（第25条）：作品刊登后，除著作权人声明不得转载/摘编的外，
     其他报刊可以转载/作为文摘/资料刊登，但应当按照规定向著作权人支付报酬
  ② 录音制作（第27条）：录音制作者使用他人已经合法录制为录音制品的音乐作品制作录音制品，可以不经著作权人许可，但应当按照规定支付报酬；著作权人声明不许使用的不得使用
  ③ 广播电台/电视台播放（第28条）：广播电台/电视台播放他人已发表的作品，可以不经著作权人许可，但应当支付报酬
  ④ 教科书（第25条）：为实施义务教育和国家教育规划而编写出版教科书，
     可以不经著作权人许可，在教科书中汇编已经发表的作品片段/短小的文字作品/音乐作品/单幅的美术作品/摄影作品/视听作品，但应当按照规定支付报酬
  ⑤ 信息网络传播法定许可（著作权法第32条）：通过信息网络向公众提供依照本节规定使用的作品，应当符合本法有关规定
```

### 著作权侵权与赔偿（第52-54条）⭐⭐⭐⭐⭐最高频⭐⭐⭐⭐⭐

```
侵权行为（第52条）⭐⭐⭐⭐⭐：
  ① 未经著作权人许可，复制/发行/表演/放映/广播/汇编/通过信息网络向公众传播其作品的（本法另有规定的除外）
  ② 出版他人享有专有出版权的图书的
  ③ 未经表演者许可，复制/发行录有其表演的录音录像制品，或者通过信息网络向公众传播其表演的（本法另有规定的除外）
  ④ 未经录音录像制作者许可，复制/发行/通过信息网络向公众传播其制作的录音录像制品的（本法另有规定的除外）
  ⑤ 未经许可，播放/复制广播/电视的（本法另有规定的除外）
  ⑥ 未经著作权人/与著作权有关的权利人许可，故意避开/破坏权利保护措施的
  ⑦ 未经著作权人/与著作权有关的权利人许可，故意删除/改变作品/版式设计/录音录像制品等的权利管理电子信息的（本法另有规定的除外）
  ⑧ 制作/出售假冒他人署名的作品的
  ⑨ 其他侵犯著作权以及与著作权有关的权益的行为

赔偿数额（第54条）⭐⭐⭐⭐⭐最高频⭐⭐⭐⭐⭐：
  ① 实际损失
  ② 侵权获利（实际损失难以计算的）
  ③ **500元到500万元法定赔偿**（实际损失/侵权获利难以计算的，法院酌情）⭐⭐⭐⭐⭐
  ④ 惩罚性赔偿：对故意侵犯著作权/与著作权有关的权利，情节严重的，可在上述数额的**一倍以上五倍以下**给予赔偿
  ⑤ 赔偿数额应当包括权利人为制止侵权行为所支付的**合理开支**（律师费/公证费/调查费）

侵犯著作权罪（刑法第217条）⭐⭐⭐：
  以营利为目的，有下列侵犯著作权情形之一，违法所得数额较大/有其他严重情节的，处3年以下有期徒刑，并处/单处罚金；
  违法所得数额巨大/有其他特别严重情节的，处3年以上10年以下有期徒刑，并处罚金：
  ① 未经著作权人许可，复制发行/通过信息网络向公众传播其文字作品/音乐/美术/视听作品/计算机软件等
  ② 出版他人享有专有出版权的图书
  ③ 未经表演者许可，复制发行录有其表演的录音录像制品/通过信息网络向公众传播其表演
  ④ 未经录音录像制作者许可，复制发行/通过信息网络向公众传播其制作的录音录像制品
  ⑤ 未经许可，播放/复制广播/电视
  ⑥ 制作/出售假冒他人署名的美术作品
  ⑦ 未经著作权人/与著作权有关的权利人许可，故意避开/破坏权利保护措施
  ⑧ 未经著作权人/与著作权有关的权利人许可，故意删除/改变权利管理电子信息
  违法所得数额较大：≥5万元
  情节严重：非法经营数额≥25万元/复制品数量合计≥500份（张）
  违法所得数额巨大：≥25万元
  特别严重：非法经营数额≥125万元/复制品数量合计≥2500份（张）
```

### 计算机软件著作权（《计算机软件保护条例》）⭐⭐⭐

```
保护期限：
  自然人软件：终生 + 死后50年
  法人/非法人组织软件：首次发表后50年

常见例外（不算侵权）：
  ① 合理使用：安装/运行/备份/版本升级
  ② 功能限制：为了学习/研究软件的设计思想和原理，通过安装/显示/传输/存储软件的方式使用软件
  ③ 兼容性：为了实现与其他软件/硬件的兼容，进行反向工程（反编译/反汇编）
  ④ 善意取得：不知道/不应当知道软件是盗版而使用
```

## 高频问题速查

| 问题 | 答案 |
|------|------|
| 作品要登记才有著作权吗？ | **不需要！** 创作完成即享有（自动取得原则） |
| 作者死后版权保护多久？ | 终生 + 死后50年 |
| 网络图片随便用吗？ | 不行！除非合理使用（介绍评论13种情形之一） |
| 转载文章要付钱吗？ | 一般法定许可（付报酬），作者声明不许的不能转 |
| 抄袭多少算侵权？ | 没有比例规定！只要实质性相似就侵权（看是否"接触+实质性相似"） |
| 软件侵权怎么算？ | 合理使用（个人/研究/备份/兼容性）不算；商业使用盗版算 |
| 著作权侵权最高赔？ | 500万元法定赔偿 + 合理开支（律师费）；故意侵权可1-5倍惩罚性赔偿 |
| 版权登记有什么用？ | 初步证据（诉讼时先推定你是著作权人），但不是取得著作权的前提 |
| 公版作品（作者去世50年） | 可以随便用，但不能侵犯署名权/修改权/保护作品完整权 |
