# 数字资产安全 · 核心速查表

> **版本**: 2026-10-25 | **来源**: 国家法律法规数据库 + 央行/网信办/最高法公开文件
> **⚠️ 重要**: 中国对虚拟货币的监管立场 **严禁 ICO 和代币融资**，但对区块链技术本身持鼓励态度。本文件整理数字资产领域的监管红线 + 司法认定标准。

---

## 一、监管立场总览

### 1.1 三层监管框架

| 层级 | 机构 | 职责 |
|------|------|------|
| 金融监管 | 央行 + 银保监会 | 数字人民币 + 支付清算 + 虚拟货币禁令 |
| 网络监管 | 网信办 | 区块链信息服务备案 + DApp 合规 |
| 司法认定 | 最高法 + 最高检 | 数字财产属性 + 案件管辖 + 量刑 |

### 1.2 核心原则

1. **虚拟货币 ≠ 法定货币**（《人民银行法》第16条：人民币为唯一法定货币）
2. **数字人民币 = 法定货币的数字化**（有国家信用背书，等同现金）
3. **DAO 无合法主体资格**（2022 年网信办+央行联合公告：去中心化组织不具备法律主体资格，其成员行为自负）
4. **区块链技术鼓励 + 应用场景收紧**（"链上"≠"法外"）

## 二、虚拟货币监管红线

### 2.1 《关于防范比特币风险的通知》（银发〔2013〕289号）

> **效力**: 现行有效 | **发布**: 央行+工信部+银监会+证监会+保监会 2013

| 核心条款 | 内容 |
|----------|------|
| **性质定性** | 比特币不是货币当局发行，不具有法偿性与强制性等货币属性，**不是真正意义的货币** |
| **禁止业务** | 金融机构和支付机构不得开展比特币相关业务（开户/充值/提现/买卖/保险） |
| **风险提示** | 提供比特币登记/交易等服务的网站需在电信管理机构备案，平台承担相应法律责任 |

### 2.2 《关于防范代币发行融资风险的公告》（2017年9月4日）— **ICO 禁令**

> **效力**: 现行有效 | **发布**: 央行+网信办+工信部+工商总局+银监会+证监会+保监会

| 核心条款 | 内容 |
|----------|------|
| **ICO 定性** | 代币发行融资（ICO）是一种未经批准非法公开融资的行为，涉嫌非法发售代币票券、非法发行证券以及非法集资、金融诈骗、传销等违法犯罪活动 |
| **交易所禁令** | 任何所谓的代币融资交易平台不得从事法定货币与代币、"虚拟货币"相互之间的兑换业务 |
| **清退要求** | 已从事代币发行融资的组织和个人应当立即停止；已上线的代币交易平台应立即停止交易 |

### 2.3 《关于进一步防范和处置虚拟货币交易炒作风险的通知》（银发〔2021〕237号）— **最严禁令**

> **效力**: 现行有效 | **发布**: 央行+网信办+最高法+最高检等十部委 2021

| 核心条款 | 内容 |
|----------|------|
| **定性升级** | 虚拟货币相关业务活动属于非法金融活动 |
| **禁止清单** | ❌ 虚拟货币兑换 ❌ 代币融资交易 ❌ 虚拟货币相关衍生品 ❌ 海外虚拟货币平台提供服务 |
| **技术中立** | 虚拟货币相关技术被用于非法活动的，公安机关、司法机关依法追究法律责任 |
| **刑事责任** | 虚拟货币交易炒作活动，扰乱经济金融秩序，滋生赌博、非法集资、诈骗、传销、洗钱等违法犯罪活动，严重危害人民群众财产安全 |

### 2.4 虚拟货币法律性质 · 三级认定

| 认定层级 | 情形 | 法律后果 |
|----------|------|----------|
| **不认定为财产** | 禁止类虚拟货币交易（如 BTC 现货买卖） | 交易不受法律保护，合同无效，公安可追缴涉案资产 |
| **认定为网络虚拟财产** | 合法游戏币/平台积分（不反向兑换人民币） | 可作为民事权益标的物，适用《民法典》第127条 |
| **认定为金融商品** | 以证券/基金等形式发行的代币（如 Security Token） | 涉嫌非法发行证券，适用《证券法》 |

## 三、数字人民币（e-CNY）

### 3.1 法定地位

《中华人民共和国人民银行法（2020修正）》第16条：**人民币是我国的法定货币**，以人民币支付中华人民共和国境内的一切公共的和私人的债务，任何单位和个人不得拒收。

> 数字人民币是人民币的数字化形态，由央行发行，与现金等价，具有法偿性、无限法偿性。

### 3.2 关键特性

| 特性 | 说明 |
|------|------|
| 双层运营 | 央行→商业银行→公众，央行不对公众直接兑换 |
| 匿名可控 | 小额交易匿名，大额交易可追溯；交易数据留央行，不向第三方暴露 |
| 双离线 | 收付款双方均离线时，通过 NFC 近场通信完成交易 |
| 智能合约 | 可在特定条件下自动执行（如定向扶贫款只能用于指定商品） |
| 货币属性 | M0（流通中现金），不计付利息 |

### 3.3 已试点区域

2020 年启动以来，已在深圳、苏州、北京（冬奥会）、上海、成都、雄安新区、长沙等地试点，2025 年全国推行。

## 四、区块链信息服务监管

### 4.1 《区块链信息服务管理规定》（网信办令第3号，2019）

| 条款 | 内容 |
|------|------|
| **备案强制** | 在中国境内从事区块链信息服务需向网信办办理备案（服务提供者/信息发布者/开发者三类） |
| **内容合规** | 禁止利用区块链传播违法信息、从事违法活动 |
| **技术可控** | 区块链服务提供者应提供可溯源技术手段 |
| **定期报告** | 每年1月31日前提交年度备案报告 |

### 4.2 《网络安全法》配套要求

- 区块链节点属于网络设备，应符合 **关键信息基础设施保护** 要求（如果属于关基的话）
- 链上数据属于数据资产，应遵守《数据安全法》《个人信息保护法》

## 五、NFT 合规框架（非同质化代币）

### 5.1 监管现状

中国目前 **没有** 针对 NFT 的专门立法，但适用虚拟货币监管框架 + 艺术品/知识产权法规。

### 5.2 红线清单

| 禁止行为 | 依据 |
|----------|------|
| NFT 与虚拟货币挂钩交易 | 银发〔2021〕237号 |
| 炒作 NFT 价格、拉盘砸盘 | 《证券法》《期货法》 |
| 未授权发行、变相 ICO | 2017 年 ICO 禁令 |
| 数字艺术品侵权（盗用 IP） | 《著作权法》第52条（计算机软件侵权） |

### 5.3 合法路径

| 路径 | 监管要求 |
|------|----------|
| 实体经济应用（产品溯源、版权登记） | 区块链备案 + 不得交易 |
| 平台积分化（如蚂蚁链积分仅限内部兑换） | 不反向兑换人民币，不与虚拟货币挂钩 |
| 数字藏品销售（不允许二次交易） | 2022 年 2 月 国家版权局 18 部门《关于防范 NFT 相关风险的提示》 |

## 六、DAO（去中心化自治组织）合规风险

### 6.1 2022 年监管表态

> 网信办+央行联合新闻发布会：**DAO 不具备法律主体资格**，在中国境内活动的 DAO 成员需以个人身份承担全部法律责任。

### 6.2 高风险 DAO 行为

| 行为 | 涉嫌罪名 |
|------|----------|
| 代币融资（ICO/IFO） | 非法吸收公众存款罪、集资诈骗罪 |
| 平台代币发行 + 二级市场交易 | 非法发行证券罪 |
| 匿名钱包归集资金 | 洗钱罪 |
| 跨链资产转移（规避资本管制） | 逃汇罪 |
| 治理代币投票权分红 | 非法经营罪 |

## 七、数字资产民事纠纷

### 7.1 最高法典型案例（指导案例）

**案例 1：比特币代购纠纷案**（上海，2019）
- 法院认定：比特币交易不受法律保护，代购协议无效
- 判决：各自返还本金，不计利息

**案例 2：游戏账号被盗案**（浙江，2020）
- 法院认定：游戏虚拟货币属于网络虚拟财产，受《民法典》第127条保护
- 判决：盗号方赔偿游戏币市场价值

**案例 3：NFT 版权侵权案**（北京，2023）
- 法院认定：未经授权将他人美术作品上链生成 NFT 构成侵犯著作权
- 判决：停止侵权 + 赔偿 10 万元

### 7.2 数字财产继承

《民法典》第1122条：**遗产是自然人死亡时遗留的个人合法财产**。

> 数字资产是否可继承取决于其合法性：
> - ✅ 合法游戏币、平台积分、电子货币（如 Q 币）：可继承
> - ❌ 禁止类虚拟货币（BTC、ETH 等）：继承不受法律保护
> - ✅ 数字人民币：等同现金，可继承

## 八、跨境合规

### 8.1 资本管制红线

《外汇管理条例》+《个人外汇管理办法》：
- 个人年度便利化购汇额度 5 万美元
- 跨境虚拟货币交易 = 违反资本管制 + 外汇管制
- 通过境外交易所买卖虚拟货币 = 非法经营罪 + 逃汇罪

### 8.2 CIPS 系统

中国自主研发的跨境人民币支付系统（CIPS），支持数字人民币跨境结算，替代 SWIFT 的部分功能。
