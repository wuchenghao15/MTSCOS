# 中华人民共和国职业教育法（69 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 现行版本 | **2022年4月20日新修订**（2022年5月1日施行） |
| 条文总数 | **69 条**（旧版51条→+18条） |
| 定位 | 职业教育专门法律（2022重大修订） |

---

## 2022修订重大变化 ⭐⭐⭐

```
❶ 明确职业教育与普通教育同等重要地位（第3条）
  职业教育是与普通教育具有同等重要地位的教育类型

❷ 职业院校学生享同等待遇（第53条）
  职业学校毕业生在升学/就业/职业发展等方面享有与普通学校毕业生同等机会
  用人单位不得对职业学校毕业生设置限制性条件

❸ 学徒制（第30条）
  国家推行中国特色学徒制，引导企业/学校深度合作
  学徒与企业签订劳动合同，可享有工资待遇

❹ 职业教育考试（第45条）
  建立职业教育国家学分银行
  学生获得的技能等级证书可折算为相应学历教育的学分

❺ 社会力量参与（第12条）
  鼓励企业/事业单位/社会团体/其他社会组织及公民个人依法举办职业学校和职业培训机构

❻ 实习权利保护（第31条）⭐⭐⭐
  实习岗位应符合专业培养目标，不得安排学生从事高空/井下/有毒/有害/易燃易爆/国家规定的第四级体力劳动强度的劳动或者其他具有安全风险的劳动
  不得安排学生到娱乐性场所实习
  不得向学生收取实习押金/培训费或者其他费用
  顶岗实习学生实习报酬不低于本单位相同岗位试用期工资标准的80%

❼ 就业促进（第53条）
  用人单位不得歧视职业院校毕业生
  不得以学历/年龄/性别/民族等为由拒绝录用
```

## 核心条文速查

### 职业教育体系（第14-21条）

```
纵向：
  初等职业教育（小学后）→ 中等职业教育（初中后/高中后）→ 高等职业教育（高中后）
横向：
  普通教育与职业教育相互沟通
  学历教育与培训并重

职业学校类型（第15条）：
  职业初中（初等职业教育）
  职业高中/技工学校/中专（中等职业教育）
  职业技术学院/职业大学/应用技术大学（高等职业教育）

升学通道（第17条）⭐2022明确⭐：
  中等职业学校毕业生可以报考高等职业学校
  高等职业学校毕业生可以报考本科及以上院校
  应用型本科高校应当以职业教育为基础
  研究生教育应当增加应用型人才培养比例
```

### 实习制度（第31条）⭐⭐⭐

```
实习类型：
  认知实习（低年级，认识岗位）
  跟岗实习（中年级，师傅带徒弟）
  顶岗实习（毕业前，独立顶岗）

实习报酬（第31条第5款）⭐⭐⭐：
  顶岗实习学生实习报酬不得低于本单位相同岗位试用期工资标准的80%
  实习单位应当按照规定为学生缴纳工伤保险
  注意：认知/跟岗实习报酬可协商，顶岗实习必须不低于80%试用期工资

实习禁止（第31条第4款）⭐⭐⭐：
  不得安排学生从事：
    ① 高空作业
    ② 井下作业
    ③ 有毒/有害作业
    ④ 易燃易爆作业
    ⑤ 国家规定的第四级体力劳动强度的劳动
    ⑥ 其他具有安全风险的劳动
    ⑦ 娱乐性场所实习
    ⑧ 向学生收取实习押金/培训费/其他费用

实习责任（第32条）：
  学生实习期间发生人身/财产损害的，按照工伤保险有关规定由实习单位承担相应责任
  学校/实习单位应当为实习学生购买实习责任保险
```

### 职业技能等级制度（第44条）

```
职业学校学生在校期间可以参加职业技能等级评价，取得相应职业技能等级证书
技能等级证书与学历证书具有同等效力
国家实行职业技能等级认定制度，由用人单位和社会培训评价组织按照国家有关规定开展职业技能等级认定
```

### 高频问题速查

| 问题 | 答案 |
|------|------|
| 职业学校毕业生能考大学吗？ | 可以！2022新法明确升学通道 |
| 实习有工资吗？ | 顶岗实习不得低于80%试用期工资；其他实习可协商 |
| 实习被安排去KTV/娱乐场所？ | 违法！2022新法明确禁止 |
| 职校生会被歧视吗？ | 新法明确同等地位；用人单位歧视可投诉 |
| 学生实习受伤谁负责？ | 实习单位承担工伤保险责任 |
