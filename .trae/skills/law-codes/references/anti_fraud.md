# 中华人民共和国反电信网络诈骗法（50 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 施行时间 | **2022年12月1日**（反诈专项立法） |
| 条文总数 | 50 条 |
| 定位 | 针对电信网络诈骗的专项法律 |
| 背景 | 全国每年被骗金额超 3000 亿元，受害人数超 100 万 |

---

## 核心机制

### 多部门联动（第3-4条）

```
国务院建立反电信网络诈骗工作机制
  公安部统筹协调全国反电信网络诈骗工作
  电信/银行/网信/文旅/市场监管等部门各司其职
  乡镇政府/街道办事处/村民委员会/居民委员会协助
```

### 电信治理（第10-14条）⭐⭐⭐

```
实名制（第10条）：
  电信业务经营者应当严格落实电话用户真实身份信息登记制度
  非法办理/买卖电话卡：违法！惩戒措施包括信用惩戒/限制办卡/行政拘留/刑事追诉
涉诈电话卡处置：
  公安机关发现涉诈电话卡/涉诈网络账号的，应当及时通知电信业务经营者/互联网服务提供者采取限制业务功能/关闭等处置措施
  被处置后需要恢复的，应当本人到现场核实身份并说明理由

禁止行为（第14条）：
  任何单位/个人不得非法制造/买卖/提供/使用GOIP等涉诈技术设备
  不得非法交易电话卡/物联网卡/信用卡/银行卡
  不得非法买卖公民个人信息（用于诈骗的按诈骗罪共犯/帮信罪/侵犯公民个人信息罪）
```

### 金融治理（第15-18条）⭐⭐⭐⭐⭐

```
银行卡/账户管理（第15条）：
  银行应当为每个客户开立的银行账户数量设置合理上限
  银行应当建立账户风险监测机制，对异常交易及时预警/采取限制措施
  禁止非法买卖/出租/出借银行卡
涉诈账户处置：
  银行接到公安机关的止付/冻结指令后，应当立即执行
  紧急情况下，银行可先行采取临时冻结措施，再报告公安机关

跨境资金通道（第17条）：
  任何单位/个人不得非法提供资金转移服务（地下钱庄/跑分）
  构成犯罪的，按洗钱罪/非法经营罪/帮助信息网络犯罪活动罪追究刑事责任

跑分/帮信（第10条+刑法第287条之二）⭐⭐⭐⭐⭐最高频⭐⭐⭐⭐⭐：
  为诈骗分子提供银行卡/收款码/支付通道赚取佣金（"跑分"/"兼职刷流水"）
  → 构成**帮助信息网络犯罪活动罪**（刑法第287条之二）
  → 即使自己没直接诈骗，只要明知他人利用信息网络实施犯罪仍提供帮助，就构成犯罪
  → 量刑：3年以下有期徒刑/拘役/管制，并处/单处罚金
  → 情节严重：3年以上7年以下有期徒刑，并处罚金
  → 情节严重认定（司法解释）：
    ① 为3个以上对象提供帮助的
    ② 支付结算金额20万元以上的
    ③ 以投放广告等方式提供资金5万元以上的
    ④ 违法所得1万元以上的
    ⑤ 被帮助对象实施的犯罪造成严重后果的
    ⑥ 其他情节严重的情形
```

### 互联网治理（第19-21条）⭐⭐⭐

```
涉诈域名/IP处置（第19条）：
  网信部门发现涉诈网站/应用，应当立即责令关闭/下架
  互联网服务提供者发现涉诈信息，应当及时删除/屏蔽/断开链接
  不得为涉诈网站提供服务器托管/网络加速等服务

诈骗信息监测（第20条）：
  互联网服务提供者应当对涉诈信息进行监测，及时发现并处置
  公安机关/网信部门可以要求互联网服务提供者提供技术支持和协助

AI/深度合成管理（第21条）：
  任何单位/个人不得利用AI/深度合成等技术手段制作/传播涉诈内容
  平台应当对深度合成内容进行标识
```

### 综合措施（第23-31条）

```
预警劝阻（第23条）：⭐⭐⭐⭐⭐最高频⭐⭐⭐⭐⭐
  公安机关应当建立预警劝阻机制，发现受害人可能遭受诈骗的，及时通过电话/短信/上门等方式进行劝阻
  各单位/基层组织应当协助公安机关开展预警劝阻工作
  受害人已经转账的，公安机关应当立即采取止付/冻结措施，尽最大可能挽回损失

宣传教育（第24条）：
  国家支持开展反电信网络诈骗宣传教育进学校/进家庭/进社区/进企业/进农村/进商圈等活动
  新闻媒体应当开展反电信网络诈骗公益宣传
  学校应当将反诈知识纳入法治教育内容

信用惩戒（第29条）：
  电信网络诈骗相关的违法犯罪行为，应当记入信用记录
  对惩戒对象可以采取限制办卡/限制信贷/限制高消费等惩戒措施
```

### 法律责任（第34-46条）⭐⭐

```
行政责任：
  非法买卖电话卡/银行卡：没收违法所得 + 1-10万元罚款
  非法提供支付结算服务：没收违法所得 + 2-20万元罚款
  为诈骗分子提供帮助：没收违法所得 + 1-20万元罚款
  电信/银行/互联网单位失职：责令改正 + 警告 + 10-100万元罚款 + 吊销证照
个人违法：
  情节较轻：拘留/警告/罚款
  情节较重：拘留/罚款/信用惩戒
刑事责任：
  电信网络诈骗（刑法第266条）：诈骗罪从重处罚（数额特别巨大+情节特别严重可无期）
  帮信罪（刑法第287条之二）：3年以下；情节严重3-7年
  掩饰/隐瞒犯罪所得罪（刑法第312条）：3年以下；情节严重3-7年
  洗钱罪（刑法第191条）：5年以下；情节严重5-10年
```

### 诈骗常见类型速查 ⭐⭐⭐⭐⭐

```
① 刷单返利（最高频！）：先给小甜头，后要求大额投入 → 血本无归
② 虚假投资理财：APP/平台/大师带飞 → 平台关闭/提现失败
③ 冒充公检法："你涉嫌洗钱/诈骗/帮信，需要转账到安全账户"
④ 冒充客服/退款："你的订单有问题，需要退款/赔偿/转保证金"
⑤ 冒充领导/熟人："我在开会/不方便说话，请先帮我转钱"
⑥ 虚假贷款："零抵押/秒放款，先交保证金/手续费/验证金"
⑦ 杀猪盘：婚恋交友→诱导投资→跑路
⑧ 裸聊敲诈：被诱导安装APP→被敲诈勒索
⑨ 校园贷/培训贷：诱导学生签订高额贷款合同
⑩ 冒充快递/物流："你的包裹有问题，需要退款/转钱"
```

### 受害人权益保护

```
① 立即报警：110 / 96110（反诈专线）
② 紧急止付：通过银行APP/客服立即挂失/冻结涉案账户
③ 固定证据：聊天记录/转账凭证/电话录音/APP截图
④ 配合调查：向公安机关如实陈述经过
⑤ 追缴退赔：犯罪嫌疑人到案后，可追缴其违法所得并退赔受害人
⑥ 法院起诉：如果有明确被告/责任主体，可提起民事诉讼
```

| 问题 | 答案 |
|------|------|
| 朋友让我办张卡借给他用？ | 绝对不行！借卡=帮信罪！最高3年有期徒刑！ |
| 跑分/刷流水兼职？ | 绝对不行！构成帮信罪！ |
| 被骗了怎么办？ | ① 先报警 ② 银行止付 ③ 保证据 ④ 别信"大师追回"二次被骗 |

| 诈骗金额多少立案？ | 一般3000元（诈骗罪立案标准） |
| 诈骗判刑？ | 数额较大3年以下；数额巨大3-10年；数额特别巨大10年以上/无期 |
