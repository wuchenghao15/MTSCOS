# 网络购买商品七日无理由退货暂行办法（27 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 发布机构 | 国家工商行政管理总局 |
| 施行时间 | 2017年3月15日 |
| 条文总数 | 27 条 |
| 定位 | 消保法第25条的具体实施细则 |

---

## 核心规则 ⭐⭐⭐⭐⭐

### 七日期限计算（第10条）⭐⭐⭐

```
7天期限从消费者收到商品之日起计算
消费者应当自收到商品之日起7日内提交退货申请（订单显示签收时间起算）
起算时间：消费者在物流/快递系统的签收时间（自动签收/实际签收都算）
注意：是"7个自然日"，不是工作日（包括周末/节假日）
```

### 7天无理由退货范围

#### ✅ 适用情形（消保法第25条）

```
经营者采用网络/电视/电话/邮购等方式销售商品 → 消费者享有7天无理由退货权
退货条件：商品完好
消费者承担退回运费（经营者另有约定除外）
```

#### ❌ 不适用情形（消保法第25条第2款）⭐⭐⭐⭐⭐

```
以下商品不适用7天无理由退货：
  ① 消费者定作的（特别定制/个性化）
  ② 鲜活易腐的（生鲜/海鲜/肉类/奶制品等）
  ③ 在线下载/消费者拆封的音像制品/计算机软件等数字化商品
  ④ 交付的报纸/期刊
  ⑤ 其他根据商品性质并经消费者在购买时确认不宜退货的商品
    （如贴身衣物/化妆品需消费者确认才能排除无理由退货）
注意：化妆品/贴身衣物等如果商家没有提前在购买页面显著提示+消费者确认，仍然可以7天无理由退货
```

### 退货程序（第11-17条）⭐⭐⭐

```
消费者申请退货：
  ① 消费者应当自收到商品之日起7日内通过网络/电话/邮件等方式向经营者提出退货申请
  ② 经营者应当在收到退货申请后及时处理（一般≤3个工作日）
  ③ 经营者同意退货的，应当提供退货地址/联系人/联系电话等信息
  ④ 消费者应当按照经营者提供的退货信息将商品寄回
商品完好标准（第9条）⭐⭐⭐：
  消费者退回的商品应当完好
  商品完好：指商品能够保持原有品质/功能，商品配件/标识标签完整齐全
  可以有必要的开箱/试用痕迹，不影响商品再次销售
  消费者基于查验需要打开商品包装/对商品进行调试，应当保持商品完好
经营者退回货款（第16条）：
  经营者应当自收到退回商品之日起7日内返还消费者支付的商品价款
  涉及商品价格/运费/保险费等的，经营者应当一并返还已收取的费用
  退回货款一般原路退回消费者支付账户
运费承担（第18条）：
  7天无理由退货的，退回商品的运费由消费者承担
  经营者另有约定的，从其约定（如"包邮退"）
  因质量问题退货的，运费由经营者承担
```

### 赠品处理（第17条）⭐

```
消费者退货的，应当将商品本身/配件/赠品一并退回
消费者未退赠品的，经营者可以按照赠品的实际价格扣除货款
```

### 多件/套装商品（第15条）⭐

```
商品包含配件/套装/组合等的，消费者退货应当将全部退回
消费者只退主商品或只退部分的，经营者可以要求消费者按照套装/组合的实际价格退还
```

## 高频问题速查

| 问题 | 答案 |
|------|------|
| 7天是工作日还是自然日？ | 自然日！包括周末节假日 |
| 超过7天了还能退吗？ | ① 质量问题可走"有理由退货"（无期限但举证在消费者）② 协商 ③ 平台介入 |
| 拆了包装还能退吗？ | 能！只要商品完好（能保持原有品质/功能），开箱/试用痕迹不算坏 |
| 化妆品/贴身衣物能7天退吗？ | 如果商家没有提前+显著提示+消费者确认，仍可退！ |
| 商家说"特价不退"？ | 违法！特价也是7天无理由范围内 |
| 退货运费谁出？ | 7天无理由：消费者；质量问题：经营者 |
| 可以只退其中一件吗？ | 套装/组合的要全部退；单独买的可以单独退 |
| 食品/生鲜能退吗？ | 不能！鲜活易腐排除 |
| 在线下载的APP/会员能退吗？ | 不能！在线下载的数字化商品排除 |
| 商家不处理退货？ | ① 申请平台介入（淘宝/京东/拼多多等都有争议入口）② 12315投诉 ③ 诉讼 |
