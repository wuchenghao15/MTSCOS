## 18 种欺诈消费者行为（第3-6条）⭐⭐⭐⭐⭐

### 商品/服务中掺杂掺假/以假充真

| # | 行为类型 | 具体情形 |
|---|----------|----------|
| 1 | 销售掺杂掺假/以假充真/以次充好商品 | 如"水洗标羊毛100%"实际含聚酯纤维 |
| 2 | 采取虚假/其他不正当手段使销售商品分量不足 | 如标注500g实际400g |
| 3 | 销售"处理品"等外品/残次品而谎称是正品 | 谎称清仓处理实际是质量不合格品 |
| 4 | 以虚假"清仓价""甩卖价""最低价""优惠价"等手段销售商品 | 虚构原价/虚假折扣 |
| 5 | 不以真实名称/标记提供服务 | 冒用/伪造他人企业名称 |
| 6 | 谎称有奖销售/有奖销售的奖品/奖品种类/质量/数量与实际不符 | 虚假中奖/奖品是劣质商品 |
| 7 | 故意侵犯消费者注册商标专用权 | 销售假冒注册商标商品 |
| 8 | 伪造/冒用商品的产地/厂名厂址/质量标志 | 如冒用"绿色食品""有机食品"认证 |
| 9 | 作虚假或者引人误解的现场说明/演示 | 虚假对比演示/夸大功能 |
| 10 | 利用广播/电视/电影/报刊等大众传播媒介作虚假/引人误解的宣传 | 典型虚假广告 |
| 11 | 骗取消费者预付款 | 收取预付款后不履行/不完整履行 |
| 12 | 利用邮购销售骗取价款而不提供/不按照约定条件提供商品 | 只收款不发货/发次货 |
| 13 | 以虚假的"有奖销售""还本销售""体验销售"等方式销售商品 | 诈骗式销售 |
| 14 | 销售"进口商品"而未提供相应手续 | 谎称进口实际国产 |
| 15 | 销售"特价品"而与正常价格无差异 | 虚假优惠 |
| 16 | 销售"试用商品"而不履行退货/换货义务 | 试用后不允许退回 |
| 17 | 虚构合同主体/合同标的 | 合同诈骗 |
| 18 | 其他欺诈行为 | 兜底条款 |

### 欺诈认定关键要素（第2条）⭐⭐⭐

```
欺诈消费者行为的构成要件：
  ① 经营者存在主观故意（明知自己的行为会欺骗消费者）
  ② 经营者实施了欺诈行为（虚假陈述/隐瞒真相/伪造事实等）
  ③ 消费者因该欺诈行为作出错误的意思表示（即被骗了）
  ④ 消费者因错误意思表示受到损害
注意：不需要消费者造成实际财产损失 — 只要消费者被骗购买了商品/接受了服务就算！
```

### 欺诈赔偿（消保法第55条 + 本办法第10条）⭐⭐⭐⭐⭐

```
经营者提供商品/服务有欺诈行为的，应当：
  ① 退一赔三：退还货款/服务费 + 增加赔偿额为3倍
  ② 不足500补500：增加赔偿的金额不足500元的，为500元
  ③ 造成人身伤害/死亡的，承担医疗费/护理费/误工费/残疾赔偿金/死亡赔偿金等
  ④ 其他法律/行政法规另有规定的，依照其规定（如食安法十倍/消保法第23条/农产品质量安全法等）
注意：
  退一赔三 + 最低500元下限，与食品十倍赔偿（最低1000元）是两套体系
  食品问题优先适用食安法；其他商品/服务问题适用消保法55条（三倍+500元）
```

### 经营者行政责任（第12条）⭐

```
经营者有本办法第3-6条所列欺诈消费者行为之一的，
由工商行政管理部门依照《中华人民共和国消费者权益保护法》第56条规定处罚：
  责令改正，可以根据情节单处/并处警告/没收违法所得/处以违法所得一倍以上十倍以下罚款
  没收违法所得的，处以1万元以下罚款
  情节严重的，责令停业整顿/吊销营业执照
构成犯罪的，依法追究刑事责任（如合同诈骗罪/生产销售伪劣产品罪/虚假广告罪）
```

### 网络交易欺诈（第14条）

```
通过网络平台实施欺诈消费者行为的，适用本办法
网络交易平台提供者知道/应当知道经营者利用其平台实施欺诈消费者行为的，
应当及时采取删除/屏蔽/断开链接等必要措施；未采取的，
依法与经营者承担连带责任（消保法第44条）
```
