## 核心条文速查

### 教育基本制度

```
国家教育方针（第5条）：
  教育必须为社会主义现代化建设服务、为人民服务，必须与生产劳动和社会实践相结合，
  培养德智体美劳全面发展的社会主义建设者和接班人
教育优先发展（第4条）：
  保障教育事业优先发展，全社会应当关心和支持教育事业的发展
公民教育权利（第9条）：
  中华人民共和国公民有受教育的权利和义务
  公民不分民族/种族/性别/职业/财产状况/宗教信仰等，依法享有平等的受教育机会
  受教育者在入学/升学/就业等方面依法享有平等权利
教育制度（第17条）：
  国家实行学前教育/初等教育/中等教育/高等教育的学校教育制度
  建立科学的学制系统
  学制系统内的学校和其他教育机构的设置/教育形式/修业年限/招生对象/培养目标等，由国务院或由国务院授权省/自治区/直辖市人民政府规定
义务教育（第18条）：
  国家实行九年制义务教育制度
  各级人民政府采取各种措施保障适龄儿童/少年就学
  适龄儿童/少年的父母或者其他监护人以及有关社会组织和个人有义务使适龄儿童/少年接受并完成规定年限的义务教育
```

### 受教育者权利和义务（第43-44条）

```
受教育者权利（第43条）：
  ① 参加教育教学计划安排的各种活动，使用教育教学设施/设备/图书资料
  ② 按照国家有关规定获得奖学金/贷学金/助学金
  ③ 在学业成绩和品行上获得公正评价，完成规定学业后获得相应学业证书/学位证书
  ④ 对学校给予的处分不服向有关部门提出申诉，对学校/教师侵犯其人身权/财产权等合法权益，提出申诉或依法提起诉讼
  ⑤ 法律/法规规定的其他权利
受教育者义务（第44条）：
  ① 遵守法律/法规
  ② 遵守学生行为规范，尊敬师长，养成良好的思想品德和行为习惯
  ③ 努力学习，完成规定的学习任务
  ④ 遵守所在学校/其他教育机构的管理制度
```

### 教育投入（第54-63条）

```
经费来源多元化（第54条）：
  国家建立以财政拨款为主/其他多种渠道筹措教育经费为辅的体制
  逐步增加对教育的投入，保证国家举办的学校教育经费的稳定来源
财政拨款（第55条）：
  国务院和地方各级人民政府用于实施义务教育财政拨款的增长比例应当高于财政经常性收入的增长比例
  保证按照在校学生人数平均的义务教育费用逐步增长，保证教职工工资和学生人均公用经费逐步增长
设立专项资金（第57条）：
  国务院及县级以上地方各级人民政府应当设立教育专项资金，重点扶持边远贫困地区/少数民族地区实施义务教育
鼓励社会投入（第60条）：
  国家鼓励境内/境外社会组织和个人捐资助学
  国家运用金融/信贷手段，支持教育事业的发展
```

### 法律责任（第71-78条）

```
违法办学/收费/诈骗（第75-76条）：
  违反国家有关规定，举办学校或者其他教育机构的，由教育行政部门/人力资源社会保障行政部门予以撤销；没收违法所得；对直接负责的主管人员和其他直接责任人员，依法给予处分
  违反国家有关规定向受教育者收取费用的，由教育行政部门责令退还所收费用；对直接负责的主管人员和其他直接责任人员，依法给予处分
  构成犯罪的，依法追究刑事责任
挪用克扣教育经费（第77条）：
  违反国家财政制度/财务制度，挪用/克扣国家财政性教育经费/社会组织和个人捐助的教育经费的，由上级机关责令限期归还被挪用/克扣的经费，并对直接负责的主管人员和其他直接责任人员，依法给予处分；构成犯罪的，依法追究刑事责任
```

## 教育法律体系总览

```
法律层级：
  教育法（根本法）
    ├── 义务教育法（九年义务）
    ├── 教师法（教师权益）
    ├── 高等教育法（高校）
    ├── 职业教育法（职教2022新修订）
    ├── 学前教育法（2024即将出台）
    └── 学位条例 → 学位法（修订中）
特别法律：
  未成年人保护法（2020新修订，含学校保护/网络保护）
  国防教育法
  国家通用语言文字法
重要行政法规：
  校车安全管理条例
  义务教育经费保障机制
  教师资格条例
部门规章：
  学生伤害事故处理办法
  中小学幼儿园安全管理办法
  禁止使用童工规定
  教育部学生申诉处理办法
```
