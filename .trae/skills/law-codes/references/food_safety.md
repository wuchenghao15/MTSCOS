# 中华人民共和国食品安全法（154 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 现行版本 | 2021年4月29日修正 |
| 条文总数 | **154 条** |
| 定位 | 食品领域最严格法律 |
| 核心 | **十倍赔偿** + 最低1000元下限 + 网络食品监管 |

---

## 核心条文速查

### 食品安全标准（第25-29条）

```
强制执行标准（第25条）：
  食品/食品添加剂/食品相关产品的致病性微生物/农药残留/兽药残留/生物毒素/重金属等污染物质限量规定
  食品添加剂的品种/使用范围/用量规定
  专供婴幼儿/其他特定人群的主辅食品的营养成分要求
  对与食品安全/营养有关的标签/标识/说明书的要求
  食品生产经营过程的卫生要求
  其他应当制定为食品安全标准的内容

GB 2760 食品添加剂使用标准（国家食品安全风险评估中心）
GB 2762 食品中污染物限量
GB 2763 食品中农药残留最大限量
GB 2763.1 食品中兽药残留最大限量
GB 29921 食品中致病菌限量
```

### 食品生产经营许可（第35-41条）⭐

```
许可制度：
  食品生产/食品销售/餐饮服务应当依法取得食品生产许可/食品经营许可
  销售自产农产品/小摊贩/家庭作坊按规定
  网络食品交易第三方平台提供者应当对入网食品经营者进行实名登记

禁止生产经营（第34条）⭐：
  ① 用非食品原料生产食品/在食品中添加食品添加剂以外的化学物质和其他可能危害人体健康的物质/用回收食品作为原料生产食品
  ② 生产经营致病性微生物/农药残留/兽药残留/生物毒素/重金属等污染物质以及其他危害人体健康的物质含量超过食品安全标准限量的食品/食品添加剂/食品相关产品
  ③ 生产经营营养成分不符合食品安全标准的专供婴幼儿和其他特定人群的主辅食品
  ④ 经营病死/毒死/死因不明的禽/畜/兽/水产动物肉类及其制品
  ⑤ 生产经营标注虚假生产日期/保质期或者超过保质期的食品/食品添加剂
  ⑥ 生产经营国家为防病等特殊需要明令禁止生产经营的食品
  ⑦ 其他
```

### 惩罚性赔偿（第148条）⭐⭐⭐⭐⭐最高频⭐⭐⭐⭐⭐

```
消费者赔偿权（第148条第1款）：
  消费者因不符合食品安全标准的食品受到损害的，可以向经营者要求赔偿损失，也可以向生产者要求赔偿损失
  接到消费者赔偿要求的生产经营者，应当实行首负责任制，先行赔付，不得推诿；属于生产者责任的，经营者赔偿后有权向生产者追偿；属于经营者责任的，生产者赔偿后有权向经营者追偿

惩罚性赔偿（第148条第2款）⭐⭐⭐⭐⭐：
  生产不符合食品安全标准的食品或者经营明知是不符合食品安全标准的食品，消费者除要求赔偿损失外，
  还可以向生产者或者经营者要求支付价款**十倍**或者损失**三倍**的赔偿金；
  增加赔偿的金额**不足1000元的，为1000元**
  但是，食品的标签/说明书存在不影响食品安全且不会对消费者造成误导的瑕疵的除外

十倍 vs 三倍选择：
  - 价款10倍 和 损失3倍，消费者可选择高者
  - 注意：是"可以要求支付价款十倍 **或者** 损失三倍"，二者选高
  - 损失=医疗费+护理费+误工费+残疾/死亡赔偿金等

消保法三倍 vs 食安法十倍：
  消保法第55条：经营者欺诈 → 退一赔三 + 不足500补500
  食安法第148条：不符合食品安全标准 → 退一赔十 + 不足1000补1000
  → 食品问题优先适用食安法（更高赔偿），非食品问题适用消保法
```

### 举证责任（第148条）

```
消费者主张食品不符合安全标准：
  消费者只需证明购买了该食品 + 食品存在质量问题（外观/气味/检测报告等）
  经营者/生产者应当举证证明食品符合食品安全标准
  → 举证责任在经营者/生产者！消费者只需主张，对方要证明自己没责任
```

### 经营者行政责任（第123条）⭐⭐⭐

```
违法情形（第123条）：
  生产经营第34条禁止经营的食品/食品添加剂/食品相关产品
处罚：
  没收违法所得 + 违法生产经营的食品/工具/设备等物品
  违法生产经营的食品/食品添加剂货值金额不足1万元的，并处5万元以上10万元以下罚款
  货值金额1万元以上的，并处货值金额10倍以上20倍以下罚款
  情节严重的，吊销许可证，并可以由公安机关对其直接负责的主管人员和其他直接责任人员处5日以上15日以下拘留
  构成犯罪的，依法追究刑事责任（刑法第143/144条 生产/销售不符合安全标准的食品罪/生产/销售有毒/有害食品罪）
```

### 生产/销售有毒有害食品罪（刑法第144条）⭐⭐⭐⭐⭐

```
构成要件：
  在生产/销售的食品中掺入有毒/有害的非食品原料的
  或者销售明知掺有有毒/有害的非食品原料的食品的
  或者在食品加工/销售过程中使用有毒/有害的非食品原料的
  或者在食用农产品种植/养殖/销售等活动中使用禁用农药/兽药等的

量刑：
  基本：5年以下有期徒刑或者拘役，并处罚金
  对人体健康造成严重危害/其他严重情节：5年以上10年以下有期徒刑，并处罚金
  致人死亡/特别严重情节：10年以上有期徒刑/无期徒刑/死刑，并处罚金/没收财产
```

## 食品消费者维权流程 ⭐⭐⭐⭐⭐

```
① 保存证据
   - 购买凭证（小票/订单/支付记录）
   - 食品实物（密封保存，冷藏）
   - 问题照片（发霉/变质/异物/过期标签等）
   - 就医记录（如有身体不适）

② 协商/投诉
   - 先与商家协商（保留聊天记录）
   - 协商不成 → 12315/12331（食品药品投诉）/市监局投诉
   - 食品安全举报热线：12331

③ 检测鉴定（可选）
   - 可自行送检（各地质检所/第三方检测机构）
   - 市监局调查时可申请官方检测

④ 赔偿主张
   - 退货款（100%）
   - 损失赔偿（医疗费/误工费/交通费等）
   - 惩罚性赔偿：价款10倍（最低1000元）
   - 精神损害抚慰金（造成人身损害时可主张）

⑤ 诉讼/仲裁
   - 协商调解不成可起诉
   - 简易程序小额诉讼（≤5万元）
   - 管辖：被告所在地/合同履行地
   - 举证：消费者只需主张，经营者/生产者举证证明食品安全
```

### 常见食品问题及赔偿参考

| 问题 | 赔偿依据 | 典型赔偿 |
|------|----------|----------|
| 食品过期 | 食安法第148条 | 退货款+10倍赔偿（最低1000元） |
| 食品发霉/变质 | 食安法第148条 | 同上 |
| 食品中有异物（钢丝/蟑螂/头发等） | 食安法第148条 | 同上 |
| 虚假生产日期/保质期 | 食安法第34条+148条 | 退货款+10倍赔偿 |
| 农药残留超标 | 食安法第148条 | 退货款+10倍赔偿 |
| 添加剂超量 | 食安法第148条 | 退货款+10倍赔偿 |
| 食品标签误导 | 消保法第55条 | 退货款+3倍赔偿（最低500元） |

## 高频问题速查

| 问题 | 答案 |
|------|------|
| 买到过期牛奶能赔多少？ | 退货款 + 10倍赔偿（最低1000元） |
| 食品里有头发？ | 同上，退+赔10倍 |
| 吃了拉肚子医院检查？ | 医疗费+误工费+10倍赔偿 |
| 保质期是食品"安全期"吗？ | 不是！保质期是最佳食用期，不是食品安全保证期 |
| 商家说"概不退换"？ | 违法！格式条款免除自身责任无效 |
| 网购食品维权？ | 可向销售者/平台/生产者任一方主张（连带责任） |
| 食品检测机构？ | 市场监管局下属检测中心/第三方检测机构 |
