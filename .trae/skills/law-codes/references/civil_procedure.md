# 中华人民共和国民事诉讼法（291 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 现行版本 | 2024年修正 |
| 条文总数 | 291 条 |
| 定位 | 民事诉讼基本程序法 |

---

## 核心条文速查

### 管辖（第18-39条）⭐⭐⭐

```
级别管辖：
  基层法院：第一审民事案件（原则）
  中级法院：
    ① 重大涉外案件
    ② 在本辖区有重大影响的案件
    ③ 最高院确定由中级法院管辖的案件
    ④ 专利纠纷/海事海商/知识产权一般由中院管辖（知产法院例外）
  高级法院：在本辖区有重大影响的案件
  最高法院：
    ① 在全国有重大影响的案件
    ② 认为应当由本院审理的案件

地域管辖（原告就被告，第22条）⭐⭐⭐：
  对公民提起诉讼 → 被告住所地法院；住所地与经常居住地不一致 → 经常居住地法院
  对法人/其他组织 → 被告住所地法院
  合同纠纷（第24条）：被告住所地 + 合同履行地
  专属管辖（第34条）：
    ① 不动产纠纷 → 不动产所在地法院
    ② 港口作业纠纷 → 港口所在地法院
    ③ 继承遗产纠纷 → 被继承人死亡时住所地/主要遗产所在地法院
  协议管辖（第35条）：合同/其他财产权益纠纷的当事人可以书面协议选择被告住所地/合同履行地/合同签订地/原告住所地/标的物所在地等与争议有实际联系的地点法院管辖（不得违反级别/专属管辖）
```

### 诉讼时效（民法典第188条）⭐⭐⭐⭐⭐

```
普通时效：3年（从知道/应当知道权利受损害及义务人之日起）
最长时效：20年（从权利受损害之日起）
→ 民法典已统一，民诉法不再重复规定时效内容，只规定时效中断/中止
→ 诉讼时效中断（民法典第195条）：起诉/仲裁/申请强制执行/权利人主张/义务人同意履行
→ 民事诉讼时效抗辩：当事人未提出时效抗辩的，法院不得主动适用时效规定
```

### 起诉与受理（第122-130条）⭐⭐

```
起诉条件（第122条）：
  ① 原告是与本案有直接利害关系的公民/法人/其他组织
  ② 有明确的被告
  ③ 有具体的诉讼请求和事实/理由
  ④ 属于法院受理民事诉讼的范围和受诉法院管辖
起诉材料：起诉状 + 证据清单 + 原告身份证明 + 被告身份信息
受理/不予受理：
  符合起诉条件 → 7日内立案
  不符合 → 7日内裁定不予受理（原告不服可上诉）
```

### 送达（第84-92条）

```
送达方式：
  ① 直接送达（首选）
  ② 留置送达（拒收时）
  ③ 委托送达
  ④ 邮寄送达（寄出之日起15日未退回的视为送达）
  ⑤ 电子送达（经受送达人同意，电子邮件/短信/传真等）
  ⑥ 公告送达（下落不明/其他方式无法送达 → 60日视为送达）
```

### 证据（第66-81条）⭐⭐⭐

```
证据种类：当事人陈述/书证/物证/视听资料/电子数据/证人证言/当事人陈述/鉴定意见/勘验笔录
举证责任（第67条）⭐⭐⭐：
  当事人对自己提出的主张，有责任提供证据
  → "谁主张，谁举证"
  例外：
    ① 产品质量（民法典第1199条等）→ 生产者/销售者举证
    ② 医疗损害（民法典第1218条）→ 医疗机构举证（5种过错推定情形）
    ③ 教育机构（民法典第1199条）→ 教育机构举证
    ④ 高空抛物（民法典第1254条）→ 可能加害者举证
    ⑤ 高度危险作业 → 经营者举证
    ⑥ 饲养动物 → 动物饲养人/管理人举证
  举证期限（民诉证据规定）：
    ① 一审普通程序：不少于15日
    ② 一审简易程序：≤15日
    ③ 小额诉讼：≤7日
    ④ 当事人可以协商举证期限（不超过法院指定的）
    ⑤ 逾期举证 → 法院可以责令说明理由，拒不说明/理由不成立的，法院可以不采纳该证据/采纳但予以训诫/罚款
```

### 审理程序

```
一审普通程序：
  立案 → 送达 → 举证 → 开庭审理（调查/辩论/最后陈述/调解）→ 宣判
  审限：6个月（有特殊情况需延长的，经本院院长批准，可延长6个月；还需延长的，报请上级法院批准）
一审简易程序（第162条）⭐⭐：
  基层法院和它派出的法庭审理事实清楚/权利义务关系明确/争议不大的简单民事案件，适用简易程序
  审限：3个月
小额诉讼（第165条）⭐⭐⭐：
  基层法院及其派出法庭审理事实清楚/权利义务关系明确/争议不大的简单金钱给付民事案件
  标的额为各省/自治区/直辖市上年度就业人员年平均工资50%以下的
  审限：2个月
  → **一审终审！** 不能上诉！
二审程序（第173-176条）：
  上诉期限：不服一审判决 → 判决书送达之日起15日内；不服一审裁定 → 裁定书送达之日起10日内
  审限：判决上诉3个月；裁定上诉30日
  二审裁判：驳回上诉维持原判/改判/撤销原判发回重审/直接改判
```

### 强制执行（第231-264条）⭐⭐⭐⭐⭐

```
申请执行期限（第246条）⭐⭐⭐⭐⭐最高频⭐⭐⭐⭐⭐：
  申请执行的期间为**2年**
  起算点：从法律文书规定履行期间的最后一日起计算
  法律文书规定分期履行的，从最后一期履行期限届满之日起计算
  法律文书未规定履行期间的，从法律文书生效之日起计算
  执行时效中止/中断：适用诉讼时效中止/中断的规定（民法典第194/195条）
执行措施（第249-255条）：
  ① 查询/冻结/划拨被执行人存款
  ② 查封/扣押/拍卖/变卖被执行人财产
  ③ 搜查被执行人住所/财产隐匿地
  ④ 强制被执行人交付法律文书指定交付的财物/票证
  ⑤ 强制被执行人迁出房屋/退出土地
  ⑥ 强制被执行人履行法律文书指定的行为
  ⑦ 加倍支付迟延履行期间的债务利息（第260条）⭐⭐⭐：
    被执行人未按判决/裁定和其他法律文书指定的期间履行给付金钱义务的，
    应当**加倍支付迟延履行期间的债务利息**（即2倍LPR利率）
  ⑧ 未履行非金钱义务 → 支付迟延履行金
  ⑨ 限制出境（第262条）
  ⑩ 在征信系统记录不履行义务信息（第262条）
  ⑪ 罚款/拘留（第114条）：
    拒不执行法院判决/裁定的 → 可处1-15日拘留/10万元以下罚款
    构成犯罪的 → 拒不执行判决裁定罪（刑法第313条，最高3年）

执行中止（第263条）：
  ① 申请人表示可以延期执行
  ② 案外人对执行标的提出确有理由的异议
  ③ 作为一方当事人的公民死亡，需要等待继承人继承权利/义务
  ④ 作为一方当事人的法人/其他组织终止，尚未确定权利义务承受人
  ⑤ 法院认为应当中止执行的其他情形

执行终结（第264条）：
  ① 申请人撤销申请
  ② 据以执行的法律文书被撤销
  ③ 作为被执行人的公民死亡，无遗产可供执行又无义务承担人
  ④ 追索赡养费/扶养费/抚养费案件的权利人死亡
  ⑤ 作为被执行人的公民因生活困难无力偿还借款，无收入来源又丧失劳动能力
  ⑥ 法院认为应当终结执行的其他情形
```

## 高频问题速查

| 问题 | 答案 |
|------|------|
| 起诉时效？ | 3年（民法典第188条），从知道被侵害之日起 |
| 起诉要准备什么？ | 起诉状 + 证据清单 + 原被告身份证明 |
| 不服一审判决怎么办？ | 15日内上诉（判决）/10日内（裁定） |
| 一审审限？ | 6个月（可延长）；简易3个月；小额2个月 |
| 申请执行期限？ | **2年**！逾期不申请法院不再执行 |
| 执行不回款怎么办？ | ① 申请财产调查 ② 申请将对方列入失信名单 ③ 申请拘留 ④ 追究拒不执行判决裁定罪 |
| 诉讼费用？ | 按标的额比例（1万以下50元；1-10万2.5%；10-20万2%...） |
| 谁出律师费？ | 原则上谁请谁出；合同约定/人身损害/知识产权/公益诉讼等可由败诉方承担 |
| 涉外案件审理期限？ | 不受国内审限限制 |
