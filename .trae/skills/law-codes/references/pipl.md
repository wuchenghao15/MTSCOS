# 中华人民共和国个人信息保护法（74 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 通过时间 | 2021年8月20日（第十三届全国人大常委会第三十次会议） |
| 生效时间 | 2021年11月1日 |
| 条文总数 | 74 条 |
| 定位 | 中国首部专门的个人信息保护法律，数据合规核心法律 |
| 配套 | 《数据安全法》《网络安全法》《民法典》人格权编 |

---

## 核心概念

```
个人信息（第4条）：
  以电子/其他方式记录的能够单独/结合其他信息识别特定自然人身份/反映特定自然人活动情况的各种信息，不包括匿名化处理后的信息
敏感个人信息（第28条）⭐⭐⭐：
  一旦泄露/非法使用容易导致自然人的人格尊严受到侵害/人身/财产安全受到危害的个人信息，包括：
  ① 生物识别（指纹/人脸/声纹/虹膜/DNA等）
  ② 宗教信仰
  ③ 特定身份（未成年人/妇女/老年人/残疾人/军人等）
  ④ 医疗健康（病史/基因/病历等）
  ⑤ 金融账户（银行卡号/支付账号/交易记录等）
  ⑥ 行踪轨迹（GPS/位置数据）
  ⑦ 未成年人的个人信息
  ⑧ 其他可能影响人身/财产安全的信息
个人信息主体：自然人
个人信息处理者：对个人信息进行处理的组织/个人
匿名化：对个人信息进行技术处理，使其无法识别且无法复原
去标识化：对个人信息进行处理，使其无法识别特定个人但可复原
自动化决策：通过计算机程序自动分析/预测个人的行为习惯/兴趣爱好/经济状况等，并据此作出决策
```

## 处理原则（第6-13条）⭐⭐⭐

| 原则 | 条文 | 含义 |
|------|------|------|
| 合法/正当/必要 | 第6条 | 处理个人信息应具有明确/合理目的，应与处理目的直接相关，采取对个人权益影响最小的方式；收集范围限于实现目的的最小范围 |
| 诚信原则 | 第7条 | 不得通过欺诈/诱骗/误导等方式处理个人信息 |
| 目的明确 | 第6条 | 应当具有明确/合理的目的 |
| 公开透明 | 第17条 | 应当以显著方式/清晰易懂的语言向个人告知处理目的/方式/范围等 |
| 质量原则 | 第8条 | 保证个人信息质量准确/完整；及时更正/补充 |
| 安全原则 | 第9条 | 采取足够技术/管理措施保障个人信息安全 |
| 权责一致 | 第10条 | 对其个人信息处理活动负责，并采取措施保障个人信息权益 |
| 国家利益优先 | 第13条 | 在法定情形下可豁免同意（见下） |

## 个人同意规则（第13-16条）⭐⭐⭐

```
需要取得个人同意的情形（第13条）：
  一般情况下处理个人信息应当取得个人同意
无需取得同意的情形（第13条第2款）⭐⭐⭐高频：
  ① 为国家安全/公共安全/刑事侦查/起诉/审判/裁判执行等法定情形
  ② 为公共利益/新闻报道/舆论监督/学术研究等
  ③ 自行公开/合法公开的个人信息，在公开范围内处理
  ④ 个人信息处理者自行决定处理的公共行政/公共安全/社会管理
  ⑤ 为保护个人/其他个人生命财产安全的紧急情况
  ⑥ 合同签订/履行所必需
  ⑦ 人力资源管理所必需
  ⑧ 金融机构/征信机构合法业务所必需
  ⑨ 其他法定情形
敏感个人信息的特殊规则（第28-29条）⭐⭐⭐：
  ① 处理敏感个人信息应取得单独同意（不能与其他同意打包）
  ② 需向个人告知处理的必要性以及对个人权益的影响
  ③ 法定情形无需同意的除外
未成年人个人信息（第31条）：
  不满14周岁未成年人的个人信息属于敏感个人信息
  处理应当取得其监护人的同意
个人同意的有效性（第14条）：
  基于自愿/明确/具体的意思表示；声明/合同中的格式条款不当然有效
个人同意的撤回（第15条）：
  个人可以撤回同意；撤回同意后处理者应停止处理（法定情形除外）
  撤回同意不影响撤回前基于个人同意已进行的处理活动的效力
自动化决策的同意（第24条）：
  个人可拒绝处理者仅通过自动化决策的方式作出对个人权益有重大影响的决定
  个人有权要求处理者予以说明（人工作出审核）
```

## 个人权利（第44-50条）⭐⭐

| 权利 | 条文 | 内容 |
|------|------|------|
| 知情权 | 第44条 | 知道处理者的处理目的/方式/范围/个人权利行使方式等 |
| 决定权 | 第44条 | 同意/拒绝处理/撤回同意/注销账号等 |
| 访问权 | 第44条 | 访问个人信息 |
| 更正权 | 第44条 | 更正不准确/不完整的个人信息 |
| 删除权（被遗忘权） | 第47条 | 请求删除个人信息的法定情形：① 处理目的已实现/无法实现；② 处理者停止提供产品/服务/个人注销账号；③ 个人撤回同意；④ 处理者违反法律/处理合同；⑤ 其他 |
| 解释权 | 第48条 | 请求处理者对自动化决策作出说明 |
| 可携带权 | 第45条 | 请求将个人信息转移给本人/第三方（技术可行） |
| 响应权 | 第48条 | 请求处理者采取措施消除对个人权益的不利影响 |
| 投诉权 | 第49条 | 个人信息处理活动侵害个人信息权益的，个人可向主管部门投诉/举报 |

## 跨境提供个人信息（第38-39条）⭐

```
合规路径：
  ① 通过国家网信部门组织的安全评估
  ② 按国家网信部门规定经专业机构进行个人信息保护认证
  ③ 按国家网信部门制定的标准合同与境外接收方订立合同（示范合同）
  ④ 法律/行政法规规定/国家网信部门规定的其他条件
禁止出境情形（第39条）：
  关键信息基础设施运营者和处理个人信息达到国家网信部门规定数量的个人信息处理者，应当将在境内收集/产生的个人信息存储在境内
向境外提供敏感个人信息：
  ① 应当取得个人单独同意
  ② 应当就敏感个人信息的处理等事项向个人告知境外接收方名称/联系方式/处理目的/处理方式/个人权利等
```

## 个人信息保护影响评估（PIA）（第55条）⭐

```
应当开展评估的情形：
  ① 处理敏感个人信息
  ② 利用个人信息进行自动化决策
  ③ 委托处理/对外提供/公开个人信息
  ④ 向境外提供个人信息
  ⑤ 其他对个人权益可能产生重大影响的处理活动
评估内容：
  ① 处理活动的合法性/正当性/必要性
  ② 对个人权益可能产生的影响及安全措施
  ③ 个人权益受到侵害的风险及应对措施
  ④ 评估报告应至少保存3年
```

## 法律责任（第66-71条）⭐⭐⭐

```
行政责任（第66条）⭐⭐⭐最高：
  违反本法规定处理个人信息/处理个人信息未履行安全保护义务：
  ① 责令改正/给予警告/没收违法所得/违法所得1-10倍罚款
  ② 责令暂停/终止个人信息处理活动/停业整顿
  ③ **情节严重的**：处5000万元以下/上一年度营业额5%以下罚款
  ④ **直接责任人**：处1-10万元罚款
  ⑤ 责令停业整顿/吊销相关业务许可/吊销营业执照
  ⑥ 对直接负责的主管人员和其他直接责任人员禁止担任相关职务
民事责任（第69条）：
  侵害个人信息权益造成损害的，依法承担民事责任
  个人信息处理者不能证明自己没有过错的，应当承担损害赔偿等责任（过错推定）
  侵权赔偿的损失赔偿额：
    ① 按个人因此受到的损失/个人信息处理者因此获得的利益确定
    ② 难以确定的，按实际处理相关个人信息的数量/违法所得/为制止侵权所支付的合理开支等确定
  公益诉讼（第70条）：
    违反本法规定处理个人信息，侵害众多个人的权益的，检察院/规定的组织可提起公益诉讼
刑事责任（第71条）：
  违反本法规定，构成犯罪的，依法追究刑事责任
  → 涉及刑法第253条之一（侵犯公民个人信息罪）
个人可以行使的权利（第69条）：
  非法处理个人信息的，个人可请求处理者停止处理/删除个人信息/更正不准确的信息/解释自动化决策的逻辑/采取措施消除对个人权益的不利影响
```

## 与民法典关系

```
民法典人格权编（第1032-1039条）规定了隐私权和个人信息保护的民事基本规则
《个人信息保护法》是特别法，优先适用
民法典的核心要点：
  - 自然人享有隐私权
  - 个人信息处理应遵循合法/正当/必要原则
  - 敏感个人信息需单独同意
  - 特别强调未成年人/个人生物信息等敏感信息保护
```

## 高频问题速查

| 问题 | 答案 |
|------|------|
| 哪些个人信息算敏感？ | 第28条（生物识别/宗教/医疗健康/金融账户/行踪轨迹/未成年人/特定身份等） |
| 无需同意的情形？ | 第13条（国家安全/公共利益/自行公开/紧急情况/合同必需等8种） |
| 可以出售个人信息吗？ | 原则上不行；公开/合法公开的个人信息可能可以；敏感个人信息严格限制 |
| 被遗忘权适用条件？ | 第47条（处理目的已实现/撤回同意/注销账号/违反法律等5种） |
| 跨境传输怎么合规？ | 安全评估/认证/标准合同（3种路径） |
| 最高罚款多少？ | 5000万元 或 上一年度营业额5%（取更高者） |
| 个人信息泄露怎么办？ | ① 要求删除/更正 ② 投诉主管部门 ③ 起诉 ④ 公益诉讼（检察院） |
| 企业做 PIA 情形？ | 第55条（敏感个人信息/自动化决策/委托处理/对外提供/跨境等） |
