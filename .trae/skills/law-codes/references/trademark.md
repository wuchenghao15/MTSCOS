# 中华人民共和国商标法（73 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 现行版本 | 2019年4月23日修正 |
| 条文总数 | 73 条 |
| 定位 | 商标领域基本法律 |
| 核心 | 申请在先 + 保护在先 + 驰名商标特别保护 |

---

## 核心条文速查

### 商标注册申请原则（第4-32条）⭐⭐⭐

```
申请在先原则（第31条）⭐⭐⭐⭐：
  两个或两个以上的商标注册申请人，在同一种商品/类似商品上，以相同/近似的商标申请注册的，
  初步审定并公告**申请在先**的商标
  同一天申请的 → 初步审定并公告**使用在先**的商标
  同日申请且都未使用的 → 申请人抽签决定

自愿注册原则（第4条）：
  自然人/法人/其他组织在生产经营活动中，对其商品/服务需要取得商标专用权的，应当向商标局申请商标注册
  → 商标自愿注册，但**烟草制品必须注册商标**才能销售（第6条）

禁止注册/使用的商标（第8-14条）⭐⭐⭐：
  绝对禁止注册（第10条）：
    ① 同中华人民共和国国家名称/国旗/国徽/国歌/军旗/军徽等相同/近似的
    ② 同外国的国家名称/国旗/国徽/军旗相同/近似的（该国政府同意除外）
    ③ 同政府间国际组织的名称/旗帜/徽记等相同/近似的
    ④ 与表明实施控制/予以保证的官方标志/检验印记相同/近似的（授权除外）
    ⑤ 同"红十字""红新月"的名称/标志相同/近似的
    ⑥ 带有民族歧视性的
    ⑦ 带有欺骗性，容易使公众对商品的质量等特点/产地产生误认的
    ⑧ 有害于社会主义道德风尚/有其他不良影响的
    ⑨ 县级以上行政区划的地名/公众知晓的外国地名（地名有其他含义/作为集体商标/证明商标组成部分除外；已注册的地名商标继续有效）
  相对禁止注册（第11-13条）：
    ① 仅有本商品的通用名称/图形/型号的
    ② 仅直接表示商品的质量/主要原料/功能/用途/重量/数量及其他特点的
    ③ 其他缺乏显著特征的
    （以上经过使用取得显著特征并便于识别的，可以注册）
    ④ 与他人已注册/初步审定的商标相同/近似的
    ⑤ 侵犯他人在先权利的（著作权/姓名权/肖像权/字号权等）
    ⑥ 以欺骗/其他不正当手段取得注册的
    ⑦ 抢注他人未注册驰名商标（第13条第1款）
    ⑧ 复制/摹仿/翻译他人已注册驰名商标（第13条第2款）
    ⑨ 未经授权，代理人/代表人以自己的名义将被代理人/被代表人的商标进行注册（第15条）
    ⑩ 申请商标注册损害他人现有的在先权利/以不正当手段抢先注册他人已经使用并有一定影响的商标（第32条）⭐⭐⭐⭐⭐抢注⭐⭐⭐⭐⭐
```

### 注册商标有效期与续展（第39-40条）⭐⭐⭐

```
有效期（第39条）：
  注册商标的有效期为**10年**，自核准注册之日起计算
续展（第40条）⭐⭐⭐：
  注册商标有效期满，需要继续使用的，
  商标注册人应当在期满前**12个月内**按照规定办理续展手续
  在此期间未能办理的，可以给予**6个月的宽展期**
  每次续展注册的有效期为**10年**，自该商标上一届有效期满次日起计算
  期满未办理续展手续的 → 注销其注册商标
```

### 商标无效与撤销（第44-50条）⭐⭐⭐

```
宣告无效（第44-45条）：
  绝对理由（第44条第1款，任何人可申请）：
    ① 使用本法第4条规定（不以使用为目的的恶意注册）
    ② 使用本法第10条规定（绝对禁止标志）
    ③ 使用本法第11条规定（缺乏显著特征）
    ④ 使用本法第12条规定（三维标志功能性）
    ⑤ 以欺骗/其他不正当手段取得注册的
    → 无时间限制！任何时候都可以申请无效宣告
  相对理由（第45条第1款，利害关系人申请）：
    ① 违反本法第13条（驰名商标）
    ② 违反本法第15条（代理人/代表人抢注）
    ③ 违反本法第16条第1款（地理标志误导）
    ④ 违反本法第30条（近似商标）
    ⑤ 违反本法第31条（在先申请）
    ⑥ 违反本法第32条（在先权利/抢注有一定影响的商标）
    → 申请期限：**自商标注册之日起5年内**
    → 恶意注册 + 驰名商标所有人不受5年限制（第45条第2款）

撤销（第49条）：
  ① 自行改变注册商标/注册人名义地址/其他注册事项的 → 自行改正/商标局撤销
  ② 注册商标成为其核定使用的商品的通用名称的
  ③ 没有正当理由连续**3年**不使用的（撤三）⭐⭐⭐⭐⭐
    → 任何人可以向商标局申请撤销该注册商标
    → 商标注册人应当提交该商标在撤销申请提出前**3年**内使用的证据材料/不使用的正当理由
    → 不使用的正当理由：不可抗力/政府政策限制/其他不可归责于商标注册人的正当事由
    → 注意："撤三"是打击商标囤积的利器！
```

### 商标侵权（第57-63条）⭐⭐⭐⭐⭐

```
商标侵权行为（第57条）⭐⭐⭐⭐⭐最高频⭐⭐⭐⭐⭐：
  ① 未经商标注册人的许可，在同一种商品上使用与其注册商标相同的商标
  ② 未经商标注册人的许可，在同一种商品上使用与其注册商标近似的商标，或者在类似商品上使用与其注册商标相同/近似的商标，容易导致混淆的
  ③ 销售侵犯注册商标专用权的商品的
  ④ 伪造/擅自制造他人注册商标标识/销售伪造/擅自制造的注册商标标识的
  ⑤ 未经商标注册人同意，更换其注册商标并将该更换商标的商品又投入市场的（反向假冒）
  ⑥ 故意为侵犯他人商标专用权行为提供便利条件，帮助他人实施侵犯商标专用权行为的
  ⑦ 给他人的注册商标专用权造成其他损害的

商标侵权赔偿（第63条）⭐⭐⭐⭐⭐最高频⭐⭐⭐⭐⭐：
  赔偿数额计算方式：
    ① 实际损失 → 按被侵权人实际损失确定
    ② 侵权获利 → 实际损失难以确定的，按照侵权人因侵权所获得的利益确定
    ③ 合理许可费 → 权利人损失/侵权获利难以确定的，参照该商标许可使用费的倍数合理确定
    ④ 法定赔偿 → 以上都难以确定的，由法院根据侵权行为的情节判决给予**500万元以下**的赔偿
  惩罚性赔偿（第63条第1款）⭐⭐⭐⭐⭐：
    对恶意侵犯商标专用权，情节严重的，可以在按照上述方法确定数额的**一倍以上五倍以下**确定赔偿数额
  权利人因被侵权所受到的实际损失/侵权人因侵权所获得的利益/注册商标许可使用费难以确定的，
  由法院根据侵权行为的情节判决给予**500万元以下**的赔偿
  赔偿数额应当包括权利人为制止侵权行为所支付的**合理开支**（律师费/公证费/调查取证费等）

销售者免除赔偿条件（第64条第2款）⭐⭐⭐：
  销售不知道是侵犯注册商标专用权的商品，能证明该商品是自己合法取得并说明提供者的，不承担赔偿责任
  → 但应当停止销售！只是不赔钱
```

### 驰名商标保护（第13条）⭐⭐⭐

```
驰名商标的跨类别保护（第13条第2款）：
  已注册驰名商标 → 他人在不相同/不类似的商品上使用容易误导公众的，也构成侵权
未注册驰名商标（第13条第1款）：
  未注册但已驰名的商标 → 他人在相同/类似商品上使用容易导致混淆的，禁止注册和使用

驰名商标认定（第14条）：
  认定驰名商标应当考虑下列因素：
    ① 相关公众对该商标的知晓程度
    ② 该商标使用的持续时间
    ③ 该商标的任何宣传工作的持续时间/程度和地理范围
    ④ 该商标作为驰名商标受保护的记录
    ⑤ 该商标驰名的其他因素
  → 认定机关：商标局/商标评审委员会/法院（商标局/商评委/法院根据案件需要认定）
  → **驰名商标不能作为宣传用语！** 生产/经营者不得将"驰名商标"字样用于商品/商品包装/容器上，或者用于广告宣传/展览以及其他商业活动中（第53条）
```

### 商标抢注 ⭐⭐⭐⭐⭐

```
常见抢注类型：
  ① 抢注他人在先使用并有一定影响的未注册商标（第32条）
  ② 抢注他人未注册驰名商标（第13条第1款）
  ③ 代理人/代表人抢注被代理人/被代表人的商标（第15条）
  ④ 抢注他人在先使用的相同/近似商标（第31条同日申请）
  ⑤ 恶意注册（不以使用为目的，第4条）

抢注救济：
  ① 初审公告期提出异议（第33条）：公告之日起3个月内
  ② 注册后申请无效宣告（第45条）：注册之日起5年内（驰名商标不受时间限制）
  ③ 恶意注册 → 商标局/商评委可宣告无效（不受5年限制）
  ④ 要求赔偿因抢注造成的损失
```

## 高频问题速查

| 问题 | 答案 |
|------|------|
| 商标有效期？ | 10年，到期前12个月内续展，宽展期6个月 |
| 同天申请谁赢？ | 使用在先；没使用的抽签 |
| 商标"撤三"？ | 连续3年不使用，任何人可申请撤销；商标权人需举证使用 |
| 抢注了怎么办？ | 初审公告3个月内异议 / 注册后5年内无效宣告（驰名商标不受5年限制） |
| 销售假货要赔钱吗？ | 不知道是假货+合法渠道+能说明提供者 → 不赔钱但要停止销售 |
| 商标侵权最高赔多少？ | 500万元（法定赔偿上限）；恶意侵权可1-5倍惩罚性赔偿 |
| 驰名商标好处？ | 跨类别保护（别人不能在不类似商品上用相同/近似商标） |
| 能用"驰名商标"做广告吗？ | **绝对不行！** 违法，会被罚款 |
| 商标被驳回怎么办？ | 15日内申请复审（商标评审委员会）；不服起诉北京知产法院 |
