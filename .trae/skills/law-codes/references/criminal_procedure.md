# 中华人民共和国刑事诉讼法（347 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 现行版本 | 2018年10月26日修正 |
| 条文总数 | 347 条 |
| 定位 | 刑事诉讼基本程序法 |
| 核心 | 未经法院依法判决不得确定任何人有罪（第12条） |

---

## 核心条文速查

### 刑事诉讼基本原则

```
无罪推定（第12条）⭐⭐⭐⭐⭐：
  未经人民法院依法判决，对任何人都不得确定有罪
  → 核心要求：
    ① 公诉案件中被告人有罪的举证责任由检察院承担
    ② 不得强迫任何人证实自己有罪（第56条）
    ③ 证据不足不能认定被告人有罪的，应当作出证据不足/指控的犯罪不能成立的无罪判决（第200条）
    ④ 上诉不加刑（第237条）

三机关分工负责（第7条）：
  公安机关负责对刑事案件的侦查/拘留/执行逮捕/预审
  人民检察院负责批准逮捕/对直接受理的案件实行侦查/提起公诉
  人民法院负责审判
  三者分工负责，互相配合，互相制约

两审终审制（第10条）：
  法院审判案件，实行两审终审制
  最高院一审判决/裁定是终审的判决/裁定
```

### 强制措施（第66-100条）⭐⭐⭐⭐⭐

```
拘传（第66条）：
  对未被羁押的犯罪嫌疑人/被告人，经传唤无正当理由拒不到案的，可以拘传
  也可以根据案件情况直接拘传
  每次拘传持续时间不得超过12小时；案情特别重大复杂需采取拘留/逮捕措施的，不得超过24小时

取保候审（第67条）⭐⭐⭐：
  适用条件：
    ① 可能判处管制/拘役/独立适用附加刑的
    ② 可能判处有期徒刑以上刑罚，采取取保候审不致发生社会危险性的
    ③ 患有严重疾病/生活不能自理/怀孕/正在哺乳自己婴儿的妇女，采取取保候审不致发生社会危险性的
    ④ 羁押期限届满，案件尚未办结，需要采取取保候审的
    ⑤ 其他法定情形
  禁止取保候审（第81条）：
    ① 可能实施新的犯罪
    ② 有危害国家安全/公共安全/社会秩序的现实危险
    ③ 可能毁灭/伪造证据，干扰证人作证/串供
    ④ 可能对被害人/举报人/控告人实施打击报复
    ⑤ 企图自杀/逃跑
  取保候审期限：最长不超过12个月
  保证方式：保证人/保证金（一般5000-10万元）
  
监视居住（第74条）：
  适用条件（比取保候审严格）：
    ① 符合逮捕条件，但患有严重疾病/生活不能自理/怀孕/正在哺乳/系生活不能自理人的唯一扶养人
    ② 羁押期限届满，案件尚未办结，需要采取监视居住措施的
    ③ 符合取保候审条件，但犯罪嫌疑人/被告人不能提出保证人/不交纳保证金
  期限：最长不超过6个月

刑事拘留（第82条）⭐⭐⭐⭐⭐最高频⭐⭐⭐⭐⭐：
  公安机关对于现行犯/重大嫌疑分子，有下列情形之一的，可以先行拘留：
    ① 正在预备犯罪/实行犯罪/犯罪后即时被发觉
    ② 被害人/在场亲眼看见的人指认他犯罪
    ③ 在身边/住处发现有犯罪证据
    ④ 犯罪后企图自杀/逃跑/在逃
    ⑤ 有毁灭/伪造证据/串供可能
    ⑥ 不讲真实姓名/住址，身份不明
    ⑦ 有流窜作案/多次作案/结伙作案重大嫌疑
  拘留期限（第91条）⭐⭐⭐：
    一般：3日内提请检察院批捕（检察院7日内决定）
    特殊：1-4日内提请
    流窜/多次/结伙作案：30日内提请
    总计：3+7=10日 / 4+7=11日 / 30+7=37日⭐⭐⭐（最长期限）
  拘留后：24小时内送看守所 + 通知家属 + 讯问

逮捕（第81条）：
  对有证据证明有犯罪事实，可能判处徒刑以上刑罚的犯罪嫌疑人/被告人，采取取保候审尚不足以防止发生下列社会危险性的，应当予以逮捕：
    ① 可能实施新的犯罪
    ② 有危害国家安全/公共安全/社会秩序的现实危险
    ③ 可能毁灭/伪造证据，干扰证人作证/串供
    ④ 可能对被害人/举报人/控告人实施打击报复
    ⑤ 企图自杀/逃跑
  检察院批捕审查期限（第91条）：7日；重大复杂可延长7日
  逮捕后：24小时内送看守所 + 通知家属 + 讯问

强制措施最长羁押期限速查 ⭐⭐⭐⭐⭐：
  拘传：≤12小时（案情重大≤24小时）
  取保候审：≤12个月
  监视居住：≤6个月
  拘留：≤37天（流窜/多次/结伙）
  逮捕后侦查羁押：
    一般：2个月
    案情复杂可延长1个月（第156条）
    交通十分不便/边远地区/重大复杂/流窜作案/涉及面广取证困难：再延长2个月（第158条）
    可能判处10年以上：再延长2个月（第159条）
    → 最长可达：2+1+2+2=7个月
  检察院审查起诉：1.5个月（可退回补充侦查2次，每次1个月）→ 最长6.5个月
```

### 辩护权（第11-16条 + 第33-49条）⭐⭐⭐⭐⭐

```
委托辩护时间（第34条）⭐⭐⭐：
  ① 犯罪嫌疑人自被侦查机关第一次讯问/采取强制措施之日起，有权委托辩护人
  ② 在侦查期间，只能委托律师作为辩护人
  ③ 被告人有权随时委托辩护人
  ④ 侦查机关在第一次讯问犯罪嫌疑人/对犯罪嫌疑人采取强制措施时，应当告知其有权委托辩护人

辩护与代理（第33条）：
  下列人员可以被委托为辩护人：
    ① 律师
    ② 人民团体/犯罪嫌疑人/被告人所在单位推荐的人
    ③ 犯罪嫌疑人/被告人的监护人/亲友
  下列人员不得担任辩护人：
    ① 正在被执行刑罚/处于缓刑/假释考验期间的人
    ② 依法被剥夺/限制人身自由的人
    ③ 无行为能力/限制行为能力的人
    ④ 法院/检察院/公安/国家安全机关/监狱的现职工作人员
    ⑤ 人民陪审员
    ⑥ 与本案审理结果有利害关系的人
    ⑦ 外国人/无国籍人

法律援助（第35条）⭐⭐⭐⭐⭐：
  犯罪嫌疑人/被告人因经济困难/其他原因没有委托辩护人的，本人/近亲属可以向法律援助机构申请法律援助
  法定情形应当法律援助（第35条第2款）⭐⭐⭐：
    ① 盲/聋/哑人
    ② 尚未完全丧失辨认/控制自己行为能力的精神病人
    ③ 可能被判处无期徒刑/死刑的
    ④ 未成年人
    ⑤ 经济困难或者其他原因没有委托辩护人
    ⑥ 缺席审判程序（第293条）
    → 以上情形，司法机关应当通知法律援助机构指派律师为其提供辩护

侦查阶段辩护律师权利（第38条）⭐⭐⭐：
  ① 可以同在押的犯罪嫌疑人会见/通信（第39条）
    会见持律师执业证书/律师事务所证明/委托书/法律援助函件
    看守所应当在48小时内安排会见
    涉及危害国家安全/恐怖活动犯罪的，侦查阶段会见需经侦查机关许可
    会见时不被监听！
  ② 辩护律师可以向侦查机关了解犯罪嫌疑人涉嫌的罪名和案件有关情况，提出意见
  ③ 有权申请变更强制措施
  ④ 有权提出取保候审申请
  ⑤ 有权申诉/控告
  ⑥ 有权申请调取证据/自行收集证据
  ⑦ 自检察院审查起诉之日起，可以查阅/摘抄/复制本案案卷材料
```

### 认罪认罚从宽（第15条 + 第182-190条）⭐⭐⭐⭐⭐

```
认罪认罚从宽制度（第15条）：
  犯罪嫌疑人/被告人自愿如实供述自己的罪行，承认指控的犯罪事实，愿意接受处罚的，可以依法从宽处理
适用条件：
  ① 自愿认罪：承认指控的犯罪事实，愿意接受法律制裁
  ② 自愿认罚：愿意接受检察院提出的量刑建议并签署认罪认罚具结书
不能适用（第181条）：
  ① 犯罪嫌疑人/被告人是盲/聋/哑人，或者是尚未完全丧失辨认/控制自己行为能力的精神病人
  ② 未成年犯罪嫌疑人/被告人的法定代理人对认罪认罚有异议
  ③ 其他不适用认罪认罚从宽制度的情形

从宽幅度：
  综合考虑：犯罪性质/情节/危害后果/社会危险性/认罪认罚时间/认罪认罚程度等
  侦查/审查起诉阶段认罪认罚 → 从宽幅度可以更大
  审判阶段认罪认罚 → 也可从宽，但幅度较小
  法定从轻/减轻：自首/坦白/立功等情节，与认罪认罚叠加
```

### 速裁程序（第222-226条）⭐⭐

```
适用条件（第222条）：
  ① 基层法院管辖
  ② 可能判处3年有期徒刑以下刑罚
  ③ 案件事实清楚，证据确实充分
  ④ 被告人认罪认罚
  ⑤ 被告人同意适用速裁程序
审限：法院应当在受理后**10日内**审结；可能判处有期徒刑超过1年的，可以延长至15日
不适用：
  ① 被告人是盲/聋/哑人或者尚未完全丧失辨认/控制自己行为能力的精神病人
  ② 被告人是未成年人
  ③ 案件有重大社会影响
  ④ 共同犯罪案件中部分被告人对指控的犯罪事实/罪名/量刑建议/适用速裁程序有异议
  ⑤ 其他不宜适用速裁程序审理的
```

### 侦查羁押期限总结 ⭐⭐⭐⭐⭐

| 阶段 | 最长期限 | 说明 |
|------|----------|------|
| 传唤/拘传 | ≤24小时 | 一般≤12小时 |
| 拘留 | **37天** | 流窜/多次/结伙作案 |
| 逮捕后侦查 | **7个月** | 2+1+2+2（可超，需最高检批） |
| 审查起诉 | **6.5个月** | 1.5月+两次退侦每次1月 |
| 一审 | **6个月** | 普通程序（可延长） |
| 速裁程序 | **15日** | 3年以下+认罪认罚 |
| 二审 | **3个月** | 判决上诉（可延长2个月） |
| 二审终审 | **立即生效** | 判决/裁定作出之日起生效 |

## 高频问题速查

| 问题 | 答案 |
|------|------|
| 被抓后多久通知家属？ | 拘留/逮捕后24小时内（除有碍侦查/无法通知外） |
| 刑事拘留最长多久？ | **37天**（流窜/多次/结伙），到期必须批捕/取保候审/监视居住/释放 |
| 拘留期间能请律师吗？ | **能！** 第一次讯问/采取强制措施后即可委托；侦查阶段只能委托律师 |
| 律师会见要多久？ | 看守所48小时内安排；危害国安/恐怖活动需侦查机关许可 |
| 取保候审保证人条件？ | 与本案无牵连/有能力履行保证义务/享有政治权利/人身自由未受限/有固定住处和收入 |
| 37天后没批捕怎么办？ | 必须释放/取保候审/监视居住 |
| 认罪认罚能减多少？ | 一般可减基准刑10-30%；主动早认罪减幅大 |
| 速裁程序好吗？ | 快（10-15日审结），但一审终审不能上诉 |
| 上诉不加刑？ | 是的（第237条），检察院抗诉/自诉人上诉除外 |
