# 生成式人工智能服务管理暂行办法（23 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 施行时间 | **2023年8月15日** |
| 条文总数 | **23 条** |
| 发布机构 | 国家网信办/工信部/公安部 |
| 定位 | 全球首部生成式AI专项立法 |
| 适用范围 | 在中国境内提供生成式AI服务/组织生产AI模型 |

---

## 核心要求速查

### 生成式AI定义（第2条）⭐

```
生成式人工智能：
  指基于算法/模型/规则生成文本/图片/音频/视频/代码等内容的技术
  包括：大语言模型（LLM）/AI绘画/AI视频/AI代码生成等
不包括：
  仅为提高工作效率而使用的文字摘要/图片压缩/语音转写等
  对已有内容进行分类/检索/推荐/排序等不生成新内容的
```

### 提供主体资质（第4条）⭐⭐⭐

```
提供生成式AI服务：
  ① 算法备案：应当依法履行算法备案手续（通过互联网信息服务算法备案系统）
  ② 安全评估：具备安全评估能力，确保生成内容符合法律法规
  ③ 安全机制：建立健全安全管理/内容审核/投诉举报等制度
  ④ 技术措施：采取技术措施防范违法有害内容生成
  ⑤ 应急处置：建立安全事件应急处置机制

组织生产AI模型（第5条）：
  ① 训练数据来源合法：不得侵害他人合法权益，不得违法收集/处理数据
  ② 训练数据质量：采取有效措施提高数据质量，避免歧视/偏见
  ③ 数据安全：采取必要技术措施保护训练数据安全
  ④ 安全测试：模型上线前应当进行安全测试和评估
```

### 内容合规要求（第6-10条）⭐⭐⭐⭐⭐

```
禁止生成违法有害内容（第6条）：
  生成的内容不得含有：
  ① 反对宪法确定的基本原则的
  ② 危害国家安全/泄露国家秘密/颠覆国家政权/破坏国家统一的
  ③ 损害国家荣誉和利益的
  ④ 煽动民族仇恨/民族歧视/破坏民族团结的
  ⑤ 破坏国家宗教政策/宣扬邪教和封建迷信的
  ⑥ 散布谣言/扰乱社会秩序/破坏社会稳定的
  ⑦ 散布淫秽/色情/赌博/暴力/凶杀/恐怖/教唆犯罪的
  ⑧ 侮辱或者诽谤他人/侵害他人合法权益的
  ⑨ 含有虚假/有害/胁迫/骚扰/商业广告等干扰他人正常生活的内容
  ⑩ 含有欺诈/引诱他人实施违背社会公德行为的内容

不得提供以下服务（第10条）：
  ① 生成/传播含有本条第6条所列违法有害内容的内容
  ② 诱导用户沉迷
  ③ 生成/传播可能诱导未成年人不良行为的内容
  ④ 模拟新闻报道/虚构事实误导公众
  ⑤ 生成/传播能识别自然人身份的人脸/指纹等生物特征信息（未经单独同意）

深度合成标识（第12条）⭐⭐⭐：
  提供生成式AI服务生成的内容应当依法采取以下措施：
  ① 生成的图片/视频/音频内容，应当添加不影响使用的水印/标识，表明内容由AI生成
  ② 生成的文本内容，应当以显著方式标识"本内容由AI生成"
  ③ 生成的合成人脸/人体的图片/视频，应当依法采取技术措施进行保护

知识产权保护（第13条）⭐：
  生成式AI服务提供者应当尊重他人知识产权，不得侵犯他人著作权/肖像权/名誉权/隐私权等合法权益
  用户使用生成式AI服务生成的内容侵犯他人合法权益的，生成式AI服务提供者应当采取必要措施防止侵害

个人信息保护（第14条）：
  生成式AI服务提供者应当遵守个人信息保护法等法律规定
  不得通过生成式AI服务非法收集/处理/使用个人信息
```

### 算法备案与安全评估（第5条+第15条）⭐⭐⭐

```
算法备案（《互联网信息服务算法推荐管理规定》）：
  利用算法从事信息分发/搜索/个性化推荐/生成合成内容的互联网信息服务提供者应当履行算法备案
  备案内容：算法基本原理/运行机制/适用场景/责任主体/安全评估等
  国家网信部门：算法备案系统（https://beian.cac.gov.cn）

生成式AI专项备案：
  提供生成式AI服务，应当在规定时间内通过国家网信部门规定的系统履行备案手续
  备案系统：国家网信办"生成式人工智能服务备案系统"

境外组织/个人在中国境内提供生成式AI服务（第22条）：
  国务院网信部门指定的机构认定安全评估通过的，可以作为生成式AI服务提供者开展服务
  否则不得开展
```

### 法律责任（第21条）⭐⭐

```
行政责任：
  ① 由网信部门/公安部门责令改正，给予警告，没收违法所得，处违法所得1倍以上10倍以下罚款
  ② 没有违法所得或者违法所得不足1万元的，处1万元以上10万元以下罚款
  ③ 情节严重的，责令暂停相关业务/停业整顿/关闭网站/吊销相关业务许可证或者吊销营业执照
  ④ 对直接负责的主管人员和其他直接责任人员处1万元以上10万元以下罚款
民事责任：
  生成式AI服务提供者违反本法规定，侵害他人合法权益的，依法承担民事责任
刑事责任：
  生成式AI服务提供者违反本法规定，构成犯罪的，依法追究刑事责任
  可能涉及罪名：
    - 非法侵入计算机信息系统罪（刑法第285条）
    - 破坏计算机信息系统罪（刑法第286条）
    - 侵犯公民个人信息罪（刑法第253条之一）
    - 侮辱罪/诽谤罪（刑法第246条）
    - 寻衅滋事罪（刑法第293条）
```

## 高频问题速查

| 问题 | 答案 |
|------|------|
| 个人用AI绘画/写文章违法吗？ | 一般不违法。但如果用来生成违法内容/侵犯他人权益/深度合成就不行 |
| 企业用生成式AI必须备案？ | 是的！在中国境内提供服务必须算法备案+生成式AI备案 |
| AI生成内容算谁的？ | 目前法律无明确规定。但生成式AI服务提供者要对其提供的服务负责；用户也要对自己的使用行为负责 |
| 用AI生成明星/名人肖像？ | 违法！侵犯肖像权/名誉权/隐私权 |
| AI训练数据爬取受版权保护作品？ | 灰色地带。目前中国无明确训练数据版权豁免规定，可能构成侵权 |
| 生成式AI安全评估怎么搞？ | ① 自行评估+第三方评估 ② 评估报告提交网信部门 ③ 定期更新 |
