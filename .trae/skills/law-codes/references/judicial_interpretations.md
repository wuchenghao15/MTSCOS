## 一、民法典配套司法解释（现行有效）⭐⭐⭐⭐⭐

### 《最高人民法院关于适用〈中华人民共和国民法典〉总则编若干问题的解释》（2022）

| # | 主题 | 要点 |
|---|------|------|
| 1 | 民事法律行为效力 | 违反法律/行政法规强制性规定 → 无效；强制性规定不包括管理性规定 |
| 2 | 显失公平（第151条） | 合同成立时一方利用对方处于危困状态/缺乏判断能力等情形，致使民事法律行为成立时显失公平的 → 可撤销 |
| 3 | 重大误解（第147条） | 行为人因对行为的性质/对方当事人/标的物的品种/质量/规格/数量等的错误认识，使行为的后果与自己的意思相悖，并造成较大损失 → 可撤销；**重大误解要在知道/应当知道之日起90日内行使撤销权** |
| 4 | 欺诈（第148条） | 一方故意告知对方虚假情况，或者故意隐瞒真实情况，诱使对方作出错误意思表示 → 可撤销 |
| 5 | 胁迫（第150条） | 一方/第三人以给另一方/其近亲属的生命/身体/健康/名誉/荣誉/财产等造成损害为要挟，迫使对方作出违背真实意思表示 → 可撤销 |
| 6 | 无权代理（第171条） | 行为人没有代理权/超越代理权/代理权终止后仍然实施代理行为 → 未经被代理人追认的，对被代理人不发生效力；相对人可以催告被代理人在1个月内予以追认 |
| 7 | 诉讼时效起算 | 有履行期限的 → 期限届满之日起算；无履行期限的 → 债权人首次主张权利时起算；分期履行 → 最后一期届满之日起算 |

### 《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》（2023）

| # | 主题 | 要点 |
|---|------|------|
| 1 | 合同成立 | 合同书形式：签字/盖章/按手印成立；电子合同：收件人指定的特定系统/任何能查收的系统收到生效 |
| 2 | 违约金调整（第585条） | 约定违约金低于造成的损失 → 可请求增加；约定违约金过分高于造成的损失（**超过实际损失的30%**）→ 可请求适当减少 |
| 3 | 定金罚则（第586-587条）⭐⭐⭐ | 债务人履行债务的，定金应当抵作价款/收回；给付定金的一方不履行债务/履行债务不符合约定致使不能实现合同目的 → **无权请求返还定金**；收受定金的一方不履行债务/履行债务不符合约定致使不能实现合同目的 → **应当双倍返还定金**；定金不得超过主合同标的额的**20%**，超过部分无效 |
| 4 | 不可抗力（第180条） | 不能预见/不能避免/不能克服的客观情况 → 免除责任；包括自然灾害/疫情/战争/政府行为等；疫情一般认定为不可抗力 |
| 5 | 情势变更（第533条）⭐⭐⭐ | 合同成立后客观情况发生了当事人在订立合同时无法预见的/不属于商业风险的重大变化，继续履行合同对于当事人一方明显不公平 → 可请求法院变更/解除合同 |
| 6 | 合同解除（第562-563条） | 法定解除情形：① 不可抗力致使不能实现合同目的 ② 履行期限届满前，一方明确表示/以自己行为表明不履行主要债务 ③ 一方迟延履行主要债务，经催告后在合理期限内仍未履行 ④ 一方迟延履行债务/有其他违约行为致使不能实现合同目的 ⑤ 其他情形；行使解除权期限：法律规定/当事人约定的期限内；未规定/约定的，自解除权人知道/应当知道解除事由之日起**1年内**不行使/经对方催告后在合理期限内不行使 → 该权利消灭 |

### 《最高人民法院关于适用〈中华人民共和国民法典〉婚姻家庭编的解释（一）》（2021）⭐⭐⭐⭐⭐

| # | 主题 | 要点 |
|---|------|------|
| 1 | 彩礼返还（第5条）⭐⭐⭐⭐⭐ | 当事人请求返还按照习俗给付的彩礼的，如果查明属于以下情形，法院应当予以支持：① 双方**未办理结婚登记手续** ② 双方办理结婚登记手续但**确未共同生活** ③ **婚前给付并导致给付人生活困难**；适用②③的规定，应当以双方离婚为条件 |
| 2 | 夫妻共同财产（第25条）⭐⭐⭐ | 婚姻关系存续期间，下列财产属于共同财产：① 工资/奖金/劳务报酬 ② 生产/经营/投资的收益 ③ 知识产权的收益 ④ 继承/受赠的财产（但遗嘱/赠与合同中确定只归一方的除外）⑤ 其他应当归共同所有的财产 |
| 3 | 夫妻个人财产（第26条） | 一方的婚前财产/一方因受到人身损害获得的赔偿/遗嘱/赠与合同中确定只归一方的财产/一方专用的生活用品/其他应当归一方的财产 |
| 4 | 夫妻共同债务认定（第33/34/35/36条）⭐⭐⭐⭐⭐ | 夫妻双方共同意思表示所负的债务/夫妻一方在婚姻关系存续期间以个人名义为**家庭日常生活需要**所负的债务 → 共同债务；夫妻一方在婚姻关系存续期间以个人名义超出家庭日常生活需要所负的债务 → 不属于共同债务，但债权人能够证明该债务用于夫妻共同生活/共同生产经营或者基于夫妻双方共同意思表示的除外 |
| 5 | 离婚过错赔偿（第86条）⭐⭐⭐⭐⭐ | 有下列情形之一导致离婚的，无过错方有权请求损害赔偿：① 重婚 ② 与他人同居 ③ 实施家庭暴力 ④ 虐待/遗弃家庭成员 ⑤ 有其他重大过错；赔偿包括物质损害赔偿和精神损害赔偿 |
| 6 | 精神损害赔偿 | 法院支持的情形：侵害他人人身权益/具有人格象征意义的特定纪念物品因侵权行为而永久性灭失/毁损；赔偿数额：最高一般不超过**50万元** |

### 《最高人民法院关于适用〈中华人民共和国民法典〉继承编的解释（一）》（2021）

| # | 主题 | 要点 |
|---|------|------|
| 1 | 遗产范围 | 遗产是自然人死亡时遗留的个人合法财产；包括收入/房屋/储蓄/生活用品/文物/图书资料/著作权/专利权中的财产权利/有价证券/股权等 |
| 2 | 法定继承顺序 | 第一顺序：配偶/子女/父母；第二顺序：兄弟姐妹/祖父母/外祖父母；子女包括婚生/非婚生/养子女/有扶养关系的继子女 |
| 3 | 代位继承 | 被继承人的子女先于被继承人死亡的 → 由被继承人的子女的晚辈直系血亲代位继承 |
| 4 | 遗嘱形式效力 | 自书遗嘱/代书遗嘱/打印遗嘱/录音录像遗嘱/口头遗嘱/公证遗嘱都有效；2021年起**公证遗嘱不再效力优先**，以最后一份遗嘱为准 |

### 《最高人民法院关于适用〈中华人民共和国民法典〉侵权责任编的解释（一）》（2023）

| # | 主题 | 要点 |
|---|------|------|
| 1 | 过错责任 | 行为人因过错侵害他人民事权益造成损害的 → 应当承担侵权责任；过错包括故意和过失 |
| 2 | 无过错责任（民法典第1166条）⭐⭐⭐ | 行为人造成他人民事权益损害，不论行为人有无过错，法律规定应当承担侵权责任的 → 依照其规定；包括：① 监护人责任 ② 用人单位责任 ③ 产品缺陷责任 ④ 机动车交通事故责任 ⑤ 环境污染责任 ⑥ 高度危险作业责任 ⑦ 饲养动物损害责任 |
| 3 | 精神损害赔偿数额 | 一般根据侵权行为所造成的后果/侵权人的过错程度/侵害的手段/场合/行为方式/侵权人的获利情况/侵权人承担责任的经济能力/受诉法院所在地平均生活水平等因素确定；致人死亡的 → 精神损害抚慰金一般为**5-10万元**；残疾的 → 根据等级酌情 |

## 二、民事诉讼核心司法解释 ⭐⭐⭐⭐⭐

### 《最高人民法院关于民事诉讼证据的若干规定》（2019）

| # | 主题 | 要点 |
|---|------|------|
| 1 | 举证期限 | 一审普通程序：**≥15日**；一审简易程序：**≤15日**；小额诉讼程序：**≤7日** |
| 2 | 逾期举证 | 当事人逾期提供证据的，法院应当责令其说明理由；拒不说明理由/理由不成立的，法院可以不予采纳该证据/采纳该证据但予以训诫/罚款 |
| 3 | 当事人自认 | 一方当事人在法庭审理中/在起诉状/答辩状/代理词等书面材料中，对于己不利的事实明确表示承认的 → 另一方当事人无需举证证明 |
| 4 | 电子数据证据 | 电子数据是指通过计算机等技术形成的数据；必须保证完整性（提供哈希值校验等）才有效 |
| 5 | 录音录像证据 | 未经对方同意的录音录像，如果**不侵害他人合法权益/不违反法律禁止性规定** → 可以作为证据（注意：窃听/偷拍/侵犯隐私的不行！） |
| 6 | 证人证言 | 证人必须出庭作证（例外：健康原因/路途遥远/不可抗力等）；不出庭的证人证言一般不采信 |

### 《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》（2020修正）⭐⭐⭐⭐⭐

| # | 主题 | 要点 |
|---|------|------|
| 1 | 利率上限（第25条）⭐⭐⭐⭐⭐ | 出借人请求借款人按照合同约定利率支付利息的，法院应予支持，但是双方约定的利率超过**合同成立时一年期LPR的4倍**的除外；一年期LPR：全国银行间同业拆借中心每月公布 |
| 2 | 逾期利息（第28条）⭐⭐⭐⭐⭐ | ① 有约定从约定（但不超过LPR4倍）② 既未约定借期内利率也未约定逾期利率 → 出借人主张借款人自逾期之日起参照当时一年期LPR标准计算的利息承担逾期还款违约责任的，法院应予支持 ③ 约定了借期内利率但未约定逾期利率 → 出借人主张借款人自逾期之日起按照借期内利率支付资金占用期间利息的，法院应予支持 |
| 3 | 砍头息（第26条）⭐⭐⭐⭐⭐ | 借据/收据/欠条等债权凭证载明的借款金额，一般认定为本金；预先在本金中扣除利息的 → 法院应当将实际出借的金额认定为本金 |
| 4 | 民间借贷与刑事交叉 | 民间借贷行为本身涉嫌非法集资等犯罪的 → 法院应当裁定驳回起诉，将涉嫌非法集资等犯罪的线索/材料移送公安/检察机关 |
| 5 | 网贷/套路贷认定 | 典型套路贷特征：① 制造虚假债权债务（虚增借款金额/制造资金走账流水）② 肆意认定违约 ③ 虚增借贷金额 ④ 制造软硬兼施的索取债权手段 ⑤ 恶意垒高借款金额 → 可以认定为套路贷，按诈骗罪/敲诈勒索罪等追究刑事责任 |

### 《最高人民法院关于审理人身损害赔偿案件适用法律若干问题的解释》（2022修正）⭐⭐⭐⭐⭐

| # | 项目 | 计算方式 |
|---|------|----------|
| 1 | 医疗费 | 根据医疗机构出具的医药费/住院费等收款凭证，结合病历和诊断证明等相关证据确定 |
| 2 | 误工费 | 根据受害人的误工时间和收入状况确定；误工时间根据受害人接受治疗的医疗机构出具的证明确定；受害人有固定收入的 → 误工费=实际减少的收入；无固定收入的 → 按最近3年平均收入/受诉法院所在地相同/相近行业上年度平均工资计算 |
| 3 | 护理费 | 根据护理人员的收入状况/护理人数/护理期限确定；护理人员有收入的 → 误工费标准；无收入/雇佣护工的 → 当地护工从事同等级别护理的劳务报酬标准；护理期限一般不超过20年 |
| 4 | 交通费 | 根据受害人及其必要的陪护人员因就医/转院治疗实际发生的费用计算 |
| 5 | 住院伙食补助费 | 可以参照当地国家机关一般工作人员的出差伙食补助标准予以确定 |
| 6 | 营养费 | 根据受害人伤残情况参照医疗机构的意见确定 |
| 7 | 残疾赔偿金（第12条）⭐⭐⭐⭐⭐ | 根据受害人丧失劳动能力程度/伤残等级，按照受诉法院所在地上一年度城镇居民人均可支配收入标准，自定残之日起按20年计算；但60周岁以上的，年龄每增加1岁减少1年；75周岁以上的，按5年计算；伤残等级：一级（100%）/二级（90%）/三级（80%）.../十级（10%） |
| 8 | 死亡赔偿金（第15条）⭐⭐⭐⭐⭐ | 按照受诉法院所在地上一年度城镇居民人均可支配收入标准，按20年计算；60周岁以上的，年龄每增加1岁减少1年；75周岁以上的，按5年计算 |
| 9 | 丧葬费 | 按照受诉法院所在地上一年度职工月平均工资标准，以**6个月**总额计算 |
| 10 | 被扶养人生活费 | 根据扶养人丧失劳动能力程度，按照受诉法院所在地上一年度城镇居民人均消费性支出/农村居民人均年生活消费支出标准计算；被扶养人为未成年人的 → 计算至18周岁；60周岁以上的 → 按20年（每增1岁减1年；75岁以上按5年） |

### 《最高人民法院、最高人民检察院关于办理电信网络诈骗等刑事案件适用法律若干问题的意见》（2016）⭐⭐⭐⭐⭐

```
电信网络诈骗数额标准：
  数额较大：3000元以上 → 3年以下有期徒刑/拘役/管制，并处罚金
  数额巨大：3万元以上 → 3-10年有期徒刑，并处罚金
  数额特别巨大：50万元以上 → 10年以上有期徒刑/无期徒刑，并处罚金/没收财产
注意：全国统一标准，不区分地区！（普通诈骗各省有差异）

从重处罚情节：
  ① 造成被害人自杀/精神失常/其他严重后果
  ② 冒充司法机关等国家机关工作人员实施诈骗
  ③ 组织/指挥电信网络诈骗犯罪团伙
  ④ 在境外实施电信网络诈骗
  ⑤ 曾因电信网络诈骗犯罪受过刑事处罚/2年内曾因电信网络诈骗受过行政处罚
  ⑥ 诈骗残疾人/老年人/在校学生/无劳动能力人财物
  ⑦ 诈骗救灾/抢险/防汛/优抚/扶贫/医疗等款物
  ⑧ 以赈灾/募捐名义实施诈骗
  ⑨ 利用电话追呼系统等技术手段严重干扰公安机关等部门工作
  ⑩ 利用"钓鱼网站""木马程序""黑客攻击"等技术手段网络技术实施诈骗

共同犯罪认定（帮信罪关联）：
  ① 提供"伪基站""黑广播"等设备
  ② 出售/提供个人信息
  ③ 提供资金支付结算服务
  ④ 提供网络技术支持
  → 以上如果明知对方是诈骗仍提供 → 按共犯追究
```

### 认罪认罚从宽司法解释（2019）⭐⭐⭐⭐⭐

```
从宽幅度（一般经验）：
  ① 侦查阶段认罪认罚：从宽30%-50%
  ② 审查起诉阶段认罪认罚：从宽20%-40%
  ③ 审判阶段认罪认罚：从宽10%-30%
  ④ 主动早认罪 + 坦白 + 退赃退赔 + 取得被害人谅解 → 叠加从宽
不予从宽情形：
  ① 犯罪性质恶劣/危害后果严重的
  ② 认罪认罚但不悔改的
  ③ 共同犯罪中起主导作用的
```

## 五、劳动争议司法解释 ⭐⭐⭐⭐⭐

### 《最高人民法院关于审理劳动争议案件适用法律若干问题的解释（一）》（2021）

| # | 主题 | 要点 |
|---|------|------|
| 1 | 劳动仲裁时效 | **1年**（从当事人知道/应当知道其权利被侵害之日起计算）；拖欠劳动报酬争议，劳动关系存续期间不受1年限制，劳动关系终止的，应当自终止之日起1年内提出 |
| 2 | 经济补偿（N） | 按劳动者在本单位工作的年限，每满1年支付1个月工资；6个月以上不满1年的按1年算；不满6个月的支付0.5个月工资；月工资：劳动者在劳动合同解除/终止前12个月的平均工资；年限最高不超过12年；月工资高于当地上年度职工月平均工资3倍的 → 按3倍计算 |
| 3 | 二倍工资（未签合同） | 用人单位自用工之日起超过1个月不满1年未与劳动者订立书面劳动合同 → 应当向劳动者每月支付2倍工资；超过1年未签 → 视为无固定期限合同；但二倍工资有**1年仲裁时效**（从应当签合同满1个月起算1年）⭐⭐⭐ |
| 4 | 违法解除赔偿（2N） | 用人单位违法解除/终止劳动合同 → 应当按经济补偿标准的**2倍**向劳动者支付赔偿金；2N 和 N 不能同时主张 |
| 5 | 代通知金（N+1） | 用人单位依照劳动合同法第40条规定解除合同的 → 提前30日书面通知/额外支付1个月工资后解除；N+1 与 2N 不能同时主张 |
| 6 | 竞业限制 | 期限不得超过2年；补偿金不低于劳动者离职前12个月平均工资的30%；违约金由双方约定但不能过高 |
| 7 | 加班举证 | 劳动者主张加班费 → 应当就加班事实存在承担举证责任；但劳动者有证据证明用人单位掌握加班事实存在的证据，用人单位不提供的 → 用人单位承担不利后果 |
| 8 | 规章制度效力 | 用人单位规章制度经过民主程序制定/不违反法律法规/向劳动者公示/告知 → 可以作为法院审理劳动争议案件的依据 |

## 司法解释效力层级 ⭐⭐⭐⭐⭐

```
效力层级：
  法律 → 行政法规 → 地方性法规/部门规章 → 司法解释 → 地方性政府规章

司法解释效力：
  最高人民法院/最高人民检察院作出的司法解释 → 与法律有同等效力（在法院审判中应当引用）
  → 注意：司法解释不能与法律冲突；冲突时以法律为准

最高法司法解释类型：
  ① "解释"：对某部法律/某类案件的全面规定
  ② "规定"：对某类问题的专项规定
  ③ "批复"：对下级法院请示的答复（具有普遍约束力）
  ④ "指导意见"：指导性规定（灵活适用）
  ⑤ "通知"：规范性文件
```
