## 总则核心

### 基本原则（第3-5条）⭐

| 原则 | 条文 | 含义 |
|------|------|------|
| 罪刑法定 | 第3条 | 法律明文规定才定罪处刑；法律没规定的不得定罪处刑 |
| 适用平等 | 第4条 | 对任何人犯罪，在适用法律上一律平等 |
| 罪责刑相适应 | 第5条 | 刑罚轻重与所犯罪行和承担的刑事责任相适应 |

### 管辖（第6-11条）

```
属地管辖（第6条）：在中国领域内犯罪的，除法律特别规定外，适用本法
  领域内：领陆/领水/领空 + 中国船舶/航空器（无论在哪）
  犯罪地包括犯罪行为发生地和犯罪结果发生地
属人管辖（第7条）：
  中国公民在境外犯罪，最高刑3年以上的适用
  中国国家工作人员/军人在境外犯罪，适用本法
保护管辖（第8条）：
  外国人在境外对中国/公民犯罪，最低刑3年以上且按犯罪地法律也受处罚
普遍管辖（第9条）：
  中国缔约/参加的国际条约规定的罪行，无论犯罪人国籍适用本法
例外（第11条）：享有外交特权/豁免权的外国人的刑事责任，通过外交途径解决
```

### 刑事责任年龄（第17条）⭐⭐⭐刑法修正案十一⭐⭐⭐

```
不满12周岁：不负刑事责任
  （责令家长/监护人管教；必要时经专门教育指导委员会评估可送专门矫治教育）
12-14周岁：犯故意杀人/故意伤害致人死亡/以特别残忍手段致重伤残疾
  → 经最高检核准追诉的，应负刑事责任
14-16周岁：犯故意杀人/故意伤害致人重伤或死亡/强奸/抢劫/贩卖毒品/放火/爆炸/投放危险物质罪的，应负刑事责任
16周岁以上：应当负刑事责任
未成年人犯罪的处理（第17条）：
  不满18周岁犯罪：应当从轻/减轻处罚
  不满16周岁不予刑事处罚的，责令家长管教；必要时可送专门学校矫治教育
  不满14周岁不予刑事处罚的，责令家长管教；必要时可送专门矫治教育
已满75周岁（第17条之一）：
  故意犯罪：可以从轻/减轻处罚
  过失犯罪：应当从轻/减轻处罚
  不适用死刑（特别残忍手段致人死亡除外）
```

### 正当防卫与紧急避险（第20-21条）⭐

```
正当防卫（第20条）：
  条件：为使国家/公共利益/本人/他人合法权益免受正在进行的不法侵害
  → 对侵害人造成损害的，不负刑事责任
  防卫过当：明显超过必要限度造成重大损害的，应当负刑事责任，但应当减轻/免除处罚
  特殊防卫（第20条第3款）⭐⭐⭐：
    对正在进行行凶/杀人/抢劫/强奸/绑架及其他严重危及人身安全的暴力犯罪，
    采取防卫行为造成不法侵害人伤亡的，不属于防卫过当，不负刑事责任
紧急避险（第21条）：
  条件：为使合法权益免受正在发生的危险，不得已采取避险行为
  → 造成损害的，不负刑事责任
  避险过当：超过必要限度造成不应有损害的，应当负刑事责任，但应当减轻/免除处罚
  职务/业务上负有特定责任的人（消防员/警察等），不适用紧急避险规定
```

### 刑罚种类（第32-60条）⭐

```
主刑（只能独立适用，第33条）：
  管制（第38条）：3个月-2年，数罪并罚≤3年
    社区矫正，不关押；可禁止令；执行期间同工同酬
  拘役（第42条）：1-6个月，数罪并罚≤1年
    就近执行；每月可回家1-2天；参加劳动酌量报酬
  有期徒刑（第45条）：6个月-15年，数罪并罚≤25年
  无期徒刑（第46条）：剥夺终身自由，强制劳动改造
  死刑（第48条）：
    死刑只适用于罪行极其严重的犯罪分子
    必须报请最高法核准（除最高法判决外）
    死刑缓期2年执行：
      期间无故意犯罪→2年期满后减为无期
      确有重大立功表现→2年期满后减为25年有期
      故意犯罪情节恶劣→报请最高法核准执行死刑
附加刑（可独立/附加适用，第34条）：
  罚金/剥夺政治权利/没收财产
驱逐出境（第35条）：适用于犯罪的外国人
```

### 追诉时效（第87-89条）⭐⭐⭐高频⭐⭐⭐

```
法定最高刑不满5年：经过5年
法定最高刑5-10年：经过10年
法定最高刑10年以上：经过15年
法定最高刑无期/死刑：经过20年
  → 20年后认为必须追诉的，须报最高检核准
时效中断（第89条第1款）：
  追诉期限内又犯罪的，前罪追诉期限从犯后罪之日起重新计算
时效延长（第88条）：
  立案侦查/受理案件后逃避侦查/审判的
  被害人在追诉期限内提出控告，法院/检察院/公安机关应当立案而不立案的
  → 不受追诉期限限制
起算点（第89条第1款）：
  追诉期限从犯罪之日起计算；犯罪有连续/继续状态的，从犯罪行为终了之日起计算
```
