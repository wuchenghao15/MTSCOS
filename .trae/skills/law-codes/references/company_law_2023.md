# 中华人民共和国公司法（2023年新修订）

## 基本信息

| 项目 | 内容 |
|------|------|
| 修订时间 | 2023年12月29日（第十四届全国人大常委会第七次会议） |
| 生效时间 | 2024年7月1日 |
| 条文总数 | **266 条**（原218条→增加48条） |
| 结构 | 15章 |
| 重大修订 | 新增国家出资公司专章；注册资本认缴期限限制；股东出资加速到期；授权资本制引入；股东权利强化 |

## 法典结构

```
第1章 总则  第2章 公司登记  第3章 有限责任公司的设立和组织机构
第4章 有限责任公司的股权转让  第5章 股份有限公司的设立和组织机构
第6章 股份有限公司的股份发行和转让  第7章 国家出资公司组织机构（新增）
第8章 公司债券  第9章 公司财务会计  第10章 公司合并分立增资减资
第11章 公司解散和清算  第12章 外国公司的分支机构  第13章 公司争议解决
第14章 法律责任  第15章 附则
```

## 核心修订点（2023新公司法）⭐⭐⭐

| # | 修订内容 | 旧法 | 2023版 |
|---|----------|------|--------|
| 1 | **注册资本认缴期限** | 无限制 | 可自主约定，但不得超过公司法规定的最长认缴期限？（需核对第47条） |
| 2 | **股东出资加速到期** | 仅破产/解散清算时 | 新增：公司不能清偿到期债务时，债权人有权请求未届出资期限的股东在未出资范围内对公司不能清偿的债务承担补充赔偿责任 |
| 3 | **授权资本制** | 仅股份公司特定 | 有限责任公司股东会可授权董事会发行新股（不超过公司章程规定的可发行总额） |
| 4 | **股东知情权** | 查阅会计账簿有条件 | 新增：可查阅会计凭证（原始凭证/记账凭证）；可委托会计师事务所等中介机构协助 |
| 5 | **股份有限公司资本充实** | 无 | 新增：股份公司发起人自公司成立之日起3年内必须实缴注册资本（分期缴纳的最长期限） |
| 6 | **国家出资公司专章** | 无 | 新增第7章：国有独资公司、国有资本控股公司、国有资本参股公司 |
| 7 | **股东权利强化** | — | 新增：股东对股东会/股东大会决议有异议的，有权请求公司回购其所持股权/股份；新增股东派生诉讼的具体程序 |
| 8 | **董监高信义义务** | 原则性规定 | 新增：勤勉义务的具体判断标准；忠实义务的具体禁止行为（新增几类） |
| 9 | **公司利润分配** | 按出资比例 | 明确：按实缴出资比例，但全体股东另有约定除外 |
| 10 | **简易合并** | 无 | 新增：持有公司90%以上表决权股份的股东可决定公司合并，无需召开股东会 |
| 11 | **公司存续期限** | 无 | 章程可规定；到期前股东会可决议续展 |
| 12 | **法律责任细化** | 模糊 | 大幅细化：虚报注册资本/虚假出资/抽逃出资/违法分配利润等具体罚款幅度 |

## 核心条文速查

### 总则

```
公司定义（第2条）：依照本法在中国境内设立的有限责任公司和股份有限公司
股东有限责任（第3条）：
  有限责任公司股东以认缴出资额为限对公司承担责任
  股份有限公司股东以认购股份为限对公司承担责任
  公司以其全部财产对公司债务承担责任
设立条件（第24/76条）：
  有限责任公司：
    ① 股东人数1-50人  ② 有公司章程
    ③ 有公司名称/建立符合要求的组织机构  ④ 有公司住所
  股份有限公司：
    ① 发起人2-200人（半数以上在中国境内有住所）
    ② 有公司章程/募集方式设立的须经创立大会通过
    ③ 有公司名称/组织机构/住所
    ④ 有符合规定的注册资本
注册资本（第47/80条）⭐⭐：
  有限责任公司：注册资本为在公司登记机关登记的全体股东认缴的出资额
    → **2023新增**：法律/行政法规/国务院决定对注册资本最低限额另有规定的，从其规定
    → 股东出资加速到期（第54条）⭐⭐⭐：公司不能清偿到期债务的，公司/债权人有权请求未届出资期限的股东在未出资范围内对公司不能清偿的债务承担补充赔偿责任
  股份有限公司：
    发起设立：注册资本为登记的全体发起人认购的股本总额
    募集设立：注册资本为登记的实收股本总额
    → **2023新增**：股份有限公司发起人自公司成立之日起3年内必须足额缴纳注册资本（分期缴纳的最长期限）
```

### 有限责任公司

```
股东权利（第4条 + 新增）⭐⭐⭐：
  ① 依法享有资产收益/参与重大决策/选择管理者/查阅公司章程/股东会会议记录/董事会会议决议/监事会会议决议/财务会计报告（第57条）
  ② **2023新增**：可查阅会计账簿/会计凭证（原始凭证/记账凭证）
  ③ **2023新增**：可委托会计师事务所等中介机构协助查阅（应当委托具有执业资格的机构）
  ④ 股东有权请求公司按照合理价格收购其股权（第89条）
  ⑤ 股东会/股东大会决议无效/可撤销之诉（第90条）
股东知情权行使：
  书面请求→公司在15日内答复/提供；拒绝提供→股东可请求法院强制
股东会（第59-64条）：
  由全体股东组成，是公司最高权力机构
  职权：决定公司经营方针/投资计划/选举更换董事监事/审议批准董事会报告/监事会报告/利润分配方案/增加减少注册资本/发行债券/公司合并分立解散变更形式等
  股东会会议：定期会议按章程；临时会议：代表1/10以上表决权股东/1/3以上董事/监事会提议召开
  决议：一般事项经代表过半数表决权股东通过；特殊事项（章程修改/增资减资/合并分立解散/变更形式）经代表2/3以上表决权股东通过
董事会（第65-70条）：
  董事3-13人；执行董事1人（股东人数较少/规模较小的可不设董事会）
  职权：召集股东会/执行股东会决议/决定经营计划/投资方案/聘任解聘经理/制定基本管理制度等
经理（第74条）：
  由董事会聘任/解聘；职权：主持生产经营管理/组织实施董事会决议/组织实施年度经营计划和投资方案/拟订内部管理机构设置方案等
监事会（第76-82条）：
  成员≥3人；股东人数较少/规模较小的可不设监事会，设1-2名监事
  职权：检查公司财务/监督董事高管履职/纠正损害公司利益行为/提议召开临时股东会/向股东会提出议案
股权转让（第84-88条）⭐：
  内部转让：有限责任公司股东之间可相互转让全部/部分股权
  对外转让：
    ① 股东向股东以外的人转让股权，应当经其他股东过半数同意
    ② 书面通知其他股东征求同意，其他股东自接到通知之日起30日未答复→视为同意
    ③ 其他股东半数以上不同意转让的，不同意的股东应购买该股权；不购买→视为同意转让
    ④ 经股东同意转让的股权，其他股东在同等条件下有优先购买权
    ⑤ 2个以上股东主张行使优先购买权的，协商确定购买比例；协商不成→按转让时各自出资比例行使
  强制执行转让（第88条）：法院依法强制执行股东股权的，应通知公司及全体股东，其他股东在同等条件下有优先购买权（20日行使）
股权回购请求权（第89条）⭐2023新增⭐：
  有下列情形之一的，对股东会该项决议投反对票的股东可请求公司按照合理价格收购其股权：
  ① 公司连续5年不向股东分配利润，而公司该5年连续盈利且符合分配利润条件
  ② 公司合并/分立/转让主要财产
  ③ 公司章程规定的营业期限届满/规定的解散事由出现，股东会会议通过决议修改章程使公司存续
  ④ 其他导致股东利益受损情形
  自股东会决议通过之日起60日内股东与公司不能达成股权收购协议的，股东可自决议通过之日起90日内向法院提起诉讼
```

### 股份有限公司

```
发起设立 vs 募集设立（第77条）：
  发起设立：由发起人认购公司应发行的全部股份设立
  募集设立：由发起人认购公司应发行股份的一部分（≥35%），其余向社会公开募集/向特定对象募集设立
创立大会（第90条，募集设立）：
  发起人应在股款缴足后30日内主持召开
  应有代表股份总数过半数的发起人/认股人出席方可举行
  决议：经出席会议的认股人所持表决权过半数通过
股东大会（第92-99条）：
  由全体股东组成
  年会：每年召开1次（通常在上一会计年度终了后6个月内）
  临时股东大会：2个月内召开情形（第92条）：
    ① 董事人数不足本法规定人数/章程规定人数2/3
    ② 公司未弥补亏损达实收股本总额1/3
    ③ 单独/合计持有公司10%以上股份的股东请求
    ④ 董事会认为必要
    ⑤ 监事会提议召开
  决议：一般事项出席会议股东所持表决权过半数通过；特别决议（章程修改/增资减资/合并分立解散等）出席会议股东所持表决权2/3以上通过
  累积投票制（第97条）：股东大会选举董事/监事时，每一股份拥有与应选董事/监事人数相同的表决权，股东拥有表决权可集中使用
董事会/监事会：与有限责任公司类似，但规模更大（股份公司董事5-19人）
```

### 国家出资公司（新增第7章）⭐⭐

```
适用范围（第168条）：
  国有独资公司、国有资本控股公司、国有资本参股公司
董事会/专门委员会：
  国有独资公司不设股东会，由国有资产监督管理机构行使股东会职权
  董事会成员≥3人，其中职工代表≥1/3
  国有资本控股公司/参股公司：董事会成员中应有职工代表
董监高选择（第176条）：
  国有独资公司：董事长/副董事长由国有资产监督管理机构从董事会成员中指定
  国有资本控股公司：董事长由公司章程规定（通常国有资产监督管理机构推荐）
审计委员会：国有独资公司/国有资本控股公司应当设立审计委员会（成员≥3人，其中独立董事≥1/2）
```

### 公司财务会计

```
利润分配（第210条）⭐2023明确⭐：
  公司分配当年税后利润时，应当提取利润10%列入公司法定公积金
  法定公积金累计额≥注册资本50%的，可不再提取
  公司弥补亏损和提取公积金后所余税后利润：
    有限责任公司：按实缴出资比例分配（全体股东另有约定除外）
    股份有限公司：按股东持有的股份比例分配（章程规定不按持股比例分配除外）
  公司持有的本公司股份不得分配利润（第211条）
禁止违法分配（第212条）：
  公司不能在弥补亏损和提取法定公积金之前分配利润
  股东会/股东大会/董事会违反前款规定分配的，股东应将分配利润退还公司
```

### 公司解散和清算

```
解散事由（第229条）：
  ① 公司章程规定的营业期限届满/章程规定的其他解散事由出现
  ② 股东会/股东大会决议解散
  ③ 因公司合并/分立需要解散
  ④ 依法被吊销营业执照/责令关闭/被撤销
  ⑤ 公司经营管理发生严重困难，继续存续会使股东利益受到重大损失，通过其他途径不能解决的，持有公司全部股东表决权10%以上的股东，可请求法院解散公司
清算组（第232条）：
  解散事由出现之日起15日内成立清算组
  有限责任公司：由股东组成
  股份有限公司：由董事/股东大会确定的人员组成
  逾期不成立清算组的，债权人/股东可申请法院指定清算组
清算顺序（第236条）：
  清算费用 → 职工工资/社会保险费用/法定补偿金 → 所欠税款 → 清偿公司债务
  剩余财产：有限责任公司按股东出资比例/股份有限公司按股东持有股份比例分配
```

### 法律责任（大幅细化）

```
虚报注册资本（第249条）：责令改正，处虚报注册资本金额5%-15%罚款
虚假出资（第250条）：责令改正，处虚假出资金额2%-10%罚款；股东不按规定缴纳出资的，除应补缴外，应向已按期足额缴纳出资的股东承担违约责任
抽逃出资（第251条）：责令改正，处所抽逃出资金额5%-15%罚款
违法分配利润（第253条）：在弥补亏损和提取法定公积金之前分配利润的，股东应退还；董事/监事/高管有过错的，应承担赔偿责任
```

## 高频问题速查

| 问题 | 条文 |
|------|------|
| 股东出资加速到期？ | 第54条（公司不能清偿到期债务时） |
| 股东知情权能查会计凭证吗？ | 第57条（2023新增） |
| 对外转让股权其他股东不同意怎么办？ | 第86条（不同意就自己买，不买视为同意） |
| 股权回购请求权适用情形？ | 第89条（5年不分红/转让主要财产/修改章程续存等） |
| 股东会特别决议？ | 第65条（2/3以上表决权） |
| 股份公司股东大会召集人？ | 第94条（董事会/监事会/10%股东） |
| 分红按实缴还是认缴？ | 第210条（**2023明确按实缴比例**） |
| 可以不设董事会/监事会吗？ | 可以（股东少/规模小，设执行董事/监事） |
| 公司注册资本最低额？ | 认缴制无最低额（但特定行业如银行/证券/保险另有规定） |
| 一人有限责任公司？ | 第93-96条（2023：人格独立举证责任在股东） |
