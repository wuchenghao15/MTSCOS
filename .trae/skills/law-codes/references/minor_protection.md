# 中华人民共和国未成年人保护法（132 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 现行版本 | 2020年10月17日新修订（2021年6月1日施行） |
| 条文总数 | **132 条** |
| 定位 | 未成年人保护核心法律（2020修订后6章） |
| 核心新增 | **政府保护** + **网络保护** 两章 |

---

## 2020修订重大变化 ⭐⭐⭐

```
❶ 结构变化：旧版4章→新版6章
  旧版：总则/家庭保护/学校保护/社会保护/司法保护
  新版：总则/家庭保护/学校保护/社会保护/网络保护/政府保护/司法保护（新增两章）

❷ 新增网络保护专章（第64-80条）
  - 规定了未成年人使用网络的保护
  - 平台责任
  - 网络游戏管理（充值/消费/防沉迷）
  - 网络欺凌治理

❸ 新增政府保护专章（第81-99条）
  - 明确政府是未成年人保护的最终责任人
  - 强制报告制度（第117条）⭐⭐⭐：
    任何组织/个人发现不利于未成年人身心健康或者侵犯未成年人合法权益的情形，都有权劝阻/制止或者向公安/民政/教育等有关部门提出检举/控告
    **强制报告主体**（第117条第2款）：
      国家机关/居民委员会/村民委员会/密切接触未成年人的单位/工作人员等，发现下列情形之一的，应当立即向公安/民政/教育等有关部门报告：
      ① 未成年人遭受/疑似遭受家庭暴力/虐待/遗弃的
      ② 未成年人身心发育异常或者身心健康受到侵害的
      ③ 未成年人被拐卖/拐骗的
      ④ 其他严重侵害未成年人身心健康的情形
    未履行报告义务的，依法给予处分（第117条第3款）

❹ 刑责年龄下调配套
  2020年刑修十一下调刑事责任年龄，保护法同步完善对罪错未成年人的矫正措施

❺ 入职查询（第62条）⭐⭐⭐
  密切接触未成年人的单位招聘工作人员时，应当向公安机关/人民检察院查询应聘者是否具有性侵害/虐待/拐卖/暴力伤害等违法犯罪记录
  发现具有上述记录的，不得录用
  本单位每年应当对工作人员是否具有上述违法犯罪记录进行查询
```

## 六大保护体系（2020版核心）

### 1. 家庭保护（第15-24条）

```
父母/监护人职责（第16条）：
  ① 为未成年人提供生活/健康/安全的保障
  ② 关注未成年人的生理/心理状况和情感需求
  ③ 教育和引导未成年人遵纪守法/勤俭节约，养成良好的思想品德和行为习惯
  ④ 对未成年人进行安全教育，提高未成年人的自我保护意识和能力
  ⑤ 尊重未成年人受教育的权利，保障适龄未成年人依法接受并完成义务教育
  ⑥ 保障未成年人休息/娱乐和体育锻炼的时间，引导未成年人进行有益身心健康的活动
  ⑦ 妥善管理和保护未成年人的财产
  ⑧ 依法代理未成年人实施民事法律行为
  ⑨ 预防和制止未成年人的不良行为和违法犯罪行为，并进行合理管教
  ⑩ 应当听取未成年人的意见并采纳合理意见
家庭暴力禁止（第17条）：
  父母/监护人不得实施家庭暴力/虐待/遗弃未成年人
  禁止对未成年人实施性侵害/性骚扰
  禁止教唆/胁迫/引诱未成年人参加邪教/迷信活动
  禁止允许/迫使未成年人结婚/为未成年人订立婚约
```

### 2. 学校保护（第25-40条）

```
学校安全（第35条）：
  学校应当建立安全管理制度，对未成年人进行安全教育，完善安保设施，配备安保人员，保障未成年人在校期间的人身安全
  学校/幼儿园不得安排未成年人参加商业性活动，不得向未成年人及其父母/监护人推销或者变相推销商品/服务
  学校应当将心理健康教育纳入教育教学工作，配备专职/兼职心理健康教育教师

禁止体罚/侮辱（第27条）：
  学校/幼儿园的教职员工应当尊重未成年人人格尊严，不得对未成年人实施体罚/变相体罚/其他侮辱人格尊严的行为

校园欺凌治理（第39条）⭐⭐⭐：
  学校应当建立学生欺凌防控工作制度
  对欺凌者：不得因行为违反校规校纪就简单开除，应当进行针对性心理辅导/教育，构成违法的移交相关部门
  对被欺凌者：应当及时安抚/保护，避免二次伤害
  学校应当及时向被欺凌者的父母/监护人告知

预防性侵（第40条）⭐⭐⭐：
  学校/幼儿园应当建立预防性侵害/性骚扰未成年人工作制度
  发现未成年人遭受性侵害/性骚扰的，应当及时处理并向家长告知，应当向公安机关/教育行政部门报告
  学校不得聘用曾因性侵害/虐待等违法犯罪被处罚的教职员工
```

### 3. 社会保护（第41-63条）

```
公共场所保护（第44条）：
  公园/商场/游乐场等公共场所应当为未成年人提供安全设施，禁止向未成年人出售烟酒
  营业性歌舞娱乐场所/酒吧/互联网上网服务营业场所等不适宜未成年人活动的场所，不得允许未成年人进入（年龄限制：不得让未满16岁独自进入网吧等）

禁止拐卖/拐骗（第51条）：
  禁止拐卖/绑架/虐待/遗弃未成年人
  禁止胁迫/诱骗未成年人参与恐怖/邪教/迷信活动
  禁止组织/强迫/引诱未成年人卖淫/嫖娼

未成年人活动场所（第46-49条）：
  爱国主义教育基地/青少年宫/儿童活动中心/儿童图书馆等公益性设施，应当对未成年人免费开放
  博物馆/纪念馆/科技馆/美术馆/文化馆/体育场馆等场所，应当按照有关规定对未成年人免费或者优惠开放

禁止向未成年人售烟售酒（第59条）：
  禁止向未成年人出售烟酒，经营者应当在显著位置设置不向未成年人出售烟酒的标志；对难以判明是否是未成年人的，应当要求其出示身份证件
  禁止向未成年人出售彩票
  禁止向未成年人提供文身服务（2022年教育部等6部门联合发文禁止）
```

### 4. 网络保护（第64-80条）⭐⭐⭐新增⭐⭐⭐

```
网络素养教育（第65条）：
  学校/家长应当加强未成年人网络素养宣传教育，培养和提高未成年人网络素养，增强未成年人科学/文明/安全/合理使用网络的意识和能力
  父母/监护人应当提高网络素养，规范自身使用网络的行为，加强对未成年人使用网络行为的引导和监督

平台保护义务（第67-68条）：
  网络服务提供者应当设置便捷合理的未成年人模式，不得向未成年人提供诱导其沉迷的产品和服务
  网络游戏服务提供者应当按照国家有关规定对游戏作品进行分类，不得向未成年人提供含有诱发未成年人模仿违反社会公德的行为和违法犯罪的行为的内容，禁止向未成年人提供、诱导其接触不利于其身心健康的信息

网络游戏管理（第75条）⭐⭐⭐⭐⭐最高频⭐⭐⭐⭐⭐：
  国家建立统一的未成年人网络游戏电子身份认证系统
  网络游戏服务提供者不得在每日22时至次日8时向未成年人提供网络游戏服务
  任何组织/个人不得向未成年人提供预租/租借/转让游戏账号/游戏道具等服务
  未成年人游戏消费限制（2021年《关于进一步严格管理切实防止未成年人沉迷网络游戏的通知》）：
    ① 仅在法定节假日每日20-21时向未成年人提供1小时游戏服务
    ② 未成年人游戏消费：8-16周岁单次不得超50元/月累计不得超200元；16-18周岁单次不得超100元/月累计不得超400元
    ③ 网络游戏企业不得为未成年人提供游戏账号租赁/交易服务
    ④ 所有网络游戏必须接入防沉迷系统（强制）
  注意：以上时间限制是防沉迷通知规定，比未成年人保护法更严

网络欺凌（第77条）：
  任何组织/个人不得通过网络以文字/图片/音视频等形式，对未成年人实施侮辱/诽谤/威胁等网络欺凌
  网络服务提供者应当加强对未成年人网络发布内容的管理，发现针对未成年人的侮辱/诽谤/威胁等网络欺凌信息时，应当及时采取删除/屏蔽/阻断等措施

禁止利用网络实施违法犯罪（第70条）：
  禁止制作/复制/发布/传播含有下列内容的信息：
    ① 反对宪法所确定的基本原则的
    ② 危害国家安全/泄露国家秘密/颠覆国家政权/破坏国家统一的
    ③ 损害国家荣誉和利益的
    ④ 煽动民族仇恨/民族歧视/破坏民族团结的
    ⑤ 破坏国家宗教政策/宣扬邪教和封建迷信的
    ⑥ 散布谣言/扰乱社会秩序/破坏社会稳定的
    ⑦ 散布淫秽/色情/赌博/暴力/凶杀/恐怖/教唆犯罪的
    ⑧ 侮辱或者诽谤他人/侵害他人合法权益的
    ⑨ 含有虚假/有害/胁迫/骚扰/商业广告等干扰未成年人正常生活的内容
    ⑩ 含有欺诈/引诱未成年人实施违背社会公德行为的内容
```

### 5. 政府保护（第81-99条）⭐⭐⭐新增⭐⭐⭐

```
强制报告制度（第117条）⭐⭐⭐⭐⭐最高频⭐⭐⭐⭐⭐：
  任何组织/个人发现不利于未成年人身心健康或者侵犯未成年人合法权益的情形，都有权劝阻/制止或者向公安/民政/教育等有关部门提出检举/控告
  密切接触未成年人的单位/工作人员发现下列情形之一的，**应当立即**报告：
    ① 未成年人遭受/疑似遭受家庭暴力/虐待/遗弃的
    ② 未成年人身心发育异常或者身心健康受到侵害的
    ③ 未成年人被拐卖/拐骗的
    ④ 其他严重侵害未成年人身心健康的情形
  未履行报告义务的，依法给予处分
  国家机关/居民委员会/村民委员会/密切接触未成年人的单位（学校/医院/培训机构/儿童福利机构/救助管理机构等）都是强制报告主体
  公安机关接到报告后，应当及时出警，制止侵害行为，调查取证

未成年人保护工作协调机制（第81条）：
  县级以上人民政府应当建立未成年人保护工作协调机制，统筹/协调/督促有关部门做好未成年人保护工作

未成年人救助保护（第92条）：
  县级以上人民政府应当根据需要设立未成年人救助保护机构/儿童福利机构，负责收留/抚养无劳动能力/无生活来源/无法查明父母/监护人的未成年人
  对临时监护的未成年人，民政部门可以采取委托亲属抚养/家庭寄养等方式进行安置，也可以交由民政部门设立的儿童福利机构收留/抚养

国家监护制度（第92条）⭐：
  父母/监护人无法履行监护职责的，由民政部门担任监护人

临时监护情形（第92条）：
  ① 未成年人流浪乞讨或者身份不明，暂时查找不到父母/监护人
  ② 监护人下落不明且无其他人可以担任监护人
  ③ 监护人因自身客观原因或者因实施家庭暴力/虐待/遗弃未成年人等原因不能履行监护职责且无其他人可以担任监护人
  ④ 未成年人遭受监护人严重伤害或者面临人身安全威胁，需要被紧急安置
  ⑤ 法律规定的其他情形
```

### 6. 司法保护（第100-132条）

```
未成年人犯罪特别程序（第101-105条）：
  对未成年犯罪嫌疑人/被告人/罪犯实行教育/感化/挽救的方针，坚持教育为主/惩罚为辅的原则
  公安机关/人民检察院/人民法院办理未成年人案件，应当设置专门机构或者指定专人办理
  对未成年人刑事案件，在讯问和审判的时候，应当通知未成年犯罪嫌疑人/被告人的法定代理人到场
  讯问未满16周岁的未成年人，应当由其监护人/近亲属或者法律工作者在场（第102条）
  对未成年人犯罪案件，新闻报道/影视节目/公开出版物等不得披露该未成年人的姓名/住所/照片/图像以及可能推断出该未成年人的资料

社会调查（第103条）：
  公安机关/人民检察院/人民法院办理未成年人刑事案件，根据情况可以对未成年犯罪嫌疑人/被告人的成长经历/犯罪原因/监护教育等情况进行调查
  调查报告可以作为办理未成年人刑事案件的参考

附条件不起诉（第104条）：
  对于未成年人涉嫌刑法分则第四章/第五章/第六章规定的犯罪，可能判处1年有期徒刑以下刑罚，符合起诉条件，但有悔罪表现的，
  人民检察院可以作出附条件不起诉的决定

违法犯罪记录封存（第105条）：⭐⭐⭐⭐⭐最高频⭐⭐⭐⭐⭐
  未成年人犯罪，被判处5年有期徒刑以下刑罚的，应当对相关犯罪记录予以封存
  犯罪记录被封存的，不得向任何单位/个人提供，但司法机关为办案需要或者有关单位根据国家规定进行查询的除外
  依法进行查询的单位，应当对被封存的犯罪记录的情况予以保密
  注意：封存范围包括被判处5年以下有期徒刑/拘役/管制/单处罚金的情形
  但被判处5年以上有期徒刑的，不得封存
  未成年人因违反治安管理被处罚的记录，参照封存规定执行

收容教养/专门教育（第106条）：
  未成年人实施刑法规定的行为/因不满法定刑事责任年龄不予刑事处罚的，经专门教育指导委员会评估同意，教育行政部门会同公安机关可以决定对其进行专门矫治教育
  对未成年犯应当在未成年犯管教所执行刑罚
```

## 强制报告制度速查表 ⭐⭐⭐⭐⭐

| 主体 | 应当报告 | 可以报告 |
|------|----------|----------|
| 国家机关工作人员 | ✅ | ✅ |
| 学校/幼儿园教职员工 | ✅ | ✅ |
| 医疗机构工作人员 | ✅ | ✅ |
| 社区工作者/居民委员会 | ✅ | ✅ |
| 救助管理机构/儿童福利机构 | ✅ | ✅ |
| 社会工作者 | ✅ | ✅ |
| 律师/心理咨询师 | ✅ | ✅ |
| 任何其他组织/个人 | — | ✅ 有权举报/控告 |
| 未履行报告义务 | 依法给予处分 | — |

**报告渠道**：
- 公安机关（110）
- 民政部门（12349 儿童福利热线）
- 教育行政部门
- 妇联/共青团/关工委

| 问题 | 答案 |
|------|------|
| 强制报告主体有哪些？ | 所有密切接触未成年人的单位/工作人员都是！未报告违法 |
