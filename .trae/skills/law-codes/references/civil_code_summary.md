## 民法典 vs 旧法重要变化

| 变化点 | 旧法 | 民法典 |
|--------|------|--------|
| 合同效力 | 批准/登记为生效条件 | 原则上成立即生效（502条） |
| 公证遗嘱 | 优先效力 | 废除，数份遗嘱最后为准 |
| 居住权 | 无 | 新增（366-371条） |
| 高空抛物 | 无 | 新增（1254条） |
| 网络侵权 | 无 | 系统规定（1194-1197条） |
| 个人信息 | 无独立人格权 | 独立编（第4编）+ 单法优先 |
| 离婚冷静期 | 无 | 30天（1077条） |
| 保证方式 | 约定不明视为连带 | 约定不明视为一般保证（686条） |
| 抵押权实现 | 先登记后诉讼 | 可直接向法院申请实现担保物权 |
| 物业合同 | 无专门规则 | 新增（937-950条） |
