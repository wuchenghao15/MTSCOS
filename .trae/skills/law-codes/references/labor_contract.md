# 中华人民共和国劳动合同法（98 条）

## 基本信息

| 项目 | 内容 |
|------|------|
| 现行版本 | 2012年12月28日修正 |
| 条文总数 | 98 条 |
| 核心 | 规范劳动合同订立/履行/变更/解除/终止；集体合同；劳务派遣；非全日制用工 |

---

## 核心条文速查

### 劳动合同订立

```
适用范围（第2条）：
  中华人民共和国境内的企业/个体经济组织/民办非企业单位等组织（用人单位）与劳动者建立劳动关系，订立/履行/变更/解除/终止劳动合同
  国家机关/事业单位/社会团体和与其建立劳动关系的劳动者
  注意：公务员/参照公务员管理的工作人员不适用本法

劳动合同订立时间（第10条）⭐⭐⭐：
  建立劳动关系，应当订立书面劳动合同
  已建立劳动关系，未同时订立书面劳动合同的，应当自用工之日起1个月内订立
  用人单位与劳动者在用工前订立劳动合同的，劳动关系自用工之日起建立

未签书面劳动合同后果（第82条）⭐⭐⭐高频⭐⭐⭐：
  用人单位自用工之日起超过1个月不满1年未与劳动者订立书面劳动合同的，
  应当向劳动者每月支付二倍的工资
  → 最多支持11个月的双倍工资（满1年视为无固定期限合同）
  计算基数：月应得工资（包括奖金/津贴/补贴等）

无固定期限劳动合同（第14条）⭐⭐⭐：
  法定情形（应当订立）：
  ① 劳动者在该用人单位连续工作满10年
  ② 用人单位初次实行劳动合同制度/国有企业改制重新订立劳动合同，劳动者在该用人单位连续工作满10年且距法定退休年龄不足10年
  ③ 连续订立2次固定期限劳动合同，且劳动者无本法第39条/第40条第1/2项规定情形，续订劳动合同的
  ④ 用人单位自用工之日起满1年不与劳动者订立书面劳动合同的，
     视为用人单位与劳动者已订立无固定期限劳动合同
  例外：劳动者提出订立固定期限劳动合同的除外

劳动合同必备条款（第17条）：
  用人单位信息/劳动者信息/劳动合同期限/工作内容/工作地点/工作时间/休息休假/劳动报酬/社会保险/劳动保护/职业危害防护等

试用期（第19条）⭐⭐⭐高频⭐⭐⭐：
  劳动合同期限 | 试用期
  不满3个月    | 不得约定
  3个月-1年    | ≤1个月
  1年-3年      | ≤2个月
  3年以上/无固定 | ≤6个月
  同一用人单位与同一劳动者只能约定1次试用期
  试用期包含在劳动合同期限内
  劳动合同仅约定试用期的，试用期不成立，该期限为劳动合同期限
  试用期工资（第20条）：
    不得低于本单位相同岗位最低档工资80% 或 劳动合同约定工资80%
    且不得低于用人单位所在地最低工资标准

违反试用期规定后果（第83条）：
  违法约定的试用期已经履行的，由用人单位以劳动者试用期满月工资为标准，
  按已经履行的超过法定试用期的期间向劳动者支付赔偿金
```

### 劳动合同履行/变更

```
工作时间（第41-43条）：
  标准工时：每日工作≤8小时，每周工作≤44小时
  加班一般每日≤1小时；特殊原因≤3小时，每月≤36小时
  加班工资（第44条）⭐⭐⭐：
    延长工作时间：≥150%工资
    休息日加班（不能安排补休）：≥200%工资
    法定休假日加班：≥300%工资
  休息日：每周至少1日（用人单位可根据生产经营特点灵活安排，但每周平均工作时间不得超过44小时）

劳动报酬（第30条）：
  用人单位应当按照劳动合同约定/国家规定，向劳动者及时足额支付劳动报酬
  拖欠/未足额支付的，劳动者可向法院申请支付令

病假/医疗期（劳动部规定）：
  实际工作年限 | 本单位工作年限 | 医疗期
  <10年       | <5年           | 3个月
              | ≥5年           | 6个月
  ≥10年       | <5年           | 6个月
              | 5-10年         | 9个月
              | 10-15年        | 12个月
              | 15-20年        | 18个月
              | ≥20年          | 24个月
  医疗期工资：不低于最低工资标准80%
```

### 劳动合同解除/终止

```
劳动者单方解除（第37/38条）：
  提前通知（第37条）：
    提前30日以书面形式通知用人单位 → 可以解除
    试用期内提前3日通知 → 可以解除
  即时解除（第38条，无需提前通知）⭐⭐⭐：
    ① 未按合同约定提供劳动保护/劳动条件
    ② 未及时足额支付劳动报酬
    ③ 未依法为劳动者缴纳社会保险费
    ④ 用人单位规章制度违法/损害劳动者权益
    ⑤ 因本法第26条第1款规定（欺诈/胁迫/乘人之危）致使合同无效
    ⑥ 其他法定情形
  → 以上情形解除，劳动者有权主张经济补偿

用人单位单方解除（第39-41条）⭐⭐⭐：
  即时解除（第39条，过失性辞退，无经济补偿）：
    ① 试用期被证明不符合录用条件
    ② 严重违反用人单位规章制度
    ③ 严重失职/营私舞弊，给用人单位造成重大损害
    ④ 同时与其他用人单位建立劳动关系，对完成本单位工作任务造成严重影响，经用人单位提出拒不改正
    ⑤ 因本法第26条第1款第1项规定（欺诈/胁迫/乘人之危）致使合同无效
    ⑥ 被依法追究刑事责任
  提前通知解除（第40条，非过失性辞退，需经济补偿）：
    ① 劳动者患病/非因工负伤，在规定的医疗期满后不能从事原工作，也不能从事由用人单位另行安排的工作
    ② 劳动者不能胜任工作，经过培训/调整工作岗位，仍不能胜任工作
    ③ 劳动合同订立时所依据的客观情况发生重大变化，致使劳动合同无法履行，经用人单位与劳动者协商，未能就变更劳动合同内容达成协议
  经济性裁员（第41条，需经济补偿）：
    情形：依照企业破产法规定进行重整/生产经营发生严重困难/企业转产/重大技术革新/经营方式调整/其他因劳动合同订立时所依据的客观经济情况发生重大变化，致使劳动合同无法履行
    数量：需要裁减人员20人以上/裁减不足20人但占企业职工总数10%以上
    程序：提前30日向工会/全体职工说明情况，听取工会/职工意见后，裁减人员方案经向劳动行政部门报告，可以裁减
    优先留用：
      ① 与本单位订立较长期限的固定期限劳动合同的
      ② 与本单位订立无固定期限劳动合同的
      ③ 家庭无其他就业人员，有需要扶养的老人/未成年人的
  禁止解除（第42条）⭐：
    ① 从事接触职业病危害作业的劳动者未进行离岗前职业健康检查/疑似职业病病人在诊断/医学观察期间
    ② 在本单位患职业病/因工负伤并被确认丧失/部分丧失劳动能力
    ③ 患病/非因工负伤，在规定的医疗期内
    ④ 女职工在孕期/产期/哺乳期
    ⑤ 在本单位连续工作满15年，且距法定退休年龄不足5年
    ⑥ 其他法定情形

经济补偿（第47条）⭐⭐⭐高频⭐⭐⭐：
  标准：每满1年支付1个月工资
  6个月以上不满1年 → 按1年计算；不满6个月 → 支付0.5个月工资
  高收入者限制：
    劳动者月工资高于用人单位所在直辖市/设区的市级人民政府公布的本地区上年度职工月平均工资3倍的，
    向其支付经济补偿的标准按职工月平均工资3倍的数额支付，且支付年限最高不超过12年
  月工资定义：劳动者在劳动合同解除/终止前12个月的平均工资

违法解除赔偿金（第87条）⭐⭐⭐：
  用人单位违反本法规定解除/终止劳动合同的，应当依照本法第47条规定的经济补偿标准的2倍向劳动者支付赔偿金
  即：2N（N为经济补偿月数）
  注意：2N与N+1（代通知金）不能兼得；2N与N（经济补偿）也不能兼得

代通知金（N+1中的+1，第40条）：
  用人单位依照第40条规定解除劳动合同，未提前30日通知的，应当额外支付1个月工资
  即：N+1 = 经济补偿N + 代通知金1

离职证明（第50条）：
  用人单位应当在解除/终止劳动合同时出具解除/终止劳动合同的证明
  并在15日内为劳动者办理档案和社会保险关系转移手续
  未出具证明的，由劳动行政部门责令改正；给劳动者造成损害的，应当承担赔偿责任
```

### 集体合同

```
集体合同订立（第51-52条）：
  企业职工一方与用人单位可就劳动报酬/工作时间/休息休假/劳动安全卫生/保险福利等事项订立集体合同
  由工会代表企业职工一方与用人单位订立；尚未建立工会的，由上级工会指导劳动者推举的代表与用人单位订立
  集体合同草案应当提交职工代表大会/全体职工讨论通过
  集体合同订立后，应当报送劳动行政部门；劳动行政部门自收到集体合同文本之日起15日内未提出异议的，集体合同即行生效
  集体合同对用人单位和劳动者均有约束力
```

### 劳务派遣

```
劳务派遣适用（第66条）：
  一般在临时性/辅助性/替代性的工作岗位上实施
  用工单位应当严格控制劳务派遣用工数量，使用的被派遣劳动者数量不得超过其用工总量的10%（超标的过渡期至2022年）
  禁止用工单位将被派遣劳动者再派遣到其他用人单位

劳务派遣单位（用人单位）义务：
  ① 与被派遣劳动者订立2年以上固定期限劳动合同
  ② 无工作期间应当按照所在地人民政府规定的最低工资标准向被派遣劳动者按月支付报酬
  ③ 不得克扣用工单位支付给被派遣劳动者的劳动报酬
  ④ 不得向被派遣劳动者收取费用
```

### 非全日制用工

```
定义（第68条）：
  以小时计酬为主，劳动者在同一用人单位一般平均每日工作时间不超过4小时，每周工作时间累计不超过24小时的用工形式
  特点：
    ① 非全日制用工双方当事人可以订立口头协议
    ② 从事非全日制用工的劳动者可以与一个/一个以上用人单位订立劳动合同（后订立的不得影响先订立的履行）
    ③ 非全日制用工双方当事人不得约定试用期
    ④ 非全日制用工双方当事人任何一方都可以随时通知对方终止用工；终止用工，用人单位不向劳动者支付经济补偿
    ⑤ 非全日制用工小时计酬标准不得低于用人单位所在地人民政府规定的最低小时工资标准
    ⑥ 非全日制用工劳动报酬结算支付周期最长不得超过15日
```

## 高频问题速查

| 问题 | 答案 |
|------|------|
| 未签合同双倍工资？ | 第82条，最多11个月，满1年视为无固定期限 |
| 试用期规定？ | 第19条（3月→1月；1年→2月；3年+→6月） |
| 经济补偿N怎么算？ | 第47条，每满1年=1月，6月+=1年 |
| 2N赔偿适用？ | 违法解除（87条）；需证明解除违法 |
| N+1代通知金适用？ | 第40条3种非过失性辞退情形，未提前30日通知 |
| 员工主动辞职有补偿吗？ | 一般没有；但第38条即时解除情形有N |
| 如何合法开除员工？ | 第39条（过失，无补偿）/ 第40条（非过失，需N）/ 第41条（裁员，需N） |
| 仲裁时效？ | 1年（从知道被侵害之日起；劳动关系存续期间因拖欠劳动报酬发生争议的，不受1年限制，从劳动关系终止之日起1年内提出） |
| 加班工资基数？ | 月工资/21.75天×加班天数×倍率 |
| 竞业限制？ | 2年，按月支付补偿金≥30%，违约金由双方约定 |
| 五险一金？ | 养老/医疗/失业/工伤/生育 + 住房公积金（法定必须缴纳） |
| 年假？ | 《职工带薪年休假条例》，累计工作1-10年→5天；10-20年→10天；20年+→15天 |
