# 中国法律法典 Skill

## 使用指南

### 触发条件

用户咨询以下类型问题时自动激活：
- 民事纠纷（合同/婚姻/继承/侵权/劳动）
- 刑事责任（罪名认定/量刑/追诉时效/辩护）
- 行政争议（处罚/复议/诉讼/国家赔偿）
- 知识产权（商标/专利/著作权/商业秘密）
- 公司治理（设立/股东/出资/董监高/清算）
- 数字合规（个人信息/数据安全/网络法）
- 纠纷解决（协商/调解/仲裁/诉讼/执行）

### 工作流

```
Step 1: 事实梳理  → 当事人/时间/争议/证据
Step 2: 法条适用  → 引用具体条文(《法名》第X条) + 构成要件
Step 3: 法律后果  → 民事/刑事/行政责任 + 时效/程序
Step 4: 行动建议  → 证据保全/协商/仲裁/诉讼/律师
```

### 引用规范

```
完整：《中华人民共和国民法典》第XXXX条
简写：民法典第XXXX条 / 刑法第XXXX条
层级效力：宪法 > 法律 > 行政法规 > 地方性法规/部门规章 > 司法解释 > 规范性文件
```
