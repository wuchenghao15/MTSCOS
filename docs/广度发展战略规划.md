## 3. 强度适配原则（每处落地的质量红线）

1. **零假数据**: 所有面板/API 数值必须来自落库表, 禁止硬编码（先例: iceberg_center '99.2%' 已消灭）
2. **fail-open 检索 / fail-closed 权限**: 语义/增强类可降级, 权限/密钥类必须硬拦截
3. **零 token 优先**: 能本地 Ollama 解决的不调外部 API
4. **12步骤全覆盖**: 任何泛化消费点都走独立 flow（A/B 轮表决 + test1000 + 双推）
5. **双库一致**: 主库改动必须同步 PROD（smart_sync + 对账复核）
