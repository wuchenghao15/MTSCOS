## Overview

MTSCOS AI Project v21.6.0 是一个里程碑式的版本，引入了深度巡检引擎、自动开发团队、自动巡逻队、EigenFlux广播网络和8分片数据库系统。这个版本实现了系统运维的全自动化闭环，从代码巡检到自动修复，从功能检测到自动开发，从安全巡逻到漏洞修复，全部由AI员工自动完成。

### 🔄 数据库双引擎架构

主库+二级库分离管理：

```
┌─────────────────────────────────────┐
│   DualEngineManager (双引擎管理)     │
│  ┌──────────────┐  ┌──────────────┐ │
│  │ PRIMARY引擎  │  │ BACKUP引擎   │ │
│  │ (WAL读写)    │◄►│ (只读热备)   │ │
│  └──────────────┘  └──────────────┘ │
└─────────────────────────────────────┘
```

**核心特性**:
- WAL模式支持并发读写
- 主引擎故障时 ≤500ms 自动切换到备份引擎
- SHA256校验确保主备数据一致性
- 64MB缓存提升读取性能

## Upgrade Guide

```bash
# 1. 备份数据库
python backup_db.py

# 2. 拉取最新代码
git pull origin main

# 3. 安装新依赖
pip install -r _config/requirements.txt

# 4. 初始化分片数据库
python flask-app/init_db.py

# 5. 运行数据库迁移
python data_migration_service.py

# 6. 重启服务
python server_real_db.py
```

## Migration Notes

### 数据库迁移

1. 备份现有数据库
2. 运行分片初始化脚本
3. 表会自动映射到对应分片
4. 数据会自动迁移到对应分片

### 配置更新

1. 更新 `.env` 文件，添加分片配置
2. 更新 `app/config/table_mapping.json`
3. 重启服务使配置生效
